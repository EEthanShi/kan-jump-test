You are completing the design of a small book sorting row of carts with 4 carts.

The carts are: JADI, FIJU, POJI, VAJO. Books move JADI -> FIJU -> POJI -> VAJO.
There are 5 moving steps:
- "vodu" carries each JADI tray to a FIJU tray.
- "tazo" is an internal rearrangement of FIJU: it carries each FIJU tray to a FIJU tray.
- "zigi" carries each FIJU tray to a POJI tray.
- "sogi" is an internal rearrangement of POJI: it carries each POJI tray to a POJI tray.
- "piko" carries each POJI tray to a VAJO tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "vodu" and then "tazo" lands on the same tray as running "vodu" alone.
     ("tazo" leaves every tray that "vodu" produces unchanged.)
R1.2 Running "tazo" and then "zigi" gives the same result as running "zigi" alone.
     ("zigi" cannot tell whether "tazo" was applied first.)
R1.3 Running "tazo" twice in a row leaves every FIJU tray exactly where it started.
R2.1 Running "zigi" and then "sogi" lands on the same tray as running "zigi" alone.
     ("sogi" leaves every tray that "zigi" produces unchanged.)
R2.2 Running "sogi" and then "piko" gives the same result as running "piko" alone.
     ("piko" cannot tell whether "sogi" was applied first.)
R2.3 Running "sogi" twice in a row leaves every POJI tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JADI has exactly one tray, called n1.
- VAJO has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (FIJU, POJI):
D1.1 FIJU must be a finite set with at most 3 trays.
D1.2 "tazo" must NOT be the do-nothing move (it must move at least one FIJU tray).
D2.1 POJI must be a finite set with at most 3 trays.
D2.2 "sogi" must NOT be the do-nothing move (it must move at least one POJI tray).

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

FIJU = {q1_1, ..., q1_k}
vodu: n1 -> <FIJU tray>
tazo: q1_1 -> <FIJU tray>, ..., q1_k -> <FIJU tray>
POJI = {q2_1, ..., q2_k}
zigi: q1_1 -> <POJI tray>, ... (one entry per FIJU tray)
sogi: q2_1 -> <POJI tray>, ..., q2_k -> <POJI tray>
piko: q2_1 -> <VAJO tray>, ... (one entry per POJI tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
