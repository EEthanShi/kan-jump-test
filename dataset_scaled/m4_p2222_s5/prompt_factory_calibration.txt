You are completing the design of a small toy sorting line with 6 stations.

The stations are: ZUFI, SOSI, FUSO, SONO, FULI, SUJU. Toys move ZUFI -> SOSI -> FUSO -> SONO -> FULI -> SUJU.
There are 9 moving steps:
- "vunu" carries each ZUFI slot to a SOSI slot.
- "rara" is an internal reshuffle of SOSI: it carries each SOSI slot to a SOSI slot.
- "kugi" carries each SOSI slot to a FUSO slot.
- "fani" is an internal reshuffle of FUSO: it carries each FUSO slot to a FUSO slot.
- "guma" carries each FUSO slot to a SONO slot.
- "sifu" is an internal reshuffle of SONO: it carries each SONO slot to a SONO slot.
- "kadu" carries each SONO slot to a FULI slot.
- "pata" is an internal reshuffle of FULI: it carries each FULI slot to a FULI slot.
- "govi" carries each FULI slot to a SUJU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vunu" and then "rara" lands on the same slot as running "vunu" alone.
     ("rara" leaves every slot that "vunu" produces unchanged.)
R1.2 Running "rara" and then "kugi" gives the same result as running "kugi" alone.
     ("kugi" cannot tell whether "rara" was applied first.)
R1.3 Running "rara" twice in a row leaves every SOSI slot exactly where it started.
R2.1 Running "kugi" and then "fani" lands on the same slot as running "kugi" alone.
     ("fani" leaves every slot that "kugi" produces unchanged.)
R2.2 Running "fani" and then "guma" gives the same result as running "guma" alone.
