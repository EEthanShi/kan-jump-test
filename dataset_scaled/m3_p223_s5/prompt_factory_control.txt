You are completing the design of a small toy sorting line with 5 stations.

The stations are: FIDU, ROKA, ZIBI, TORU, GAPA. Toys move FIDU -> ROKA -> ZIBI -> TORU -> GAPA.
There are 7 moving steps:
- "zifi" carries each FIDU slot to a ROKA slot.
- "dibi" is an internal reshuffle of ROKA: it carries each ROKA slot to a ROKA slot.
- "taba" carries each ROKA slot to a ZIBI slot.
- "mazi" is an internal reshuffle of ZIBI: it carries each ZIBI slot to a ZIBI slot.
- "lupo" carries each ZIBI slot to a TORU slot.
- "tigi" is an internal reshuffle of TORU: it carries each TORU slot to a TORU slot.
- "maso" carries each TORU slot to a GAPA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "zifi" and then "dibi" lands on the same slot as running "zifi" alone.
     ("dibi" leaves every slot that "zifi" produces unchanged.)
R1.2 Running "dibi" and then "taba" gives the same result as running "taba" alone.
     ("taba" cannot tell whether "dibi" was applied first.)
R1.3 Running "dibi" twice in a row leaves every ROKA slot exactly where it started.
R2.1 Running "taba" and then "mazi" lands on the same slot as running "taba" alone.
     ("mazi" leaves every slot that "taba" produces unchanged.)
R2.2 Running "mazi" and then "lupo" gives the same result as running "lupo" alone.
     ("lupo" cannot tell whether "mazi" was applied first.)
R2.3 Running "mazi" twice in a row leaves every ZIBI slot exactly where it started.
R3.1 Running "lupo" and then "tigi" lands on the same slot as running "lupo" alone.
     ("tigi" leaves every slot that "lupo" produces unchanged.)
R3.2 Running "tigi" and then "maso" gives the same result as running "maso" alone.
     ("maso" cannot tell whether "tigi" was applied first.)
R3.3 Running "tigi" three times in a row leaves every TORU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FIDU has exactly one slot, called n1.
- GAPA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (ROKA, ZIBI, TORU):
D1.1 ROKA must be a finite set with at most 1 slot.
D1.2 List the "dibi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 ZIBI must be a finite set with at most 1 slot.
D2.2 List the "mazi" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 TORU must be a finite set with at most 1 slot.
D3.2 List the "tigi" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ROKA = {q1_1, ..., q1_k}
zifi: n1 -> <ROKA slot>
dibi: q1_1 -> <ROKA slot>, ..., q1_k -> <ROKA slot>
ZIBI = {q2_1, ..., q2_k}
taba: q1_1 -> <ZIBI slot>, ... (one entry per ROKA slot)
mazi: q2_1 -> <ZIBI slot>, ..., q2_k -> <ZIBI slot>
TORU = {q3_1, ..., q3_k}
lupo: q2_1 -> <TORU slot>, ... (one entry per ZIBI slot)
tigi: q3_1 -> <TORU slot>, ..., q3_k -> <TORU slot>
maso: q3_1 -> <GAPA slot>, ... (one entry per TORU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
