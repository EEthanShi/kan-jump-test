You are completing the design of a small book sorting row of carts with 3 carts.

The carts are: KOMA, RIFU, NALI. Books move KOMA -> RIFU -> NALI.
There are 3 moving steps:
- "kiba" carries each KOMA tray to a RIFU tray.
- "kisu" is an internal rearrangement of RIFU: it carries each RIFU tray to a RIFU tray.
- "kufo" carries each RIFU tray to a NALI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "kiba" and then "kisu" lands on the same tray as running "kiba" alone.
     ("kisu" leaves every tray that "kiba" produces unchanged.)
R1.2 Running "kisu" and then "kufo" gives the same result as running "kufo" alone.
     ("kufo" cannot tell whether "kisu" was applied first.)
R1.3 Running "kisu" twice in a row leaves every RIFU tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KOMA has exactly 3 trays, called n1, n2, n3.
- NALI has exactly 1 tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle cart (RIFU):
D1.1 List the trays of RIFU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "kisu" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D1.3 List the "kiba" table entries in KOMA tray order n1, n2, n3.
D1.4 List the "kufo" table entries in RIFU tray order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle cart.

Answer format bound: designs with up to 5 trays in the middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
use tray names q1_1, q1_2, ... for the middle cart):

RIFU = {q1_1, ..., q1_k}
kiba: n1 -> <RIFU tray>, n2 -> <RIFU tray>, n3 -> <RIFU tray>
kisu: q1_1 -> <RIFU tray>, ..., q1_k -> <RIFU tray>
kufo: q1_1 -> <NALI tray>, ... (one entry per RIFU tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
