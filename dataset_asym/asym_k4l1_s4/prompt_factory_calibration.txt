You are completing the design of a small toy sorting line with 3 stations.

The stations are: NIKU, NOMA, FUSO. Toys move NIKU -> NOMA -> FUSO.
There are 3 moving steps:
- "gojo" carries each NIKU slot to a NOMA slot.
- "moga" is an internal reshuffle of NOMA: it carries each NOMA slot to a NOMA slot.
- "puko" carries each NOMA slot to a FUSO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "gojo" and then "moga" lands on the same slot as running "gojo" alone.
     ("moga" leaves every slot that "gojo" produces unchanged.)
R1.2 Running "moga" and then "puko" gives the same result as running "puko" alone.
     ("puko" cannot tell whether "moga" was applied first.)
R1.3 Running "moga" twice in a row leaves every NOMA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NIKU has exactly 4 slots, called n1, n2, n3, n4.
- FUSO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1.

Requirements for the middle station (NOMA):
D1.1 List the slots of NOMA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "moga" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "gojo" table entries in NIKU slot order n1, n2, n3, n4.
D1.4 List the "puko" table entries in NOMA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 6 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

NOMA = {q1_1, ..., q1_k}
gojo: n1 -> <NOMA slot>, n2 -> <NOMA slot>, n3 -> <NOMA slot>, n4 -> <NOMA slot>
moga: q1_1 -> <NOMA slot>, ..., q1_k -> <NOMA slot>
puko: q1_1 -> <FUSO slot>, ... (one entry per NOMA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
