You are completing the design of a small toy sorting line with 3 stations.

The stations are: GUFA, DAFO, DONA. Toys move GUFA -> DAFO -> DONA.
There are 3 moving steps:
- "nika" carries each GUFA slot to a DAFO slot.
- "futi" is an internal reshuffle of DAFO: it carries each DAFO slot to a DAFO slot.
- "nadu" carries each DAFO slot to a DONA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "nika" and then "futi" lands on the same slot as running "nika" alone.
     ("futi" leaves every slot that "nika" produces unchanged.)
R1.2 Running "futi" and then "nadu" gives the same result as running "nadu" alone.
     ("nadu" cannot tell whether "futi" was applied first.)
R1.3 Running "futi" three times in a row leaves every DAFO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GUFA has exactly one slot, called n1.
- DONA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (DAFO):
D1.1 DAFO must be a finite set with at most 1 slot.
D1.2 List the "futi" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

DAFO = {q1_1, ..., q1_k}
nika: n1 -> <DAFO slot>
futi: q1_1 -> <DAFO slot>, ..., q1_k -> <DAFO slot>
nadu: q1_1 -> <DONA slot>, ... (one entry per DAFO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
