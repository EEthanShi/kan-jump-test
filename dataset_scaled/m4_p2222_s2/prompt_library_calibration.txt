You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: GUTU, PUFO, DOTO, RUMO, DUSU, ZUZI. Books move GUTU -> PUFO -> DOTO -> RUMO -> DUSU -> ZUZI.
There are 9 moving steps:
- "muzu" carries each GUTU tray to a PUFO tray.
- "jami" is an internal rearrangement of PUFO: it carries each PUFO tray to a PUFO tray.
- "japi" carries each PUFO tray to a DOTO tray.
- "polu" is an internal rearrangement of DOTO: it carries each DOTO tray to a DOTO tray.
- "mofu" carries each DOTO tray to a RUMO tray.
- "ligo" is an internal rearrangement of RUMO: it carries each RUMO tray to a RUMO tray.
- "fata" carries each RUMO tray to a DUSU tray.
- "nuno" is an internal rearrangement of DUSU: it carries each DUSU tray to a DUSU tray.
- "kifu" carries each DUSU tray to a ZUZI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "muzu" and then "jami" lands on the same tray as running "muzu" alone.
     ("jami" leaves every tray that "muzu" produces unchanged.)
R1.2 Running "jami" and then "japi" gives the same result as running "japi" alone.
     ("japi" cannot tell whether "jami" was applied first.)
R1.3 Running "jami" twice in a row leaves every PUFO tray exactly where it started.
R2.1 Running "japi" and then "polu" lands on the same tray as running "japi" alone.
     ("polu" leaves every tray that "japi" produces unchanged.)
R2.2 Running "polu" and then "mofu" gives the same result as running "mofu" alone.
     ("mofu" cannot tell whether "polu" was applied first.)
R2.3 Running "polu" twice in a row leaves every DOTO tray exactly where it started.
R3.1 Running "mofu" and then "ligo" lands on the same tray as running "mofu" alone.
     ("ligo" leaves every tray that "mofu" produces unchanged.)
R3.2 Running "ligo" and then "fata" gives the same result as running "fata" alone.
     ("fata" cannot tell whether "ligo" was applied first.)
R3.3 Running "ligo" twice in a row leaves every RUMO tray exactly where it started.
R4.1 Running "fata" and then "nuno" lands on the same tray as running "fata" alone.
     ("nuno" leaves every tray that "fata" produces unchanged.)
R4.2 Running "nuno" and then "kifu" gives the same result as running "kifu" alone.
     ("kifu" cannot tell whether "nuno" was applied first.)
R4.3 Running "nuno" twice in a row leaves every DUSU tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GUTU has exactly one tray, called n1.
- ZUZI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (PUFO, DOTO, RUMO, DUSU):
D1.1 List the trays of PUFO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "jami" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 List the trays of DOTO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "polu" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 List the trays of RUMO in increasing index order q3_1, q3_2, ... in its set line.

D4.1 List the trays of DUSU in increasing index order q4_1, q4_2, ... in its set line.
D4.2 List the "nuno" table entries in tray order q4_1, q4_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.
