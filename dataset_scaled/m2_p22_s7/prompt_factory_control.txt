You are completing the design of a small toy sorting line with 4 stations.

The stations are: VIRA, FODI, BIMU, MADU. Toys move VIRA -> FODI -> BIMU -> MADU.
There are 5 moving steps:
- "jijo" carries each VIRA slot to a FODI slot.
- "fisi" is an internal reshuffle of FODI: it carries each FODI slot to a FODI slot.
- "viva" carries each FODI slot to a BIMU slot.
- "roni" is an internal reshuffle of BIMU: it carries each BIMU slot to a BIMU slot.
- "gara" carries each BIMU slot to a MADU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jijo" and then "fisi" lands on the same slot as running "jijo" alone.
     ("fisi" leaves every slot that "jijo" produces unchanged.)
R1.2 Running "fisi" and then "viva" gives the same result as running "viva" alone.
     ("viva" cannot tell whether "fisi" was applied first.)
R1.3 Running "fisi" twice in a row leaves every FODI slot exactly where it started.
R2.1 Running "viva" and then "roni" lands on the same slot as running "viva" alone.
     ("roni" leaves every slot that "viva" produces unchanged.)
R2.2 Running "roni" and then "gara" gives the same result as running "gara" alone.
     ("gara" cannot tell whether "roni" was applied first.)
R2.3 Running "roni" twice in a row leaves every BIMU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VIRA has exactly one slot, called n1.
- MADU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FODI, BIMU):
D1.1 FODI must be a finite set with at most 1 slot.
D1.2 List the "fisi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 BIMU must be a finite set with at most 1 slot.
D2.2 List the "roni" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FODI = {q1_1, ..., q1_k}
jijo: n1 -> <FODI slot>
fisi: q1_1 -> <FODI slot>, ..., q1_k -> <FODI slot>
BIMU = {q2_1, ..., q2_k}
viva: q1_1 -> <BIMU slot>, ... (one entry per FODI slot)
roni: q2_1 -> <BIMU slot>, ..., q2_k -> <BIMU slot>
gara: q2_1 -> <MADU slot>, ... (one entry per BIMU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
