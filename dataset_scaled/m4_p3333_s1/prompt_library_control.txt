You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: RULI, ZIZU, ROSA, TUDO, BUMA, VOJA. Books move RULI -> ZIZU -> ROSA -> TUDO -> BUMA -> VOJA.
There are 9 moving steps:
- "bipo" carries each RULI tray to a ZIZU tray.
- "fana" is an internal rearrangement of ZIZU: it carries each ZIZU tray to a ZIZU tray.
- "zatu" carries each ZIZU tray to a ROSA tray.
- "naga" is an internal rearrangement of ROSA: it carries each ROSA tray to a ROSA tray.
- "nito" carries each ROSA tray to a TUDO tray.
- "fumi" is an internal rearrangement of TUDO: it carries each TUDO tray to a TUDO tray.
- "bija" carries each TUDO tray to a BUMA tray.
- "jipo" is an internal rearrangement of BUMA: it carries each BUMA tray to a BUMA tray.
- "zudo" carries each BUMA tray to a VOJA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "bipo" and then "fana" lands on the same tray as running "bipo" alone.
     ("fana" leaves every tray that "bipo" produces unchanged.)
R1.2 Running "fana" and then "zatu" gives the same result as running "zatu" alone.
     ("zatu" cannot tell whether "fana" was applied first.)
R1.3 Running "fana" three times in a row leaves every ZIZU tray exactly where it started.
R2.1 Running "zatu" and then "naga" lands on the same tray as running "zatu" alone.
     ("naga" leaves every tray that "zatu" produces unchanged.)
R2.2 Running "naga" and then "nito" gives the same result as running "nito" alone.
     ("nito" cannot tell whether "naga" was applied first.)
R2.3 Running "naga" three times in a row leaves every ROSA tray exactly where it started.
R3.1 Running "nito" and then "fumi" lands on the same tray as running "nito" alone.
     ("fumi" leaves every tray that "nito" produces unchanged.)
R3.2 Running "fumi" and then "bija" gives the same result as running "bija" alone.
     ("bija" cannot tell whether "fumi" was applied first.)
R3.3 Running "fumi" three times in a row leaves every TUDO tray exactly where it started.
R4.1 Running "bija" and then "jipo" lands on the same tray as running "bija" alone.
     ("jipo" leaves every tray that "bija" produces unchanged.)
R4.2 Running "jipo" and then "zudo" gives the same result as running "zudo" alone.
     ("zudo" cannot tell whether "jipo" was applied first.)
R4.3 Running "jipo" three times in a row leaves every BUMA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RULI has exactly one tray, called n1.
- VOJA has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (ZIZU, ROSA, TUDO, BUMA):
D1.1 ZIZU must be a finite set with at most 1 tray.
D1.2 List the "fana" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 ROSA must be a finite set with at most 1 tray.
D2.2 List the "naga" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 TUDO must be a finite set with at most 1 tray.
D3.2 List the "fumi" table entries in tray order q3_1, q3_2, ..., one entry per tray.
D4.1 BUMA must be a finite set with at most 1 tray.
D4.2 List the "jipo" table entries in tray order q4_1, q4_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
