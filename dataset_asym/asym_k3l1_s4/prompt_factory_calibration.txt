You are completing the design of a small toy sorting line with 3 stations.

The stations are: TOLU, RUZA, NIRA. Toys move TOLU -> RUZA -> NIRA.
There are 3 moving steps:
- "dopi" carries each TOLU slot to a RUZA slot.
- "totu" is an internal reshuffle of RUZA: it carries each RUZA slot to a RUZA slot.
- "paju" carries each RUZA slot to a NIRA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dopi" and then "totu" lands on the same slot as running "dopi" alone.
     ("totu" leaves every slot that "dopi" produces unchanged.)
R1.2 Running "totu" and then "paju" gives the same result as running "paju" alone.
     ("paju" cannot tell whether "totu" was applied first.)
R1.3 Running "totu" twice in a row leaves every RUZA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TOLU has exactly 3 slots, called n1, n2, n3.
- NIRA has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (RUZA):
D1.1 List the slots of RUZA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "totu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "dopi" table entries in TOLU slot order n1, n2, n3.
D1.4 List the "paju" table entries in RUZA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

RUZA = {q1_1, ..., q1_k}
dopi: n1 -> <RUZA slot>, n2 -> <RUZA slot>, n3 -> <RUZA slot>
totu: q1_1 -> <RUZA slot>, ..., q1_k -> <RUZA slot>
paju: q1_1 -> <NIRA slot>, ... (one entry per RUZA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
