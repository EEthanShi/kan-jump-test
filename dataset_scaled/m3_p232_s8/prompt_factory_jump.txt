You are completing the design of a small toy sorting line with 5 stations.

The stations are: KULO, VINO, FUDO, BAFI, JISA. Toys move KULO -> VINO -> FUDO -> BAFI -> JISA.
There are 7 moving steps:
- "rafa" carries each KULO slot to a VINO slot.
- "jopu" is an internal reshuffle of VINO: it carries each VINO slot to a VINO slot.
- "diti" carries each VINO slot to a FUDO slot.
- "kito" is an internal reshuffle of FUDO: it carries each FUDO slot to a FUDO slot.
- "noku" carries each FUDO slot to a BAFI slot.
- "foma" is an internal reshuffle of BAFI: it carries each BAFI slot to a BAFI slot.
- "vali" carries each BAFI slot to a JISA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "rafa" and then "jopu" lands on the same slot as running "rafa" alone.
     ("jopu" leaves every slot that "rafa" produces unchanged.)
R1.2 Running "jopu" and then "diti" gives the same result as running "diti" alone.
     ("diti" cannot tell whether "jopu" was applied first.)
R1.3 Running "jopu" twice in a row leaves every VINO slot exactly where it started.
R2.1 Running "diti" and then "kito" lands on the same slot as running "diti" alone.
     ("kito" leaves every slot that "diti" produces unchanged.)
R2.2 Running "kito" and then "noku" gives the same result as running "noku" alone.
     ("noku" cannot tell whether "kito" was applied first.)
R2.3 Running "kito" three times in a row leaves every FUDO slot exactly where it started.
R3.1 Running "noku" and then "foma" lands on the same slot as running "noku" alone.
     ("foma" leaves every slot that "noku" produces unchanged.)
R3.2 Running "foma" and then "vali" gives the same result as running "vali" alone.
     ("vali" cannot tell whether "foma" was applied first.)
R3.3 Running "foma" twice in a row leaves every BAFI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KULO has exactly one slot, called n1.
- JISA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (VINO, FUDO, BAFI):
D1.1 VINO must be a finite set with at most 3 slots.
D1.2 "jopu" must NOT be the do-nothing move (it must move at least one VINO slot).
D2.1 FUDO must be a finite set with at most 4 slots.
D2.2 "kito" must NOT be the do-nothing move (it must move at least one FUDO slot).
D3.1 BAFI must be a finite set with at most 3 slots.
D3.2 "foma" must NOT be the do-nothing move (it must move at least one BAFI slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

VINO = {q1_1, ..., q1_k}
rafa: n1 -> <VINO slot>
jopu: q1_1 -> <VINO slot>, ..., q1_k -> <VINO slot>
FUDO = {q2_1, ..., q2_k}
diti: q1_1 -> <FUDO slot>, ... (one entry per VINO slot)
kito: q2_1 -> <FUDO slot>, ..., q2_k -> <FUDO slot>
BAFI = {q3_1, ..., q3_k}
noku: q2_1 -> <BAFI slot>, ... (one entry per FUDO slot)
foma: q3_1 -> <BAFI slot>, ..., q3_k -> <BAFI slot>
vali: q3_1 -> <JISA slot>, ... (one entry per BAFI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
