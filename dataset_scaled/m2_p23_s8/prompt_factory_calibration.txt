You are completing the design of a small toy sorting line with 4 stations.

The stations are: LAZO, TASO, MIPI, KAMI. Toys move LAZO -> TASO -> MIPI -> KAMI.
There are 5 moving steps:
- "diba" carries each LAZO slot to a TASO slot.
- "roru" is an internal reshuffle of TASO: it carries each TASO slot to a TASO slot.
- "guna" carries each TASO slot to a MIPI slot.
- "paka" is an internal reshuffle of MIPI: it carries each MIPI slot to a MIPI slot.
- "vubu" carries each MIPI slot to a KAMI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "diba" and then "roru" lands on the same slot as running "diba" alone.
     ("roru" leaves every slot that "diba" produces unchanged.)
R1.2 Running "roru" and then "guna" gives the same result as running "guna" alone.
     ("guna" cannot tell whether "roru" was applied first.)
R1.3 Running "roru" twice in a row leaves every TASO slot exactly where it started.
R2.1 Running "guna" and then "paka" lands on the same slot as running "guna" alone.
     ("paka" leaves every slot that "guna" produces unchanged.)
R2.2 Running "paka" and then "vubu" gives the same result as running "vubu" alone.
     ("vubu" cannot tell whether "paka" was applied first.)
R2.3 Running "paka" three times in a row leaves every MIPI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LAZO has exactly one slot, called n1.
- KAMI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (TASO, MIPI):
D1.1 List the slots of TASO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "roru" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of MIPI in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "paka" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

TASO = {q1_1, ..., q1_k}
diba: n1 -> <TASO slot>
roru: q1_1 -> <TASO slot>, ..., q1_k -> <TASO slot>
MIPI = {q2_1, ..., q2_k}
guna: q1_1 -> <MIPI slot>, ... (one entry per TASO slot)
paka: q2_1 -> <MIPI slot>, ..., q2_k -> <MIPI slot>
vubu: q2_1 -> <KAMI slot>, ... (one entry per MIPI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
