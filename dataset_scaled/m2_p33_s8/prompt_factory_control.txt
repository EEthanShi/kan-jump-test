You are completing the design of a small toy sorting line with 4 stations.

The stations are: PUMI, BUGA, NAVO, MIPO. Toys move PUMI -> BUGA -> NAVO -> MIPO.
There are 5 moving steps:
- "goba" carries each PUMI slot to a BUGA slot.
- "bonu" is an internal reshuffle of BUGA: it carries each BUGA slot to a BUGA slot.
- "rova" carries each BUGA slot to a NAVO slot.
- "dazo" is an internal reshuffle of NAVO: it carries each NAVO slot to a NAVO slot.
- "fibi" carries each NAVO slot to a MIPO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "goba" and then "bonu" lands on the same slot as running "goba" alone.
     ("bonu" leaves every slot that "goba" produces unchanged.)
R1.2 Running "bonu" and then "rova" gives the same result as running "rova" alone.
     ("rova" cannot tell whether "bonu" was applied first.)
R1.3 Running "bonu" three times in a row leaves every BUGA slot exactly where it started.
R2.1 Running "rova" and then "dazo" lands on the same slot as running "rova" alone.
     ("dazo" leaves every slot that "rova" produces unchanged.)
R2.2 Running "dazo" and then "fibi" gives the same result as running "fibi" alone.
     ("fibi" cannot tell whether "dazo" was applied first.)
R2.3 Running "dazo" three times in a row leaves every NAVO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PUMI has exactly one slot, called n1.
- MIPO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (BUGA, NAVO):
D1.1 BUGA must be a finite set with at most 1 slot.
D1.2 List the "bonu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 NAVO must be a finite set with at most 1 slot.
D2.2 List the "dazo" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BUGA = {q1_1, ..., q1_k}
goba: n1 -> <BUGA slot>
bonu: q1_1 -> <BUGA slot>, ..., q1_k -> <BUGA slot>
NAVO = {q2_1, ..., q2_k}
rova: q1_1 -> <NAVO slot>, ... (one entry per BUGA slot)
dazo: q2_1 -> <NAVO slot>, ..., q2_k -> <NAVO slot>
fibi: q2_1 -> <MIPO slot>, ... (one entry per NAVO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
