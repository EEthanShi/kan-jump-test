You are completing the design of a small toy sorting line with 5 stations.

The stations are: ZUDU, KUNI, BUTA, FIPO, LALA. Toys move ZUDU -> KUNI -> BUTA -> FIPO -> LALA.
There are 7 moving steps:
- "ruja" carries each ZUDU slot to a KUNI slot.
- "gusa" is an internal reshuffle of KUNI: it carries each KUNI slot to a KUNI slot.
- "mabi" carries each KUNI slot to a BUTA slot.
- "sozi" is an internal reshuffle of BUTA: it carries each BUTA slot to a BUTA slot.
- "rini" carries each BUTA slot to a FIPO slot.
- "roli" is an internal reshuffle of FIPO: it carries each FIPO slot to a FIPO slot.
- "sodu" carries each FIPO slot to a LALA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "ruja" and then "gusa" lands on the same slot as running "ruja" alone.
     ("gusa" leaves every slot that "ruja" produces unchanged.)
R1.2 Running "gusa" and then "mabi" gives the same result as running "mabi" alone.
     ("mabi" cannot tell whether "gusa" was applied first.)
R1.3 Running "gusa" twice in a row leaves every KUNI slot exactly where it started.
R2.1 Running "mabi" and then "sozi" lands on the same slot as running "mabi" alone.
     ("sozi" leaves every slot that "mabi" produces unchanged.)
R2.2 Running "sozi" and then "rini" gives the same result as running "rini" alone.
     ("rini" cannot tell whether "sozi" was applied first.)
R2.3 Running "sozi" three times in a row leaves every BUTA slot exactly where it started.
R3.1 Running "rini" and then "roli" lands on the same slot as running "rini" alone.
     ("roli" leaves every slot that "rini" produces unchanged.)
R3.2 Running "roli" and then "sodu" gives the same result as running "sodu" alone.
     ("sodu" cannot tell whether "roli" was applied first.)
R3.3 Running "roli" twice in a row leaves every FIPO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ZUDU has exactly one slot, called n1.
- LALA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KUNI, BUTA, FIPO):
D1.1 KUNI must be a finite set with at most 3 slots.
D1.2 "gusa" must NOT be the do-nothing move (it must move at least one KUNI slot).
D2.1 BUTA must be a finite set with at most 4 slots.
D2.2 "sozi" must NOT be the do-nothing move (it must move at least one BUTA slot).
D3.1 FIPO must be a finite set with at most 3 slots.
D3.2 "roli" must NOT be the do-nothing move (it must move at least one FIPO slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KUNI = {q1_1, ..., q1_k}
ruja: n1 -> <KUNI slot>
gusa: q1_1 -> <KUNI slot>, ..., q1_k -> <KUNI slot>
BUTA = {q2_1, ..., q2_k}
mabi: q1_1 -> <BUTA slot>, ... (one entry per KUNI slot)
sozi: q2_1 -> <BUTA slot>, ..., q2_k -> <BUTA slot>
FIPO = {q3_1, ..., q3_k}
rini: q2_1 -> <FIPO slot>, ... (one entry per BUTA slot)
roli: q3_1 -> <FIPO slot>, ..., q3_k -> <FIPO slot>
sodu: q3_1 -> <LALA slot>, ... (one entry per FIPO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
