You are completing the design of a small toy sorting line with 5 stations.

The stations are: KOVU, BAPA, GOSA, BIJO, GUSI. Toys move KOVU -> BAPA -> GOSA -> BIJO -> GUSI.
There are 7 moving steps:
- "ruri" carries each KOVU slot to a BAPA slot.
- "rosi" is an internal reshuffle of BAPA: it carries each BAPA slot to a BAPA slot.
- "lapu" carries each BAPA slot to a GOSA slot.
- "nafa" is an internal reshuffle of GOSA: it carries each GOSA slot to a GOSA slot.
- "bumo" carries each GOSA slot to a BIJO slot.
- "gida" is an internal reshuffle of BIJO: it carries each BIJO slot to a BIJO slot.
- "bofa" carries each BIJO slot to a GUSI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "ruri" and then "rosi" lands on the same slot as running "ruri" alone.
     ("rosi" leaves every slot that "ruri" produces unchanged.)
R1.2 Running "rosi" and then "lapu" gives the same result as running "lapu" alone.
     ("lapu" cannot tell whether "rosi" was applied first.)
R1.3 Running "rosi" three times in a row leaves every BAPA slot exactly where it started.
R2.1 Running "lapu" and then "nafa" lands on the same slot as running "lapu" alone.
     ("nafa" leaves every slot that "lapu" produces unchanged.)
R2.2 Running "nafa" and then "bumo" gives the same result as running "bumo" alone.
     ("bumo" cannot tell whether "nafa" was applied first.)
R2.3 Running "nafa" three times in a row leaves every GOSA slot exactly where it started.
R3.1 Running "bumo" and then "gida" lands on the same slot as running "bumo" alone.
     ("gida" leaves every slot that "bumo" produces unchanged.)
R3.2 Running "gida" and then "bofa" gives the same result as running "bofa" alone.
     ("bofa" cannot tell whether "gida" was applied first.)
R3.3 Running "gida" twice in a row leaves every BIJO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KOVU has exactly one slot, called n1.
- GUSI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (BAPA, GOSA, BIJO):
D1.1 BAPA must be a finite set with at most 1 slot.
D1.2 List the "rosi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 GOSA must be a finite set with at most 1 slot.
D2.2 List the "nafa" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 BIJO must be a finite set with at most 1 slot.
D3.2 List the "gida" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BAPA = {q1_1, ..., q1_k}
ruri: n1 -> <BAPA slot>
rosi: q1_1 -> <BAPA slot>, ..., q1_k -> <BAPA slot>
GOSA = {q2_1, ..., q2_k}
lapu: q1_1 -> <GOSA slot>, ... (one entry per BAPA slot)
nafa: q2_1 -> <GOSA slot>, ..., q2_k -> <GOSA slot>
BIJO = {q3_1, ..., q3_k}
bumo: q2_1 -> <BIJO slot>, ... (one entry per GOSA slot)
gida: q3_1 -> <BIJO slot>, ..., q3_k -> <BIJO slot>
bofa: q3_1 -> <GUSI slot>, ... (one entry per BIJO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
