You are completing the design of a small book sorting row of carts with 4 carts.

The carts are: DULU, JOKO, JAKU, SIJO. Books move DULU -> JOKO -> JAKU -> SIJO.
There are 5 moving steps:
- "pupo" carries each DULU tray to a JOKO tray.
- "zato" is an internal rearrangement of JOKO: it carries each JOKO tray to a JOKO tray.
- "dati" carries each JOKO tray to a JAKU tray.
- "nodi" is an internal rearrangement of JAKU: it carries each JAKU tray to a JAKU tray.
- "pavo" carries each JAKU tray to a SIJO tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "pupo" and then "zato" lands on the same tray as running "pupo" alone.
     ("zato" leaves every tray that "pupo" produces unchanged.)
R1.2 Running "zato" and then "dati" gives the same result as running "dati" alone.
     ("dati" cannot tell whether "zato" was applied first.)
R1.3 Running "zato" three times in a row leaves every JOKO tray exactly where it started.
R2.1 Running "dati" and then "nodi" lands on the same tray as running "dati" alone.
     ("nodi" leaves every tray that "dati" produces unchanged.)
R2.2 Running "nodi" and then "pavo" gives the same result as running "pavo" alone.
     ("pavo" cannot tell whether "nodi" was applied first.)
R2.3 Running "nodi" twice in a row leaves every JAKU tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DULU has exactly one tray, called n1.
- SIJO has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (JOKO, JAKU):
D1.1 JOKO must be a finite set with at most 1 tray.
D1.2 List the "zato" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 JAKU must be a finite set with at most 1 tray.
D2.2 List the "nodi" table entries in tray order q2_1, q2_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

JOKO = {q1_1, ..., q1_k}
pupo: n1 -> <JOKO tray>
zato: q1_1 -> <JOKO tray>, ..., q1_k -> <JOKO tray>
JAKU = {q2_1, ..., q2_k}
dati: q1_1 -> <JAKU tray>, ... (one entry per JOKO tray)
nodi: q2_1 -> <JAKU tray>, ..., q2_k -> <JAKU tray>
pavo: q2_1 -> <SIJO tray>, ... (one entry per JAKU tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
