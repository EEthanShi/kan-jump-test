You are completing the design of a small toy sorting line with 4 stations.

The stations are: LODI, NATU, BUVI, RILO. Toys move LODI -> NATU -> BUVI -> RILO.
There are 5 moving steps:
- "muzo" carries each LODI slot to a NATU slot.
- "dova" is an internal reshuffle of NATU: it carries each NATU slot to a NATU slot.
- "kilu" carries each NATU slot to a BUVI slot.
- "fobi" is an internal reshuffle of BUVI: it carries each BUVI slot to a BUVI slot.
- "futu" carries each BUVI slot to a RILO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "muzo" and then "dova" lands on the same slot as running "muzo" alone.
     ("dova" leaves every slot that "muzo" produces unchanged.)
R1.2 Running "dova" and then "kilu" gives the same result as running "kilu" alone.
     ("kilu" cannot tell whether "dova" was applied first.)
R1.3 Running "dova" three times in a row leaves every NATU slot exactly where it started.
R2.1 Running "kilu" and then "fobi" lands on the same slot as running "kilu" alone.
     ("fobi" leaves every slot that "kilu" produces unchanged.)
R2.2 Running "fobi" and then "futu" gives the same result as running "futu" alone.
     ("futu" cannot tell whether "fobi" was applied first.)
R2.3 Running "fobi" three times in a row leaves every BUVI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LODI has exactly one slot, called n1.
- RILO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (NATU, BUVI):
D1.1 NATU must be a finite set with at most 1 slot.
D1.2 List the "dova" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 BUVI must be a finite set with at most 1 slot.
D2.2 List the "fobi" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

NATU = {q1_1, ..., q1_k}
muzo: n1 -> <NATU slot>
dova: q1_1 -> <NATU slot>, ..., q1_k -> <NATU slot>
BUVI = {q2_1, ..., q2_k}
kilu: q1_1 -> <BUVI slot>, ... (one entry per NATU slot)
fobi: q2_1 -> <BUVI slot>, ..., q2_k -> <BUVI slot>
futu: q2_1 -> <RILO slot>, ... (one entry per BUVI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
