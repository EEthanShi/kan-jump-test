You are completing the design of a small book sorting row of carts with 4 carts.

The carts are: SIZO, FANU, SUGO, PALI. Books move SIZO -> FANU -> SUGO -> PALI.
There are 5 moving steps:
- "loto" carries each SIZO tray to a FANU tray.
- "moju" is an internal rearrangement of FANU: it carries each FANU tray to a FANU tray.
- "fora" carries each FANU tray to a SUGO tray.
- "dinu" is an internal rearrangement of SUGO: it carries each SUGO tray to a SUGO tray.
- "dafu" carries each SUGO tray to a PALI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "loto" and then "moju" lands on the same tray as running "loto" alone.
     ("moju" leaves every tray that "loto" produces unchanged.)
R1.2 Running "moju" and then "fora" gives the same result as running "fora" alone.
     ("fora" cannot tell whether "moju" was applied first.)
R1.3 Running "moju" three times in a row leaves every FANU tray exactly where it started.
R2.1 Running "fora" and then "dinu" lands on the same tray as running "fora" alone.
     ("dinu" leaves every tray that "fora" produces unchanged.)
R2.2 Running "dinu" and then "dafu" gives the same result as running "dafu" alone.
     ("dafu" cannot tell whether "dinu" was applied first.)
R2.3 Running "dinu" three times in a row leaves every SUGO tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SIZO has exactly one tray, called n1.
- PALI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (FANU, SUGO):
D1.1 FANU must be a finite set with at most 1 tray.
D1.2 List the "moju" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 SUGO must be a finite set with at most 1 tray.
D2.2 List the "dinu" table entries in tray order q2_1, q2_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

FANU = {q1_1, ..., q1_k}
loto: n1 -> <FANU tray>
moju: q1_1 -> <FANU tray>, ..., q1_k -> <FANU tray>
SUGO = {q2_1, ..., q2_k}
fora: q1_1 -> <SUGO tray>, ... (one entry per FANU tray)
dinu: q2_1 -> <SUGO tray>, ..., q2_k -> <SUGO tray>
dafu: q2_1 -> <PALI tray>, ... (one entry per SUGO tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
