You are completing the design of a small toy sorting line with 3 stations.

The stations are: NAMI, GORI, SUTA. Toys move NAMI -> GORI -> SUTA.
There are 3 moving steps:
- "mafa" carries each NAMI slot to a GORI slot.
- "lodi" is an internal reshuffle of GORI: it carries each GORI slot to a GORI slot.
- "sifo" carries each GORI slot to a SUTA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "mafa" and then "lodi" lands on the same slot as running "mafa" alone.
     ("lodi" leaves every slot that "mafa" produces unchanged.)
R1.2 Running "lodi" and then "sifo" gives the same result as running "sifo" alone.
     ("sifo" cannot tell whether "lodi" was applied first.)
R1.3 Running "lodi" twice in a row leaves every GORI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NAMI has exactly 2 slots, called n1, n2.
- SUTA has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1.

Requirements for the middle station (GORI):
D1.1 GORI must be a finite set with at most 2 slots.
D1.2 List the "lodi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "mafa" must carry different NAMI slots to different GORI slots.
D1.4 List the "sifo" table entries in GORI slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

GORI = {q1_1, ..., q1_k}
mafa: n1 -> <GORI slot>, n2 -> <GORI slot>
lodi: q1_1 -> <GORI slot>, ..., q1_k -> <GORI slot>
sifo: q1_1 -> <SUTA slot>, ... (one entry per GORI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
