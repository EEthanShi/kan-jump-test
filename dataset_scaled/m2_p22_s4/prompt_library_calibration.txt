You are completing the design of a small book sorting row of carts with 4 carts.

The carts are: BAKA, LORI, GIJA, PAMU. Books move BAKA -> LORI -> GIJA -> PAMU.
There are 5 moving steps:
- "fugu" carries each BAKA tray to a LORI tray.
- "fubo" is an internal rearrangement of LORI: it carries each LORI tray to a LORI tray.
- "dipi" carries each LORI tray to a GIJA tray.
- "kipo" is an internal rearrangement of GIJA: it carries each GIJA tray to a GIJA tray.
- "jazo" carries each GIJA tray to a PAMU tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "fugu" and then "fubo" lands on the same tray as running "fugu" alone.
     ("fubo" leaves every tray that "fugu" produces unchanged.)
R1.2 Running "fubo" and then "dipi" gives the same result as running "dipi" alone.
     ("dipi" cannot tell whether "fubo" was applied first.)
R1.3 Running "fubo" twice in a row leaves every LORI tray exactly where it started.
R2.1 Running "dipi" and then "kipo" lands on the same tray as running "dipi" alone.
     ("kipo" leaves every tray that "dipi" produces unchanged.)
R2.2 Running "kipo" and then "jazo" gives the same result as running "jazo" alone.
     ("jazo" cannot tell whether "kipo" was applied first.)
R2.3 Running "kipo" twice in a row leaves every GIJA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- BAKA has exactly one tray, called n1.
- PAMU has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (LORI, GIJA):
D1.1 List the trays of LORI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "fubo" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 List the trays of GIJA in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "kipo" table entries in tray order q2_1, q2_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

LORI = {q1_1, ..., q1_k}
fugu: n1 -> <LORI tray>
fubo: q1_1 -> <LORI tray>, ..., q1_k -> <LORI tray>
GIJA = {q2_1, ..., q2_k}
dipi: q1_1 -> <GIJA tray>, ... (one entry per LORI tray)
kipo: q2_1 -> <GIJA tray>, ..., q2_k -> <GIJA tray>
jazo: q2_1 -> <PAMU tray>, ... (one entry per GIJA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
