You are completing the design of a small toy sorting line with 4 stations.

The stations are: ZABO, FORO, FIKA, LORU. Toys move ZABO -> FORO -> FIKA -> LORU.
There are 5 moving steps:
- "fili" carries each ZABO slot to a FORO slot.
- "jiva" is an internal reshuffle of FORO: it carries each FORO slot to a FORO slot.
- "jodo" carries each FORO slot to a FIKA slot.
- "juzi" is an internal reshuffle of FIKA: it carries each FIKA slot to a FIKA slot.
- "lodo" carries each FIKA slot to a LORU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "fili" and then "jiva" lands on the same slot as running "fili" alone.
     ("jiva" leaves every slot that "fili" produces unchanged.)
R1.2 Running "jiva" and then "jodo" gives the same result as running "jodo" alone.
     ("jodo" cannot tell whether "jiva" was applied first.)
R1.3 Running "jiva" twice in a row leaves every FORO slot exactly where it started.
R2.1 Running "jodo" and then "juzi" lands on the same slot as running "jodo" alone.
     ("juzi" leaves every slot that "jodo" produces unchanged.)
R2.2 Running "juzi" and then "lodo" gives the same result as running "lodo" alone.
     ("lodo" cannot tell whether "juzi" was applied first.)
R2.3 Running "juzi" three times in a row leaves every FIKA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ZABO has exactly one slot, called n1.
- LORU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FORO, FIKA):
D1.1 List the slots of FORO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "jiva" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of FIKA in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "juzi" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FORO = {q1_1, ..., q1_k}
fili: n1 -> <FORO slot>
jiva: q1_1 -> <FORO slot>, ..., q1_k -> <FORO slot>
FIKA = {q2_1, ..., q2_k}
jodo: q1_1 -> <FIKA slot>, ... (one entry per FORO slot)
juzi: q2_1 -> <FIKA slot>, ..., q2_k -> <FIKA slot>
lodo: q2_1 -> <LORU slot>, ... (one entry per FIKA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
