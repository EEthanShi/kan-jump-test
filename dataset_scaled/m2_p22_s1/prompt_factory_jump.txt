You are completing the design of a small toy sorting line with 4 stations.

The stations are: RUZA, KODU, VOKA, FOSO. Toys move RUZA -> KODU -> VOKA -> FOSO.
There are 5 moving steps:
- "toti" carries each RUZA slot to a KODU slot.
- "bota" is an internal reshuffle of KODU: it carries each KODU slot to a KODU slot.
- "vasu" carries each KODU slot to a VOKA slot.
- "tusa" is an internal reshuffle of VOKA: it carries each VOKA slot to a VOKA slot.
- "pogo" carries each VOKA slot to a FOSO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "toti" and then "bota" lands on the same slot as running "toti" alone.
     ("bota" leaves every slot that "toti" produces unchanged.)
R1.2 Running "bota" and then "vasu" gives the same result as running "vasu" alone.
     ("vasu" cannot tell whether "bota" was applied first.)
R1.3 Running "bota" twice in a row leaves every KODU slot exactly where it started.
R2.1 Running "vasu" and then "tusa" lands on the same slot as running "vasu" alone.
     ("tusa" leaves every slot that "vasu" produces unchanged.)
R2.2 Running "tusa" and then "pogo" gives the same result as running "pogo" alone.
     ("pogo" cannot tell whether "tusa" was applied first.)
R2.3 Running "tusa" twice in a row leaves every VOKA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUZA has exactly one slot, called n1.
- FOSO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KODU, VOKA):
D1.1 KODU must be a finite set with at most 3 slots.
D1.2 "bota" must NOT be the do-nothing move (it must move at least one KODU slot).
D2.1 VOKA must be a finite set with at most 3 slots.
D2.2 "tusa" must NOT be the do-nothing move (it must move at least one VOKA slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KODU = {q1_1, ..., q1_k}
toti: n1 -> <KODU slot>
bota: q1_1 -> <KODU slot>, ..., q1_k -> <KODU slot>
VOKA = {q2_1, ..., q2_k}
vasu: q1_1 -> <VOKA slot>, ... (one entry per KODU slot)
tusa: q2_1 -> <VOKA slot>, ..., q2_k -> <VOKA slot>
pogo: q2_1 -> <FOSO slot>, ... (one entry per VOKA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
