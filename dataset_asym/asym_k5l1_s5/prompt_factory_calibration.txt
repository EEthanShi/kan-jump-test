You are completing the design of a small toy sorting line with 3 stations.

The stations are: ROBO, LANO, DANO. Toys move ROBO -> LANO -> DANO.
There are 3 moving steps:
- "doro" carries each ROBO slot to a LANO slot.
- "vizi" is an internal reshuffle of LANO: it carries each LANO slot to a LANO slot.
- "bogu" carries each LANO slot to a DANO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "doro" and then "vizi" lands on the same slot as running "doro" alone.
     ("vizi" leaves every slot that "doro" produces unchanged.)
R1.2 Running "vizi" and then "bogu" gives the same result as running "bogu" alone.
     ("bogu" cannot tell whether "vizi" was applied first.)
R1.3 Running "vizi" twice in a row leaves every LANO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ROBO has exactly 5 slots, called n1, n2, n3, n4, n5.
- DANO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (LANO):
D1.1 List the slots of LANO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "vizi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "doro" table entries in ROBO slot order n1, n2, n3, n4, n5.
D1.4 List the "bogu" table entries in LANO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

LANO = {q1_1, ..., q1_k}
doro: n1 -> <LANO slot>, n2 -> <LANO slot>, n3 -> <LANO slot>, n4 -> <LANO slot>, n5 -> <LANO slot>
vizi: q1_1 -> <LANO slot>, ..., q1_k -> <LANO slot>
bogu: q1_1 -> <DANO slot>, ... (one entry per LANO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
