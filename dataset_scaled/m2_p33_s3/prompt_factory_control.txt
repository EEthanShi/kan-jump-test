You are completing the design of a small toy sorting line with 4 stations.

The stations are: PIJI, RINO, MUGA, PIRI. Toys move PIJI -> RINO -> MUGA -> PIRI.
There are 5 moving steps:
- "tava" carries each PIJI slot to a RINO slot.
- "guti" is an internal reshuffle of RINO: it carries each RINO slot to a RINO slot.
- "golu" carries each RINO slot to a MUGA slot.
- "giba" is an internal reshuffle of MUGA: it carries each MUGA slot to a MUGA slot.
- "bori" carries each MUGA slot to a PIRI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "tava" and then "guti" lands on the same slot as running "tava" alone.
     ("guti" leaves every slot that "tava" produces unchanged.)
R1.2 Running "guti" and then "golu" gives the same result as running "golu" alone.
     ("golu" cannot tell whether "guti" was applied first.)
R1.3 Running "guti" three times in a row leaves every RINO slot exactly where it started.
R2.1 Running "golu" and then "giba" lands on the same slot as running "golu" alone.
     ("giba" leaves every slot that "golu" produces unchanged.)
R2.2 Running "giba" and then "bori" gives the same result as running "bori" alone.
     ("bori" cannot tell whether "giba" was applied first.)
R2.3 Running "giba" three times in a row leaves every MUGA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PIJI has exactly one slot, called n1.
- PIRI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RINO, MUGA):
D1.1 RINO must be a finite set with at most 1 slot.
D1.2 List the "guti" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 MUGA must be a finite set with at most 1 slot.
D2.2 List the "giba" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RINO = {q1_1, ..., q1_k}
tava: n1 -> <RINO slot>
guti: q1_1 -> <RINO slot>, ..., q1_k -> <RINO slot>
MUGA = {q2_1, ..., q2_k}
golu: q1_1 -> <MUGA slot>, ... (one entry per RINO slot)
giba: q2_1 -> <MUGA slot>, ..., q2_k -> <MUGA slot>
bori: q2_1 -> <PIRI slot>, ... (one entry per MUGA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
