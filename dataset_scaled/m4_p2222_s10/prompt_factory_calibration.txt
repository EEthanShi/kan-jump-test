You are completing the design of a small toy sorting line with 6 stations.

The stations are: JINA, PUZU, GOMO, DOKA, POFA, LAKA. Toys move JINA -> PUZU -> GOMO -> DOKA -> POFA -> LAKA.
There are 9 moving steps:

- "kupo" is an internal reshuffle of PUZU: it carries each PUZU slot to a PUZU slot.
- "tora" carries each PUZU slot to a GOMO slot.
- "maza" is an internal reshuffle of GOMO: it carries each GOMO slot to a GOMO slot.
- "zoga" carries each GOMO slot to a DOKA slot.
- "toji" is an internal reshuffle of DOKA: it carries each DOKA slot to a DOKA slot.
- "koki" carries each DOKA slot to a POFA slot.
- "jafi" is an internal reshuffle of POFA: it carries each POFA slot to a POFA slot.
- "nofi" carries each POFA slot to a LAKA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "pufu" and then "kupo" lands on the same slot as running "pufu" alone.
     ("kupo" leaves every slot that "pufu" produces unchanged.)
R1.2 Running "kupo" and then "tora" gives the same result as running "tora" alone.
     ("tora" cannot tell whether "kupo" was applied first.)
R1.3 Running "kupo" twice in a row leaves every PUZU slot exactly where it started.
R2.1 Running "tora" and then "maza" lands on the same slot as running "tora" alone.
     ("maza" leaves every slot that "tora" produces unchanged.)
R2.2 Running "maza" and then "zoga" gives the same result as running "zoga" alone.
     ("zoga" cannot tell whether "maza" was applied first.)
R2.3 Running "maza" twice in a row leaves every GOMO slot exactly where it started.
R3.1 Running "zoga" and then "toji" lands on the same slot as running "zoga" alone.
     ("toji" leaves every slot that "zoga" produces unchanged.)
R3.2 Running "toji" and then "koki" gives the same result as running "koki" alone.
     ("koki" cannot tell whether "toji" was applied first.)
R3.3 Running "toji" twice in a row leaves every DOKA slot exactly where it started.
R4.1 Running "koki" and then "jafi" lands on the same slot as running "koki" alone.
     ("jafi" leaves every slot that "koki" produces unchanged.)
R4.2 Running "jafi" and then "nofi" gives the same result as running "nofi" alone.
     ("nofi" cannot tell whether "jafi" was applied first.)
