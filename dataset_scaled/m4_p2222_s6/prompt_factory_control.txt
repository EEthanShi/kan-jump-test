You are completing the design of a small toy sorting line with 6 stations.

The stations are: SANA, PIVI, ZORI, LIDU, ZIDO, PONO. Toys move SANA -> PIVI -> ZORI -> LIDU -> ZIDO -> PONO.
There are 9 moving steps:
- "damu" carries each SANA slot to a PIVI slot.
- "soku" is an internal reshuffle of PIVI: it carries each PIVI slot to a PIVI slot.
- "roju" carries each PIVI slot to a ZORI slot.
- "doda" is an internal reshuffle of ZORI: it carries each ZORI slot to a ZORI slot.
- "voro" carries each ZORI slot to a LIDU slot.
- "gofu" is an internal reshuffle of LIDU: it carries each LIDU slot to a LIDU slot.
- "suko" carries each LIDU slot to a ZIDO slot.
- "vuko" is an internal reshuffle of ZIDO: it carries each ZIDO slot to a ZIDO slot.
- "ropi" carries each ZIDO slot to a PONO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "damu" and then "soku" lands on the same slot as running "damu" alone.
     ("soku" leaves every slot that "damu" produces unchanged.)
R1.2 Running "soku" and then "roju" gives the same result as running "roju" alone.
     ("roju" cannot tell whether "soku" was applied first.)
R1.3 Running "soku" twice in a row leaves every PIVI slot exactly where it started.
R2.1 Running "roju" and then "doda" lands on the same slot as running "roju" alone.
     ("doda" leaves every slot that "roju" produces unchanged.)
R2.2 Running "doda" and then "voro" gives the same result as running "voro" alone.
     ("voro" cannot tell whether "doda" was applied first.)
R2.3 Running "doda" twice in a row leaves every ZORI slot exactly where it started.
R3.1 Running "voro" and then "gofu" lands on the same slot as running "voro" alone.
     ("gofu" leaves every slot that "voro" produces unchanged.)
R3.2 Running "gofu" and then "suko" gives the same result as running "suko" alone.
     ("suko" cannot tell whether "gofu" was applied first.)
R3.3 Running "gofu" twice in a row leaves every LIDU slot exactly where it started.
R4.1 Running "suko" and then "vuko" lands on the same slot as running "suko" alone.
     ("vuko" leaves every slot that "suko" produces unchanged.)
R4.2 Running "vuko" and then "ropi" gives the same result as running "ropi" alone.
     ("ropi" cannot tell whether "vuko" was applied first.)
R4.3 Running "vuko" twice in a row leaves every ZIDO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SANA has exactly one slot, called n1.
- PONO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PIVI, ZORI, LIDU, ZIDO):
D1.1 PIVI must be a finite set with at most 1 slot.
D1.2 List the "soku" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 ZORI must be a finite set with at most 1 slot.
D2.2 List the "doda" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 LIDU must be a finite set with at most 1 slot.
D3.2 List the "gofu" table entries in slot order q3_1, q3_2, ..., one entry per slot.
D4.1 ZIDO must be a finite set with at most 1 slot.
D4.2 List the "vuko" table entries in slot order q4_1, q4_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PIVI = {q1_1, ..., q1_k}
damu: n1 -> <PIVI slot>
soku: q1_1 -> <PIVI slot>, ..., q1_k -> <PIVI slot>
ZORI = {q2_1, ..., q2_k}
roju: q1_1 -> <ZORI slot>, ... (one entry per PIVI slot)
doda: q2_1 -> <ZORI slot>, ..., q2_k -> <ZORI slot>
LIDU = {q3_1, ..., q3_k}
voro: q2_1 -> <LIDU slot>, ... (one entry per ZORI slot)

ZIDO = {q4_1, ..., q4_k}
