You are completing the design of a small toy sorting line with 4 stations.

The stations are: NARU, KANI, KADU, ZIFI. Toys move NARU -> KANI -> KADU -> ZIFI.
There are 5 moving steps:
- "jora" carries each NARU slot to a KANI slot.
- "zofi" is an internal reshuffle of KANI: it carries each KANI slot to a KANI slot.
- "babo" carries each KANI slot to a KADU slot.
- "nufo" is an internal reshuffle of KADU: it carries each KADU slot to a KADU slot.
- "dizu" carries each KADU slot to a ZIFI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jora" and then "zofi" lands on the same slot as running "jora" alone.
     ("zofi" leaves every slot that "jora" produces unchanged.)
R1.2 Running "zofi" and then "babo" gives the same result as running "babo" alone.
     ("babo" cannot tell whether "zofi" was applied first.)
R1.3 Running "zofi" three times in a row leaves every KANI slot exactly where it started.
R2.1 Running "babo" and then "nufo" lands on the same slot as running "babo" alone.
     ("nufo" leaves every slot that "babo" produces unchanged.)
R2.2 Running "nufo" and then "dizu" gives the same result as running "dizu" alone.
     ("dizu" cannot tell whether "nufo" was applied first.)
R2.3 Running "nufo" twice in a row leaves every KADU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NARU has exactly one slot, called n1.
- ZIFI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KANI, KADU):
D1.1 KANI must be a finite set with at most 1 slot.
D1.2 List the "zofi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 KADU must be a finite set with at most 1 slot.
D2.2 List the "nufo" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KANI = {q1_1, ..., q1_k}
jora: n1 -> <KANI slot>
zofi: q1_1 -> <KANI slot>, ..., q1_k -> <KANI slot>
KADU = {q2_1, ..., q2_k}
babo: q1_1 -> <KADU slot>, ... (one entry per KANI slot)
nufo: q2_1 -> <KADU slot>, ..., q2_k -> <KADU slot>
dizu: q2_1 -> <ZIFI slot>, ... (one entry per KADU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
