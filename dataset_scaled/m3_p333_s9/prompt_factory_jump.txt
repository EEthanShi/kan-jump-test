You are completing the design of a small toy sorting line with 5 stations.

The stations are: LAFI, GOZO, PAVO, PADU, MUPI. Toys move LAFI -> GOZO -> PAVO -> PADU -> MUPI.
There are 7 moving steps:
- "difa" carries each LAFI slot to a GOZO slot.
- "gisa" is an internal reshuffle of GOZO: it carries each GOZO slot to a GOZO slot.
- "libi" carries each GOZO slot to a PAVO slot.
- "baku" is an internal reshuffle of PAVO: it carries each PAVO slot to a PAVO slot.
- "ziki" carries each PAVO slot to a PADU slot.
- "guli" is an internal reshuffle of PADU: it carries each PADU slot to a PADU slot.
- "giri" carries each PADU slot to a MUPI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "difa" and then "gisa" lands on the same slot as running "difa" alone.
     ("gisa" leaves every slot that "difa" produces unchanged.)
R1.2 Running "gisa" and then "libi" gives the same result as running "libi" alone.
     ("libi" cannot tell whether "gisa" was applied first.)
R1.3 Running "gisa" three times in a row leaves every GOZO slot exactly where it started.
R2.1 Running "libi" and then "baku" lands on the same slot as running "libi" alone.
     ("baku" leaves every slot that "libi" produces unchanged.)
R2.2 Running "baku" and then "ziki" gives the same result as running "ziki" alone.
     ("ziki" cannot tell whether "baku" was applied first.)
R2.3 Running "baku" three times in a row leaves every PAVO slot exactly where it started.
R3.1 Running "ziki" and then "guli" lands on the same slot as running "ziki" alone.
     ("guli" leaves every slot that "ziki" produces unchanged.)
R3.2 Running "guli" and then "giri" gives the same result as running "giri" alone.
     ("giri" cannot tell whether "guli" was applied first.)
R3.3 Running "guli" three times in a row leaves every PADU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LAFI has exactly one slot, called n1.
- MUPI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (GOZO, PAVO, PADU):
D1.1 GOZO must be a finite set with at most 4 slots.
D1.2 "gisa" must NOT be the do-nothing move (it must move at least one GOZO slot).
D2.1 PAVO must be a finite set with at most 4 slots.
D2.2 "baku" must NOT be the do-nothing move (it must move at least one PAVO slot).
D3.1 PADU must be a finite set with at most 4 slots.
D3.2 "guli" must NOT be the do-nothing move (it must move at least one PADU slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

GOZO = {q1_1, ..., q1_k}
difa: n1 -> <GOZO slot>
gisa: q1_1 -> <GOZO slot>, ..., q1_k -> <GOZO slot>
PAVO = {q2_1, ..., q2_k}
libi: q1_1 -> <PAVO slot>, ... (one entry per GOZO slot)
baku: q2_1 -> <PAVO slot>, ..., q2_k -> <PAVO slot>
PADU = {q3_1, ..., q3_k}
ziki: q2_1 -> <PADU slot>, ... (one entry per PAVO slot)
guli: q3_1 -> <PADU slot>, ..., q3_k -> <PADU slot>
giri: q3_1 -> <MUPI slot>, ... (one entry per PADU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
