You are completing the design of a small toy sorting line with 4 stations.

The stations are: RUZA, TARA, MUGO, VUFO. Toys move RUZA -> TARA -> MUGO -> VUFO.
There are 5 moving steps:
- "bitu" carries each RUZA slot to a TARA slot.
- "suju" is an internal reshuffle of TARA: it carries each TARA slot to a TARA slot.
- "mofa" carries each TARA slot to a MUGO slot.
- "muja" is an internal reshuffle of MUGO: it carries each MUGO slot to a MUGO slot.
- "dulo" carries each MUGO slot to a VUFO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bitu" and then "suju" lands on the same slot as running "bitu" alone.
     ("suju" leaves every slot that "bitu" produces unchanged.)
R1.2 Running "suju" and then "mofa" gives the same result as running "mofa" alone.
     ("mofa" cannot tell whether "suju" was applied first.)
R1.3 Running "suju" three times in a row leaves every TARA slot exactly where it started.
R2.1 Running "mofa" and then "muja" lands on the same slot as running "mofa" alone.
     ("muja" leaves every slot that "mofa" produces unchanged.)
R2.2 Running "muja" and then "dulo" gives the same result as running "dulo" alone.
     ("dulo" cannot tell whether "muja" was applied first.)
R2.3 Running "muja" three times in a row leaves every MUGO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUZA has exactly one slot, called n1.
- VUFO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (TARA, MUGO):
D1.1 TARA must be a finite set with at most 1 slot.
D1.2 List the "suju" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 MUGO must be a finite set with at most 1 slot.
D2.2 List the "muja" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

TARA = {q1_1, ..., q1_k}
bitu: n1 -> <TARA slot>
suju: q1_1 -> <TARA slot>, ..., q1_k -> <TARA slot>
MUGO = {q2_1, ..., q2_k}
mofa: q1_1 -> <MUGO slot>, ... (one entry per TARA slot)
muja: q2_1 -> <MUGO slot>, ..., q2_k -> <MUGO slot>
dulo: q2_1 -> <VUFO slot>, ... (one entry per MUGO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
