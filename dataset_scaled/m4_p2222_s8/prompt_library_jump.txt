You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: JAGA, DITO, KIJA, FIZO, GUMO, BILI. Books move JAGA -> DITO -> KIJA -> FIZO -> GUMO -> BILI.
There are 9 moving steps:
- "sado" carries each JAGA tray to a DITO tray.
- "kifo" is an internal rearrangement of DITO: it carries each DITO tray to a DITO tray.
- "fobo" carries each DITO tray to a KIJA tray.
- "zuro" is an internal rearrangement of KIJA: it carries each KIJA tray to a KIJA tray.
- "tabu" carries each KIJA tray to a FIZO tray.
- "fisa" is an internal rearrangement of FIZO: it carries each FIZO tray to a FIZO tray.
- "tidu" carries each FIZO tray to a GUMO tray.
- "fiba" is an internal rearrangement of GUMO: it carries each GUMO tray to a GUMO tray.
- "kova" carries each GUMO tray to a BILI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "sado" and then "kifo" lands on the same tray as running "sado" alone.
     ("kifo" leaves every tray that "sado" produces unchanged.)
R1.2 Running "kifo" and then "fobo" gives the same result as running "fobo" alone.
     ("fobo" cannot tell whether "kifo" was applied first.)
R1.3 Running "kifo" twice in a row leaves every DITO tray exactly where it started.
R2.1 Running "fobo" and then "zuro" lands on the same tray as running "fobo" alone.
     ("zuro" leaves every tray that "fobo" produces unchanged.)
R2.2 Running "zuro" and then "tabu" gives the same result as running "tabu" alone.
     ("tabu" cannot tell whether "zuro" was applied first.)
R2.3 Running "zuro" twice in a row leaves every KIJA tray exactly where it started.
R3.1 Running "tabu" and then "fisa" lands on the same tray as running "tabu" alone.
     ("fisa" leaves every tray that "tabu" produces unchanged.)
R3.2 Running "fisa" and then "tidu" gives the same result as running "tidu" alone.
     ("tidu" cannot tell whether "fisa" was applied first.)
R3.3 Running "fisa" twice in a row leaves every FIZO tray exactly where it started.
R4.1 Running "tidu" and then "fiba" lands on the same tray as running "tidu" alone.
     ("fiba" leaves every tray that "tidu" produces unchanged.)
R4.2 Running "fiba" and then "kova" gives the same result as running "kova" alone.
     ("kova" cannot tell whether "fiba" was applied first.)
R4.3 Running "fiba" twice in a row leaves every GUMO tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JAGA has exactly one tray, called n1.
- BILI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (DITO, KIJA, FIZO, GUMO):
D1.1 DITO must be a finite set with at most 3 trays.
D1.2 "kifo" must NOT be the do-nothing move (it must move at least one DITO tray).
D2.1 KIJA must be a finite set with at most 3 trays.
D2.2 "zuro" must NOT be the do-nothing move (it must move at least one KIJA tray).
D3.1 FIZO must be a finite set with at most 3 trays.
D3.2 "fisa" must NOT be the do-nothing move (it must move at least one FIZO tray).
D4.1 GUMO must be a finite set with at most 3 trays.
D4.2 "fiba" must NOT be the do-nothing move (it must move at least one GUMO tray).

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):
