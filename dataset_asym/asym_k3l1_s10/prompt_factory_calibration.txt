You are completing the design of a small toy sorting line with 3 stations.

The stations are: MUTI, NIKI, NOSO. Toys move MUTI -> NIKI -> NOSO.
There are 3 moving steps:
- "doti" carries each MUTI slot to a NIKI slot.
- "zugu" is an internal reshuffle of NIKI: it carries each NIKI slot to a NIKI slot.
- "mugi" carries each NIKI slot to a NOSO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "doti" and then "zugu" lands on the same slot as running "doti" alone.
     ("zugu" leaves every slot that "doti" produces unchanged.)
R1.2 Running "zugu" and then "mugi" gives the same result as running "mugi" alone.
     ("mugi" cannot tell whether "zugu" was applied first.)
R1.3 Running "zugu" twice in a row leaves every NIKI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- MUTI has exactly 3 slots, called n1, n2, n3.
- NOSO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (NIKI):
D1.1 List the slots of NIKI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "zugu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "doti" table entries in MUTI slot order n1, n2, n3.
D1.4 List the "mugi" table entries in NIKI slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

NIKI = {q1_1, ..., q1_k}
doti: n1 -> <NIKI slot>, n2 -> <NIKI slot>, n3 -> <NIKI slot>
zugu: q1_1 -> <NIKI slot>, ..., q1_k -> <NIKI slot>
mugi: q1_1 -> <NOSO slot>, ... (one entry per NIKI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
