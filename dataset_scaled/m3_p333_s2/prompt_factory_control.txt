You are completing the design of a small toy sorting line with 5 stations.

The stations are: VIJA, RIDO, BILO, JUNA, KAGA. Toys move VIJA -> RIDO -> BILO -> JUNA -> KAGA.
There are 7 moving steps:
- "vaka" carries each VIJA slot to a RIDO slot.
- "zovo" is an internal reshuffle of RIDO: it carries each RIDO slot to a RIDO slot.
- "tika" carries each RIDO slot to a BILO slot.
- "godi" is an internal reshuffle of BILO: it carries each BILO slot to a BILO slot.
- "faja" carries each BILO slot to a JUNA slot.
- "loso" is an internal reshuffle of JUNA: it carries each JUNA slot to a JUNA slot.
- "ziti" carries each JUNA slot to a KAGA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vaka" and then "zovo" lands on the same slot as running "vaka" alone.
     ("zovo" leaves every slot that "vaka" produces unchanged.)
R1.2 Running "zovo" and then "tika" gives the same result as running "tika" alone.
     ("tika" cannot tell whether "zovo" was applied first.)
R1.3 Running "zovo" three times in a row leaves every RIDO slot exactly where it started.
R2.1 Running "tika" and then "godi" lands on the same slot as running "tika" alone.
     ("godi" leaves every slot that "tika" produces unchanged.)
R2.2 Running "godi" and then "faja" gives the same result as running "faja" alone.
     ("faja" cannot tell whether "godi" was applied first.)
R2.3 Running "godi" three times in a row leaves every BILO slot exactly where it started.
R3.1 Running "faja" and then "loso" lands on the same slot as running "faja" alone.
     ("loso" leaves every slot that "faja" produces unchanged.)
R3.2 Running "loso" and then "ziti" gives the same result as running "ziti" alone.
     ("ziti" cannot tell whether "loso" was applied first.)
R3.3 Running "loso" three times in a row leaves every JUNA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VIJA has exactly one slot, called n1.
- KAGA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RIDO, BILO, JUNA):
D1.1 RIDO must be a finite set with at most 1 slot.
D1.2 List the "zovo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 BILO must be a finite set with at most 1 slot.
D2.2 List the "godi" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 JUNA must be a finite set with at most 1 slot.
D3.2 List the "loso" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RIDO = {q1_1, ..., q1_k}
vaka: n1 -> <RIDO slot>
zovo: q1_1 -> <RIDO slot>, ..., q1_k -> <RIDO slot>
BILO = {q2_1, ..., q2_k}
tika: q1_1 -> <BILO slot>, ... (one entry per RIDO slot)
godi: q2_1 -> <BILO slot>, ..., q2_k -> <BILO slot>
JUNA = {q3_1, ..., q3_k}
faja: q2_1 -> <JUNA slot>, ... (one entry per BILO slot)
loso: q3_1 -> <JUNA slot>, ..., q3_k -> <JUNA slot>
ziti: q3_1 -> <KAGA slot>, ... (one entry per JUNA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
