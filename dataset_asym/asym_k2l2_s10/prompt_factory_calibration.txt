You are completing the design of a small toy sorting line with 3 stations.

The stations are: PAKI, DUFU, VIZI. Toys move PAKI -> DUFU -> VIZI.
There are 3 moving steps:
- "vuli" carries each PAKI slot to a DUFU slot.
- "sini" is an internal reshuffle of DUFU: it carries each DUFU slot to a DUFU slot.
- "tabu" carries each DUFU slot to a VIZI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vuli" and then "sini" lands on the same slot as running "vuli" alone.
     ("sini" leaves every slot that "vuli" produces unchanged.)
R1.2 Running "sini" and then "tabu" gives the same result as running "tabu" alone.
     ("tabu" cannot tell whether "sini" was applied first.)
R1.3 Running "sini" twice in a row leaves every DUFU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PAKI has exactly 2 slots, called n1, n2.
- VIZI has exactly 2 slots, called s1, s2.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1.

Requirements for the middle station (DUFU):
D1.1 List the slots of DUFU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "sini" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "vuli" table entries in PAKI slot order n1, n2.
D1.4 List the "tabu" table entries in DUFU slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

DUFU = {q1_1, ..., q1_k}
vuli: n1 -> <DUFU slot>, n2 -> <DUFU slot>
sini: q1_1 -> <DUFU slot>, ..., q1_k -> <DUFU slot>
tabu: q1_1 -> <VIZI slot>, ... (one entry per DUFU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
