You are completing the design of a small toy sorting line with 3 stations.

The stations are: SUJI, FORO, SIJO. Toys move SUJI -> FORO -> SIJO.
There are 3 moving steps:
- "kuki" carries each SUJI slot to a FORO slot.
- "duki" is an internal reshuffle of FORO: it carries each FORO slot to a FORO slot.
- "solu" carries each FORO slot to a SIJO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "kuki" and then "duki" lands on the same slot as running "kuki" alone.
     ("duki" leaves every slot that "kuki" produces unchanged.)
R1.2 Running "duki" and then "solu" gives the same result as running "solu" alone.
     ("solu" cannot tell whether "duki" was applied first.)
R1.3 Running "duki" twice in a row leaves every FORO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SUJI has exactly 5 slots, called n1, n2, n3, n4, n5.
- SIJO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (FORO):
D1.1 FORO must be a finite set with at most 5 slots.
D1.2 List the "duki" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "kuki" must carry different SUJI slots to different FORO slots.
D1.4 List the "solu" table entries in FORO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

FORO = {q1_1, ..., q1_k}
kuki: n1 -> <FORO slot>, n2 -> <FORO slot>, n3 -> <FORO slot>, n4 -> <FORO slot>, n5 -> <FORO slot>
duki: q1_1 -> <FORO slot>, ..., q1_k -> <FORO slot>
solu: q1_1 -> <SIJO slot>, ... (one entry per FORO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
