You are completing the design of a small toy sorting line with 5 stations.

The stations are: NASA, GUZI, VUMO, NUFO, SAKU. Toys move NASA -> GUZI -> VUMO -> NUFO -> SAKU.
There are 7 moving steps:
- "tura" carries each NASA slot to a GUZI slot.
- "dova" is an internal reshuffle of GUZI: it carries each GUZI slot to a GUZI slot.
- "luti" carries each GUZI slot to a VUMO slot.
- "nogi" is an internal reshuffle of VUMO: it carries each VUMO slot to a VUMO slot.
- "runo" carries each VUMO slot to a NUFO slot.
- "tagu" is an internal reshuffle of NUFO: it carries each NUFO slot to a NUFO slot.
- "bizu" carries each NUFO slot to a SAKU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "tura" and then "dova" lands on the same slot as running "tura" alone.
     ("dova" leaves every slot that "tura" produces unchanged.)
R1.2 Running "dova" and then "luti" gives the same result as running "luti" alone.
     ("luti" cannot tell whether "dova" was applied first.)
R1.3 Running "dova" twice in a row leaves every GUZI slot exactly where it started.
R2.1 Running "luti" and then "nogi" lands on the same slot as running "luti" alone.
     ("nogi" leaves every slot that "luti" produces unchanged.)
R2.2 Running "nogi" and then "runo" gives the same result as running "runo" alone.
     ("runo" cannot tell whether "nogi" was applied first.)
R2.3 Running "nogi" three times in a row leaves every VUMO slot exactly where it started.
R3.1 Running "runo" and then "tagu" lands on the same slot as running "runo" alone.
     ("tagu" leaves every slot that "runo" produces unchanged.)
R3.2 Running "tagu" and then "bizu" gives the same result as running "bizu" alone.
     ("bizu" cannot tell whether "tagu" was applied first.)
R3.3 Running "tagu" three times in a row leaves every NUFO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NASA has exactly one slot, called n1.
- SAKU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (GUZI, VUMO, NUFO):
D1.1 GUZI must be a finite set with at most 3 slots.
D1.2 "dova" must NOT be the do-nothing move (it must move at least one GUZI slot).
D2.1 VUMO must be a finite set with at most 4 slots.
D2.2 "nogi" must NOT be the do-nothing move (it must move at least one VUMO slot).
D3.1 NUFO must be a finite set with at most 4 slots.
D3.2 "tagu" must NOT be the do-nothing move (it must move at least one NUFO slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

GUZI = {q1_1, ..., q1_k}
tura: n1 -> <GUZI slot>
dova: q1_1 -> <GUZI slot>, ..., q1_k -> <GUZI slot>
VUMO = {q2_1, ..., q2_k}
luti: q1_1 -> <VUMO slot>, ... (one entry per GUZI slot)
nogi: q2_1 -> <VUMO slot>, ..., q2_k -> <VUMO slot>
NUFO = {q3_1, ..., q3_k}
runo: q2_1 -> <NUFO slot>, ... (one entry per VUMO slot)
tagu: q3_1 -> <NUFO slot>, ..., q3_k -> <NUFO slot>
bizu: q3_1 -> <SAKU slot>, ... (one entry per NUFO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
