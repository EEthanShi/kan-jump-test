You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: KIJI, KIVO, LALU, GUJA, BINO, KILI. Books move KIJI -> KIVO -> LALU -> GUJA -> BINO -> KILI.
There are 9 moving steps:
- "zovu" carries each KIJI tray to a KIVO tray.
- "zoma" is an internal rearrangement of KIVO: it carries each KIVO tray to a KIVO tray.
- "gizu" carries each KIVO tray to a LALU tray.
- "suso" is an internal rearrangement of LALU: it carries each LALU tray to a LALU tray.
- "ropo" carries each LALU tray to a GUJA tray.
- "nimo" is an internal rearrangement of GUJA: it carries each GUJA tray to a GUJA tray.
- "mamo" carries each GUJA tray to a BINO tray.
- "momu" is an internal rearrangement of BINO: it carries each BINO tray to a BINO tray.
- "nuju" carries each BINO tray to a KILI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "zovu" and then "zoma" lands on the same tray as running "zovu" alone.
     ("zoma" leaves every tray that "zovu" produces unchanged.)
R1.2 Running "zoma" and then "gizu" gives the same result as running "gizu" alone.
     ("gizu" cannot tell whether "zoma" was applied first.)
R1.3 Running "zoma" twice in a row leaves every KIVO tray exactly where it started.
R2.1 Running "gizu" and then "suso" lands on the same tray as running "gizu" alone.
     ("suso" leaves every tray that "gizu" produces unchanged.)
R2.2 Running "suso" and then "ropo" gives the same result as running "ropo" alone.
     ("ropo" cannot tell whether "suso" was applied first.)
R2.3 Running "suso" twice in a row leaves every LALU tray exactly where it started.
R3.1 Running "ropo" and then "nimo" lands on the same tray as running "ropo" alone.
     ("nimo" leaves every tray that "ropo" produces unchanged.)
R3.2 Running "nimo" and then "mamo" gives the same result as running "mamo" alone.
     ("mamo" cannot tell whether "nimo" was applied first.)
R3.3 Running "nimo" twice in a row leaves every GUJA tray exactly where it started.
R4.1 Running "mamo" and then "momu" lands on the same tray as running "mamo" alone.
     ("momu" leaves every tray that "mamo" produces unchanged.)
R4.2 Running "momu" and then "nuju" gives the same result as running "nuju" alone.
     ("nuju" cannot tell whether "momu" was applied first.)
R4.3 Running "momu" twice in a row leaves every BINO tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KIJI has exactly one tray, called n1.
- KILI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (KIVO, LALU, GUJA, BINO):
D1.1 KIVO must be a finite set with at most 1 tray.
D1.2 List the "zoma" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 LALU must be a finite set with at most 1 tray.
D2.2 List the "suso" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 GUJA must be a finite set with at most 1 tray.
D3.2 List the "nimo" table entries in tray order q3_1, q3_2, ..., one entry per tray.
D4.1 BINO must be a finite set with at most 1 tray.
D4.2 List the "momu" table entries in tray order q4_1, q4_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):
