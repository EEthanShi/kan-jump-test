You are completing the design of a small toy sorting line with 6 stations.

The stations are: SURU, ZOFO, KOPU, TONI, BISA, DUSA. Toys move SURU -> ZOFO -> KOPU -> TONI -> BISA -> DUSA.
There are 9 moving steps:
- "sutu" carries each SURU slot to a ZOFO slot.
- "fufa" is an internal reshuffle of ZOFO: it carries each ZOFO slot to a ZOFO slot.
- "bufa" carries each ZOFO slot to a KOPU slot.
- "vuso" is an internal reshuffle of KOPU: it carries each KOPU slot to a KOPU slot.
- "mufa" carries each KOPU slot to a TONI slot.
- "bapo" is an internal reshuffle of TONI: it carries each TONI slot to a TONI slot.
- "mofi" carries each TONI slot to a BISA slot.
- "nodu" is an internal reshuffle of BISA: it carries each BISA slot to a BISA slot.
- "mino" carries each BISA slot to a DUSA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sutu" and then "fufa" lands on the same slot as running "sutu" alone.
     ("fufa" leaves every slot that "sutu" produces unchanged.)
R1.2 Running "fufa" and then "bufa" gives the same result as running "bufa" alone.
     ("bufa" cannot tell whether "fufa" was applied first.)
R1.3 Running "fufa" twice in a row leaves every ZOFO slot exactly where it started.
R2.1 Running "bufa" and then "vuso" lands on the same slot as running "bufa" alone.
     ("vuso" leaves every slot that "bufa" produces unchanged.)
R2.2 Running "vuso" and then "mufa" gives the same result as running "mufa" alone.
     ("mufa" cannot tell whether "vuso" was applied first.)
R2.3 Running "vuso" three times in a row leaves every KOPU slot exactly where it started.
R3.1 Running "mufa" and then "bapo" lands on the same slot as running "mufa" alone.
     ("bapo" leaves every slot that "mufa" produces unchanged.)
R3.2 Running "bapo" and then "mofi" gives the same result as running "mofi" alone.
     ("mofi" cannot tell whether "bapo" was applied first.)
R3.3 Running "bapo" twice in a row leaves every TONI slot exactly where it started.
R4.1 Running "mofi" and then "nodu" lands on the same slot as running "mofi" alone.
     ("nodu" leaves every slot that "mofi" produces unchanged.)
R4.2 Running "nodu" and then "mino" gives the same result as running "mino" alone.
     ("mino" cannot tell whether "nodu" was applied first.)
R4.3 Running "nodu" three times in a row leaves every BISA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SURU has exactly one slot, called n1.
- DUSA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (ZOFO, KOPU, TONI, BISA):
D1.1 ZOFO must be a finite set with at most 3 slots.
D1.2 "fufa" must NOT be the do-nothing move (it must move at least one ZOFO slot).
D2.1 KOPU must be a finite set with at most 4 slots.
D2.2 "vuso" must NOT be the do-nothing move (it must move at least one KOPU slot).
D3.1 TONI must be a finite set with at most 3 slots.
D3.2 "bapo" must NOT be the do-nothing move (it must move at least one TONI slot).
D4.1 BISA must be a finite set with at most 4 slots.
D4.2 "nodu" must NOT be the do-nothing move (it must move at least one BISA slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ZOFO = {q1_1, ..., q1_k}
sutu: n1 -> <ZOFO slot>
fufa: q1_1 -> <ZOFO slot>, ..., q1_k -> <ZOFO slot>
KOPU = {q2_1, ..., q2_k}
bufa: q1_1 -> <KOPU slot>, ... (one entry per ZOFO slot)
vuso: q2_1 -> <KOPU slot>, ..., q2_k -> <KOPU slot>
TONI = {q3_1, ..., q3_k}
mufa: q2_1 -> <TONI slot>, ... (one entry per KOPU slot)
bapo: q3_1 -> <TONI slot>, ..., q3_k -> <TONI slot>
BISA = {q4_1, ..., q4_k}
mofi: q3_1 -> <BISA slot>, ... (one entry per TONI slot)
nodu: q4_1 -> <BISA slot>, ..., q4_k -> <BISA slot>
mino: q4_1 -> <DUSA slot>, ... (one entry per BISA slot)

Every rule and requirement above must hold exactly for your tables. Do not
