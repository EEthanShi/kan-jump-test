You are completing the design of a small toy sorting line with 6 stations.

The stations are: DOFI, ZALA, GUGI, TABO, BIPI, BULI. Toys move DOFI -> ZALA -> GUGI -> TABO -> BIPI -> BULI.
There are 9 moving steps:
- "gazi" carries each DOFI slot to a ZALA slot.
- "kujo" is an internal reshuffle of ZALA: it carries each ZALA slot to a ZALA slot.
- "para" carries each ZALA slot to a GUGI slot.
- "tugo" is an internal reshuffle of GUGI: it carries each GUGI slot to a GUGI slot.
- "dona" carries each GUGI slot to a TABO slot.
- "pafa" is an internal reshuffle of TABO: it carries each TABO slot to a TABO slot.
- "zura" carries each TABO slot to a BIPI slot.
- "daza" is an internal reshuffle of BIPI: it carries each BIPI slot to a BIPI slot.
- "lafi" carries each BIPI slot to a BULI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "gazi" and then "kujo" lands on the same slot as running "gazi" alone.
     ("kujo" leaves every slot that "gazi" produces unchanged.)
R1.2 Running "kujo" and then "para" gives the same result as running "para" alone.
     ("para" cannot tell whether "kujo" was applied first.)
R1.3 Running "kujo" three times in a row leaves every ZALA slot exactly where it started.
R2.1 Running "para" and then "tugo" lands on the same slot as running "para" alone.
     ("tugo" leaves every slot that "para" produces unchanged.)
R2.2 Running "tugo" and then "dona" gives the same result as running "dona" alone.
     ("dona" cannot tell whether "tugo" was applied first.)
R2.3 Running "tugo" three times in a row leaves every GUGI slot exactly where it started.
R3.1 Running "dona" and then "pafa" lands on the same slot as running "dona" alone.
     ("pafa" leaves every slot that "dona" produces unchanged.)
R3.2 Running "pafa" and then "zura" gives the same result as running "zura" alone.
     ("zura" cannot tell whether "pafa" was applied first.)
R3.3 Running "pafa" three times in a row leaves every TABO slot exactly where it started.
R4.1 Running "zura" and then "daza" lands on the same slot as running "zura" alone.
     ("daza" leaves every slot that "zura" produces unchanged.)
R4.2 Running "daza" and then "lafi" gives the same result as running "lafi" alone.
     ("lafi" cannot tell whether "daza" was applied first.)
