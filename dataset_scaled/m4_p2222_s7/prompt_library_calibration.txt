You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: FUPA, NUDU, LOJU, MIPI, MUZA, FIZA. Books move FUPA -> NUDU -> LOJU -> MIPI -> MUZA -> FIZA.
There are 9 moving steps:
- "rugu" carries each FUPA tray to a NUDU tray.
- "lalo" is an internal rearrangement of NUDU: it carries each NUDU tray to a NUDU tray.
- "rozi" carries each NUDU tray to a LOJU tray.
- "sado" is an internal rearrangement of LOJU: it carries each LOJU tray to a LOJU tray.
- "tidu" carries each LOJU tray to a MIPI tray.
- "gimu" is an internal rearrangement of MIPI: it carries each MIPI tray to a MIPI tray.
- "nuzi" carries each MIPI tray to a MUZA tray.
- "buvu" is an internal rearrangement of MUZA: it carries each MUZA tray to a MUZA tray.
- "zoga" carries each MUZA tray to a FIZA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "rugu" and then "lalo" lands on the same tray as running "rugu" alone.
     ("lalo" leaves every tray that "rugu" produces unchanged.)
R1.2 Running "lalo" and then "rozi" gives the same result as running "rozi" alone.
     ("rozi" cannot tell whether "lalo" was applied first.)
R1.3 Running "lalo" twice in a row leaves every NUDU tray exactly where it started.
R2.1 Running "rozi" and then "sado" lands on the same tray as running "rozi" alone.
     ("sado" leaves every tray that "rozi" produces unchanged.)
R2.2 Running "sado" and then "tidu" gives the same result as running "tidu" alone.
     ("tidu" cannot tell whether "sado" was applied first.)
R2.3 Running "sado" twice in a row leaves every LOJU tray exactly where it started.
R3.1 Running "tidu" and then "gimu" lands on the same tray as running "tidu" alone.
     ("gimu" leaves every tray that "tidu" produces unchanged.)
R3.2 Running "gimu" and then "nuzi" gives the same result as running "nuzi" alone.
     ("nuzi" cannot tell whether "gimu" was applied first.)
R3.3 Running "gimu" twice in a row leaves every MIPI tray exactly where it started.
R4.1 Running "nuzi" and then "buvu" lands on the same tray as running "nuzi" alone.
     ("buvu" leaves every tray that "nuzi" produces unchanged.)
R4.2 Running "buvu" and then "zoga" gives the same result as running "zoga" alone.
     ("zoga" cannot tell whether "buvu" was applied first.)
R4.3 Running "buvu" twice in a row leaves every MUZA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FUPA has exactly one tray, called n1.
- FIZA has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (NUDU, LOJU, MIPI, MUZA):
D1.1 List the trays of NUDU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "lalo" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 List the trays of LOJU in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "sado" table entries in tray order q2_1, q2_2, ..., one entry per tray.
