You are completing the design of a small toy sorting line with 3 stations.

The stations are: GUPI, SIGO, SOBU. Toys move GUPI -> SIGO -> SOBU.
There are 3 moving steps:
- "koza" carries each GUPI slot to a SIGO slot.
- "roda" is an internal reshuffle of SIGO: it carries each SIGO slot to a SIGO slot.
- "risu" carries each SIGO slot to a SOBU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "koza" and then "roda" lands on the same slot as running "koza" alone.
     ("roda" leaves every slot that "koza" produces unchanged.)
R1.2 Running "roda" and then "risu" gives the same result as running "risu" alone.
     ("risu" cannot tell whether "roda" was applied first.)
R1.3 Running "roda" twice in a row leaves every SIGO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GUPI has exactly 3 slots, called n1, n2, n3.
- SOBU has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (SIGO):
D1.1 List the slots of SIGO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "roda" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "koza" table entries in GUPI slot order n1, n2, n3.
D1.4 List the "risu" table entries in SIGO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

SIGO = {q1_1, ..., q1_k}
koza: n1 -> <SIGO slot>, n2 -> <SIGO slot>, n3 -> <SIGO slot>
roda: q1_1 -> <SIGO slot>, ..., q1_k -> <SIGO slot>
risu: q1_1 -> <SOBU slot>, ... (one entry per SIGO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
