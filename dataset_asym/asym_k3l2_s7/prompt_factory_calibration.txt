You are completing the design of a small toy sorting line with 3 stations.

The stations are: TIZO, TUBI, ROLA. Toys move TIZO -> TUBI -> ROLA.
There are 3 moving steps:
- "vofo" carries each TIZO slot to a TUBI slot.
- "bifu" is an internal reshuffle of TUBI: it carries each TUBI slot to a TUBI slot.
- "rama" carries each TUBI slot to a ROLA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vofo" and then "bifu" lands on the same slot as running "vofo" alone.
     ("bifu" leaves every slot that "vofo" produces unchanged.)
R1.2 Running "bifu" and then "rama" gives the same result as running "rama" alone.
     ("rama" cannot tell whether "bifu" was applied first.)
R1.3 Running "bifu" twice in a row leaves every TUBI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TIZO has exactly 3 slots, called n1, n2, n3.
- ROLA has exactly 2 slots, called s1, s2.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (TUBI):
D1.1 List the slots of TUBI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "bifu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "vofo" table entries in TIZO slot order n1, n2, n3.
D1.4 List the "rama" table entries in TUBI slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

TUBI = {q1_1, ..., q1_k}
vofo: n1 -> <TUBI slot>, n2 -> <TUBI slot>, n3 -> <TUBI slot>
bifu: q1_1 -> <TUBI slot>, ..., q1_k -> <TUBI slot>
rama: q1_1 -> <ROLA slot>, ... (one entry per TUBI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
