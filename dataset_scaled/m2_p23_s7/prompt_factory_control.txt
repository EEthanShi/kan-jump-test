You are completing the design of a small toy sorting line with 4 stations.

The stations are: VOTU, PUTA, TIDO, SIZA. Toys move VOTU -> PUTA -> TIDO -> SIZA.
There are 5 moving steps:
- "vini" carries each VOTU slot to a PUTA slot.
- "goga" is an internal reshuffle of PUTA: it carries each PUTA slot to a PUTA slot.
- "viku" carries each PUTA slot to a TIDO slot.
- "gagi" is an internal reshuffle of TIDO: it carries each TIDO slot to a TIDO slot.
- "jazo" carries each TIDO slot to a SIZA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vini" and then "goga" lands on the same slot as running "vini" alone.
     ("goga" leaves every slot that "vini" produces unchanged.)
R1.2 Running "goga" and then "viku" gives the same result as running "viku" alone.
     ("viku" cannot tell whether "goga" was applied first.)
R1.3 Running "goga" twice in a row leaves every PUTA slot exactly where it started.
R2.1 Running "viku" and then "gagi" lands on the same slot as running "viku" alone.
     ("gagi" leaves every slot that "viku" produces unchanged.)
R2.2 Running "gagi" and then "jazo" gives the same result as running "jazo" alone.
     ("jazo" cannot tell whether "gagi" was applied first.)
R2.3 Running "gagi" three times in a row leaves every TIDO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VOTU has exactly one slot, called n1.
- SIZA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PUTA, TIDO):
D1.1 PUTA must be a finite set with at most 1 slot.
D1.2 List the "goga" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 TIDO must be a finite set with at most 1 slot.
D2.2 List the "gagi" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PUTA = {q1_1, ..., q1_k}
vini: n1 -> <PUTA slot>
goga: q1_1 -> <PUTA slot>, ..., q1_k -> <PUTA slot>
TIDO = {q2_1, ..., q2_k}
viku: q1_1 -> <TIDO slot>, ... (one entry per PUTA slot)
gagi: q2_1 -> <TIDO slot>, ..., q2_k -> <TIDO slot>
jazo: q2_1 -> <SIZA slot>, ... (one entry per TIDO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
