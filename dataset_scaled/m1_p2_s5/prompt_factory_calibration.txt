You are completing the design of a small toy sorting line with 3 stations.

The stations are: DAMO, MOMI, JOSU. Toys move DAMO -> MOMI -> JOSU.
There are 3 moving steps:
- "raja" carries each DAMO slot to a MOMI slot.
- "rada" is an internal reshuffle of MOMI: it carries each MOMI slot to a MOMI slot.
- "pona" carries each MOMI slot to a JOSU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "raja" and then "rada" lands on the same slot as running "raja" alone.
     ("rada" leaves every slot that "raja" produces unchanged.)
R1.2 Running "rada" and then "pona" gives the same result as running "pona" alone.
     ("pona" cannot tell whether "rada" was applied first.)
R1.3 Running "rada" twice in a row leaves every MOMI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DAMO has exactly one slot, called n1.
- JOSU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (MOMI):
D1.1 List the slots of MOMI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "rada" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

MOMI = {q1_1, ..., q1_k}
raja: n1 -> <MOMI slot>
rada: q1_1 -> <MOMI slot>, ..., q1_k -> <MOMI slot>
pona: q1_1 -> <JOSU slot>, ... (one entry per MOMI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
