You are completing the design of a small book sorting row of carts with 5 carts.

The carts are: TOLU, TABA, TOFI, GIMA, RISA. Books move TOLU -> TABA -> TOFI -> GIMA -> RISA.
There are 7 moving steps:
- "duli" carries each TOLU tray to a TABA tray.
- "gula" is an internal rearrangement of TABA: it carries each TABA tray to a TABA tray.
- "lazo" carries each TABA tray to a TOFI tray.
- "kilu" is an internal rearrangement of TOFI: it carries each TOFI tray to a TOFI tray.
- "galu" carries each TOFI tray to a GIMA tray.
- "jona" is an internal rearrangement of GIMA: it carries each GIMA tray to a GIMA tray.
- "napi" carries each GIMA tray to a RISA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "duli" and then "gula" lands on the same tray as running "duli" alone.
     ("gula" leaves every tray that "duli" produces unchanged.)
R1.2 Running "gula" and then "lazo" gives the same result as running "lazo" alone.
     ("lazo" cannot tell whether "gula" was applied first.)
R1.3 Running "gula" three times in a row leaves every TABA tray exactly where it started.
R2.1 Running "lazo" and then "kilu" lands on the same tray as running "lazo" alone.
     ("kilu" leaves every tray that "lazo" produces unchanged.)
R2.2 Running "kilu" and then "galu" gives the same result as running "galu" alone.
     ("galu" cannot tell whether "kilu" was applied first.)
R2.3 Running "kilu" twice in a row leaves every TOFI tray exactly where it started.
R3.1 Running "galu" and then "jona" lands on the same tray as running "galu" alone.
     ("jona" leaves every tray that "galu" produces unchanged.)
R3.2 Running "jona" and then "napi" gives the same result as running "napi" alone.
     ("napi" cannot tell whether "jona" was applied first.)
R3.3 Running "jona" twice in a row leaves every GIMA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TOLU has exactly one tray, called n1.
- RISA has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (TABA, TOFI, GIMA):
D1.1 TABA must be a finite set with at most 4 trays.
D1.2 "gula" must NOT be the do-nothing move (it must move at least one TABA tray).
D2.1 TOFI must be a finite set with at most 3 trays.
D2.2 "kilu" must NOT be the do-nothing move (it must move at least one TOFI tray).
D3.1 GIMA must be a finite set with at most 3 trays.
D3.2 "jona" must NOT be the do-nothing move (it must move at least one GIMA tray).

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

TABA = {q1_1, ..., q1_k}
duli: n1 -> <TABA tray>
gula: q1_1 -> <TABA tray>, ..., q1_k -> <TABA tray>
TOFI = {q2_1, ..., q2_k}
lazo: q1_1 -> <TOFI tray>, ... (one entry per TABA tray)
kilu: q2_1 -> <TOFI tray>, ..., q2_k -> <TOFI tray>
GIMA = {q3_1, ..., q3_k}
galu: q2_1 -> <GIMA tray>, ... (one entry per TOFI tray)
jona: q3_1 -> <GIMA tray>, ..., q3_k -> <GIMA tray>
napi: q3_1 -> <RISA tray>, ... (one entry per GIMA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
