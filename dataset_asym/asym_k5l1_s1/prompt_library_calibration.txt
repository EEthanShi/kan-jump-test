You are completing the design of a small book sorting row of carts with 3 carts.

The carts are: FIMI, MATO, DATA. Books move FIMI -> MATO -> DATA.
There are 3 moving steps:
- "jamo" carries each FIMI tray to a MATO tray.
- "gogu" is an internal rearrangement of MATO: it carries each MATO tray to a MATO tray.
- "zajo" carries each MATO tray to a DATA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "jamo" and then "gogu" lands on the same tray as running "jamo" alone.
     ("gogu" leaves every tray that "jamo" produces unchanged.)
R1.2 Running "gogu" and then "zajo" gives the same result as running "zajo" alone.
     ("zajo" cannot tell whether "gogu" was applied first.)
R1.3 Running "gogu" twice in a row leaves every MATO tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FIMI has exactly 5 trays, called n1, n2, n3, n4, n5.
- DATA has exactly 1 tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle cart (MATO):
D1.1 List the trays of MATO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "gogu" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D1.3 List the "jamo" table entries in FIMI tray order n1, n2, n3, n4, n5.
D1.4 List the "zajo" table entries in MATO tray order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle cart.

Answer format bound: designs with up to 7 trays in the middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
use tray names q1_1, q1_2, ... for the middle cart):

MATO = {q1_1, ..., q1_k}
jamo: n1 -> <MATO tray>, n2 -> <MATO tray>, n3 -> <MATO tray>, n4 -> <MATO tray>, n5 -> <MATO tray>
gogu: q1_1 -> <MATO tray>, ..., q1_k -> <MATO tray>
zajo: q1_1 -> <DATA tray>, ... (one entry per MATO tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
