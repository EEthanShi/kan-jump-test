You are completing the design of a small toy sorting line with 6 stations.

The stations are: ZUFI, DATO, KILI, PIBO, KARO, TIKU. Toys move ZUFI -> DATO -> KILI -> PIBO -> KARO -> TIKU.

- "galo" is an internal reshuffle of DATO: it carries each DATO slot to a DATO slot.
- "riti" carries each DATO slot to a KILI slot.
- "kuta" is an internal reshuffle of KILI: it carries each KILI slot to a KILI slot.
- "duro" carries each KILI slot to a PIBO slot.
- "koki" is an internal reshuffle of PIBO: it carries each PIBO slot to a PIBO slot.
- "raza" carries each PIBO slot to a KARO slot.
- "kiju" is an internal reshuffle of KARO: it carries each KARO slot to a KARO slot.
- "tugu" carries each KARO slot to a TIKU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jobu" and then "galo" lands on the same slot as running "jobu" alone.
     ("galo" leaves every slot that "jobu" produces unchanged.)
R1.2 Running "galo" and then "riti" gives the same result as running "riti" alone.
     ("riti" cannot tell whether "galo" was applied first.)
R1.3 Running "galo" three times in a row leaves every DATO slot exactly where it started.
R2.1 Running "riti" and then "kuta" lands on the same slot as running "riti" alone.
     ("kuta" leaves every slot that "riti" produces unchanged.)
R2.2 Running "kuta" and then "duro" gives the same result as running "duro" alone.
     ("duro" cannot tell whether "kuta" was applied first.)
R2.3 Running "kuta" twice in a row leaves every KILI slot exactly where it started.
R3.1 Running "duro" and then "koki" lands on the same slot as running "duro" alone.
     ("koki" leaves every slot that "duro" produces unchanged.)
R3.2 Running "koki" and then "raza" gives the same result as running "raza" alone.

R4.1 Running "raza" and then "kiju" lands on the same slot as running "raza" alone.

R4.2 Running "kiju" and then "tugu" gives the same result as running "tugu" alone.
     ("tugu" cannot tell whether "kiju" was applied first.)
R4.3 Running "kiju" twice in a row leaves every KARO slot exactly where it started.
