You are completing the design of a small toy sorting line with 3 stations.

The stations are: NUZO, BIVO, PASU. Toys move NUZO -> BIVO -> PASU.
There are 3 moving steps:
- "kovi" carries each NUZO slot to a BIVO slot.
- "zuji" is an internal reshuffle of BIVO: it carries each BIVO slot to a BIVO slot.
- "doto" carries each BIVO slot to a PASU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "kovi" and then "zuji" lands on the same slot as running "kovi" alone.
     ("zuji" leaves every slot that "kovi" produces unchanged.)
R1.2 Running "zuji" and then "doto" gives the same result as running "doto" alone.
     ("doto" cannot tell whether "zuji" was applied first.)
R1.3 Running "zuji" twice in a row leaves every BIVO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NUZO has exactly one slot, called n1.
- PASU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (BIVO):
D1.1 List the slots of BIVO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "zuji" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BIVO = {q1_1, ..., q1_k}
kovi: n1 -> <BIVO slot>
zuji: q1_1 -> <BIVO slot>, ..., q1_k -> <BIVO slot>
doto: q1_1 -> <PASU slot>, ... (one entry per BIVO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
