You are completing the design of a small toy sorting line with 3 stations.

The stations are: NUDA, TAJA, RARA. Toys move NUDA -> TAJA -> RARA.
There are 3 moving steps:
- "davu" carries each NUDA slot to a TAJA slot.
- "baru" is an internal reshuffle of TAJA: it carries each TAJA slot to a TAJA slot.
- "gavi" carries each TAJA slot to a RARA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "davu" and then "baru" lands on the same slot as running "davu" alone.
     ("baru" leaves every slot that "davu" produces unchanged.)
R1.2 Running "baru" and then "gavi" gives the same result as running "gavi" alone.
     ("gavi" cannot tell whether "baru" was applied first.)
R1.3 Running "baru" twice in a row leaves every TAJA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NUDA has exactly one slot, called n1.
- RARA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (TAJA):
D1.1 List the slots of TAJA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "baru" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

TAJA = {q1_1, ..., q1_k}
davu: n1 -> <TAJA slot>
baru: q1_1 -> <TAJA slot>, ..., q1_k -> <TAJA slot>
gavi: q1_1 -> <RARA slot>, ... (one entry per TAJA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
