You are completing the design of a small toy sorting line with 3 stations.

The stations are: SARU, SUTI, ZOVI. Toys move SARU -> SUTI -> ZOVI.
There are 3 moving steps:
- "rapi" carries each SARU slot to a SUTI slot.
- "fupu" is an internal reshuffle of SUTI: it carries each SUTI slot to a SUTI slot.
- "gura" carries each SUTI slot to a ZOVI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "rapi" and then "fupu" lands on the same slot as running "rapi" alone.
     ("fupu" leaves every slot that "rapi" produces unchanged.)
R1.2 Running "fupu" and then "gura" gives the same result as running "gura" alone.
     ("gura" cannot tell whether "fupu" was applied first.)
R1.3 Running "fupu" three times in a row leaves every SUTI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SARU has exactly one slot, called n1.
- ZOVI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (SUTI):
D1.1 SUTI must be a finite set with at most 1 slot.
D1.2 List the "fupu" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

SUTI = {q1_1, ..., q1_k}
rapi: n1 -> <SUTI slot>
fupu: q1_1 -> <SUTI slot>, ..., q1_k -> <SUTI slot>
gura: q1_1 -> <ZOVI slot>, ... (one entry per SUTI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
