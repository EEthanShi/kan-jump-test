You are completing the design of a small toy sorting line with 4 stations.

The stations are: MOKI, PASU, NAPA, SUGU. Toys move MOKI -> PASU -> NAPA -> SUGU.
There are 5 moving steps:
- "piki" carries each MOKI slot to a PASU slot.
- "lija" is an internal reshuffle of PASU: it carries each PASU slot to a PASU slot.
- "tuku" carries each PASU slot to a NAPA slot.
- "gigo" is an internal reshuffle of NAPA: it carries each NAPA slot to a NAPA slot.
- "pitu" carries each NAPA slot to a SUGU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "piki" and then "lija" lands on the same slot as running "piki" alone.
     ("lija" leaves every slot that "piki" produces unchanged.)
R1.2 Running "lija" and then "tuku" gives the same result as running "tuku" alone.
     ("tuku" cannot tell whether "lija" was applied first.)
R1.3 Running "lija" twice in a row leaves every PASU slot exactly where it started.
R2.1 Running "tuku" and then "gigo" lands on the same slot as running "tuku" alone.
     ("gigo" leaves every slot that "tuku" produces unchanged.)
R2.2 Running "gigo" and then "pitu" gives the same result as running "pitu" alone.
     ("pitu" cannot tell whether "gigo" was applied first.)
R2.3 Running "gigo" three times in a row leaves every NAPA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- MOKI has exactly one slot, called n1.
- SUGU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PASU, NAPA):
D1.1 List the slots of PASU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "lija" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of NAPA in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "gigo" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PASU = {q1_1, ..., q1_k}
piki: n1 -> <PASU slot>
lija: q1_1 -> <PASU slot>, ..., q1_k -> <PASU slot>
NAPA = {q2_1, ..., q2_k}
tuku: q1_1 -> <NAPA slot>, ... (one entry per PASU slot)
gigo: q2_1 -> <NAPA slot>, ..., q2_k -> <NAPA slot>
pitu: q2_1 -> <SUGU slot>, ... (one entry per NAPA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
