You are completing the design of a small toy sorting line with 3 stations.

The stations are: FUSI, BILI, LIVA. Toys move FUSI -> BILI -> LIVA.
There are 3 moving steps:
- "dodi" carries each FUSI slot to a BILI slot.
- "zupi" is an internal reshuffle of BILI: it carries each BILI slot to a BILI slot.
- "zipu" carries each BILI slot to a LIVA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dodi" and then "zupi" lands on the same slot as running "dodi" alone.
     ("zupi" leaves every slot that "dodi" produces unchanged.)
R1.2 Running "zupi" and then "zipu" gives the same result as running "zipu" alone.
     ("zipu" cannot tell whether "zupi" was applied first.)
R1.3 Running "zupi" three times in a row leaves every BILI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FUSI has exactly one slot, called n1.
- LIVA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (BILI):
D1.1 BILI must be a finite set with at most 1 slot.
D1.2 List the "zupi" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BILI = {q1_1, ..., q1_k}
dodi: n1 -> <BILI slot>
zupi: q1_1 -> <BILI slot>, ..., q1_k -> <BILI slot>
zipu: q1_1 -> <LIVA slot>, ... (one entry per BILI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
