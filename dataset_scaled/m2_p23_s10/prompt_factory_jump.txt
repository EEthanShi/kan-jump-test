You are completing the design of a small toy sorting line with 4 stations.

The stations are: ZARO, RAJO, BIPA, KUBI. Toys move ZARO -> RAJO -> BIPA -> KUBI.
There are 5 moving steps:
- "lumo" carries each ZARO slot to a RAJO slot.
- "zuja" is an internal reshuffle of RAJO: it carries each RAJO slot to a RAJO slot.
- "libo" carries each RAJO slot to a BIPA slot.
- "jusa" is an internal reshuffle of BIPA: it carries each BIPA slot to a BIPA slot.
- "duja" carries each BIPA slot to a KUBI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "lumo" and then "zuja" lands on the same slot as running "lumo" alone.
     ("zuja" leaves every slot that "lumo" produces unchanged.)
R1.2 Running "zuja" and then "libo" gives the same result as running "libo" alone.
     ("libo" cannot tell whether "zuja" was applied first.)
R1.3 Running "zuja" twice in a row leaves every RAJO slot exactly where it started.
R2.1 Running "libo" and then "jusa" lands on the same slot as running "libo" alone.
     ("jusa" leaves every slot that "libo" produces unchanged.)
R2.2 Running "jusa" and then "duja" gives the same result as running "duja" alone.
     ("duja" cannot tell whether "jusa" was applied first.)
R2.3 Running "jusa" three times in a row leaves every BIPA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ZARO has exactly one slot, called n1.
- KUBI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RAJO, BIPA):
D1.1 RAJO must be a finite set with at most 3 slots.
D1.2 "zuja" must NOT be the do-nothing move (it must move at least one RAJO slot).
D2.1 BIPA must be a finite set with at most 4 slots.
D2.2 "jusa" must NOT be the do-nothing move (it must move at least one BIPA slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RAJO = {q1_1, ..., q1_k}
lumo: n1 -> <RAJO slot>
zuja: q1_1 -> <RAJO slot>, ..., q1_k -> <RAJO slot>
BIPA = {q2_1, ..., q2_k}
libo: q1_1 -> <BIPA slot>, ... (one entry per RAJO slot)
jusa: q2_1 -> <BIPA slot>, ..., q2_k -> <BIPA slot>
duja: q2_1 -> <KUBI slot>, ... (one entry per BIPA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
