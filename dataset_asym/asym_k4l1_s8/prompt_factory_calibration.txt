You are completing the design of a small toy sorting line with 3 stations.

The stations are: FUSI, VOFA, TARI. Toys move FUSI -> VOFA -> TARI.
There are 3 moving steps:
- "bisu" carries each FUSI slot to a VOFA slot.
- "bagu" is an internal reshuffle of VOFA: it carries each VOFA slot to a VOFA slot.
- "kuti" carries each VOFA slot to a TARI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bisu" and then "bagu" lands on the same slot as running "bisu" alone.
     ("bagu" leaves every slot that "bisu" produces unchanged.)
R1.2 Running "bagu" and then "kuti" gives the same result as running "kuti" alone.
     ("kuti" cannot tell whether "bagu" was applied first.)
R1.3 Running "bagu" twice in a row leaves every VOFA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FUSI has exactly 4 slots, called n1, n2, n3, n4.
- TARI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1.

Requirements for the middle station (VOFA):
D1.1 List the slots of VOFA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "bagu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "bisu" table entries in FUSI slot order n1, n2, n3, n4.
D1.4 List the "kuti" table entries in VOFA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 6 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

VOFA = {q1_1, ..., q1_k}
bisu: n1 -> <VOFA slot>, n2 -> <VOFA slot>, n3 -> <VOFA slot>, n4 -> <VOFA slot>
bagu: q1_1 -> <VOFA slot>, ..., q1_k -> <VOFA slot>
kuti: q1_1 -> <TARI slot>, ... (one entry per VOFA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
