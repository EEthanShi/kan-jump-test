You are completing the design of a small toy sorting line with 4 stations.

The stations are: DULO, POFO, LAFU, FIBU. Toys move DULO -> POFO -> LAFU -> FIBU.
There are 5 moving steps:
- "loma" carries each DULO slot to a POFO slot.
- "bagu" is an internal reshuffle of POFO: it carries each POFO slot to a POFO slot.
- "zivu" carries each POFO slot to a LAFU slot.
- "fuvi" is an internal reshuffle of LAFU: it carries each LAFU slot to a LAFU slot.
- "jona" carries each LAFU slot to a FIBU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "loma" and then "bagu" lands on the same slot as running "loma" alone.
     ("bagu" leaves every slot that "loma" produces unchanged.)
R1.2 Running "bagu" and then "zivu" gives the same result as running "zivu" alone.
     ("zivu" cannot tell whether "bagu" was applied first.)
R1.3 Running "bagu" twice in a row leaves every POFO slot exactly where it started.
R2.1 Running "zivu" and then "fuvi" lands on the same slot as running "zivu" alone.
     ("fuvi" leaves every slot that "zivu" produces unchanged.)
R2.2 Running "fuvi" and then "jona" gives the same result as running "jona" alone.
     ("jona" cannot tell whether "fuvi" was applied first.)
R2.3 Running "fuvi" twice in a row leaves every LAFU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DULO has exactly one slot, called n1.
- FIBU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (POFO, LAFU):
D1.1 List the slots of POFO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "bagu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of LAFU in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "fuvi" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

POFO = {q1_1, ..., q1_k}
loma: n1 -> <POFO slot>
bagu: q1_1 -> <POFO slot>, ..., q1_k -> <POFO slot>
LAFU = {q2_1, ..., q2_k}
zivu: q1_1 -> <LAFU slot>, ... (one entry per POFO slot)
fuvi: q2_1 -> <LAFU slot>, ..., q2_k -> <LAFU slot>
jona: q2_1 -> <FIBU slot>, ... (one entry per LAFU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
