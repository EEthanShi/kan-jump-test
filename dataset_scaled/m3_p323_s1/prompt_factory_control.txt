You are completing the design of a small toy sorting line with 5 stations.

The stations are: PAMO, KUGI, TUZA, FIKO, RUFO. Toys move PAMO -> KUGI -> TUZA -> FIKO -> RUFO.
There are 7 moving steps:
- "luda" carries each PAMO slot to a KUGI slot.
- "susi" is an internal reshuffle of KUGI: it carries each KUGI slot to a KUGI slot.
- "pozi" carries each KUGI slot to a TUZA slot.
- "bozi" is an internal reshuffle of TUZA: it carries each TUZA slot to a TUZA slot.
- "mujo" carries each TUZA slot to a FIKO slot.
- "disa" is an internal reshuffle of FIKO: it carries each FIKO slot to a FIKO slot.
- "rosi" carries each FIKO slot to a RUFO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "luda" and then "susi" lands on the same slot as running "luda" alone.
     ("susi" leaves every slot that "luda" produces unchanged.)
R1.2 Running "susi" and then "pozi" gives the same result as running "pozi" alone.
     ("pozi" cannot tell whether "susi" was applied first.)
R1.3 Running "susi" three times in a row leaves every KUGI slot exactly where it started.
R2.1 Running "pozi" and then "bozi" lands on the same slot as running "pozi" alone.
     ("bozi" leaves every slot that "pozi" produces unchanged.)
R2.2 Running "bozi" and then "mujo" gives the same result as running "mujo" alone.
     ("mujo" cannot tell whether "bozi" was applied first.)
R2.3 Running "bozi" twice in a row leaves every TUZA slot exactly where it started.
R3.1 Running "mujo" and then "disa" lands on the same slot as running "mujo" alone.
     ("disa" leaves every slot that "mujo" produces unchanged.)
R3.2 Running "disa" and then "rosi" gives the same result as running "rosi" alone.
     ("rosi" cannot tell whether "disa" was applied first.)
R3.3 Running "disa" three times in a row leaves every FIKO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PAMO has exactly one slot, called n1.
- RUFO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KUGI, TUZA, FIKO):
D1.1 KUGI must be a finite set with at most 1 slot.
D1.2 List the "susi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 TUZA must be a finite set with at most 1 slot.
D2.2 List the "bozi" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 FIKO must be a finite set with at most 1 slot.
D3.2 List the "disa" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KUGI = {q1_1, ..., q1_k}
luda: n1 -> <KUGI slot>
susi: q1_1 -> <KUGI slot>, ..., q1_k -> <KUGI slot>
TUZA = {q2_1, ..., q2_k}
pozi: q1_1 -> <TUZA slot>, ... (one entry per KUGI slot)
bozi: q2_1 -> <TUZA slot>, ..., q2_k -> <TUZA slot>
FIKO = {q3_1, ..., q3_k}
mujo: q2_1 -> <FIKO slot>, ... (one entry per TUZA slot)
disa: q3_1 -> <FIKO slot>, ..., q3_k -> <FIKO slot>
rosi: q3_1 -> <RUFO slot>, ... (one entry per FIKO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
