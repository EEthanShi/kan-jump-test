You are completing the design of a small toy sorting line with 5 stations.

The stations are: BASO, ZIZO, SUDI, JOJU, PAZO. Toys move BASO -> ZIZO -> SUDI -> JOJU -> PAZO.
There are 7 moving steps:
- "sumi" carries each BASO slot to a ZIZO slot.
- "ridi" is an internal reshuffle of ZIZO: it carries each ZIZO slot to a ZIZO slot.
- "vari" carries each ZIZO slot to a SUDI slot.
- "bona" is an internal reshuffle of SUDI: it carries each SUDI slot to a SUDI slot.
- "bunu" carries each SUDI slot to a JOJU slot.
- "tuku" is an internal reshuffle of JOJU: it carries each JOJU slot to a JOJU slot.
- "tini" carries each JOJU slot to a PAZO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sumi" and then "ridi" lands on the same slot as running "sumi" alone.
     ("ridi" leaves every slot that "sumi" produces unchanged.)
R1.2 Running "ridi" and then "vari" gives the same result as running "vari" alone.
     ("vari" cannot tell whether "ridi" was applied first.)
R1.3 Running "ridi" three times in a row leaves every ZIZO slot exactly where it started.
R2.1 Running "vari" and then "bona" lands on the same slot as running "vari" alone.
     ("bona" leaves every slot that "vari" produces unchanged.)
R2.2 Running "bona" and then "bunu" gives the same result as running "bunu" alone.
     ("bunu" cannot tell whether "bona" was applied first.)
R2.3 Running "bona" three times in a row leaves every SUDI slot exactly where it started.
R3.1 Running "bunu" and then "tuku" lands on the same slot as running "bunu" alone.
     ("tuku" leaves every slot that "bunu" produces unchanged.)
R3.2 Running "tuku" and then "tini" gives the same result as running "tini" alone.
     ("tini" cannot tell whether "tuku" was applied first.)
R3.3 Running "tuku" three times in a row leaves every JOJU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- BASO has exactly one slot, called n1.
- PAZO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (ZIZO, SUDI, JOJU):
D1.1 List the slots of ZIZO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "ridi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of SUDI in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "bona" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of JOJU in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "tuku" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ZIZO = {q1_1, ..., q1_k}
sumi: n1 -> <ZIZO slot>
ridi: q1_1 -> <ZIZO slot>, ..., q1_k -> <ZIZO slot>
SUDI = {q2_1, ..., q2_k}
vari: q1_1 -> <SUDI slot>, ... (one entry per ZIZO slot)
bona: q2_1 -> <SUDI slot>, ..., q2_k -> <SUDI slot>
JOJU = {q3_1, ..., q3_k}
bunu: q2_1 -> <JOJU slot>, ... (one entry per SUDI slot)
tuku: q3_1 -> <JOJU slot>, ..., q3_k -> <JOJU slot>
tini: q3_1 -> <PAZO slot>, ... (one entry per JOJU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
