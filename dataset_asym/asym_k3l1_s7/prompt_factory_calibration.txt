You are completing the design of a small toy sorting line with 3 stations.

The stations are: TOVA, BILO, SUZU. Toys move TOVA -> BILO -> SUZU.
There are 3 moving steps:
- "jada" carries each TOVA slot to a BILO slot.
- "zati" is an internal reshuffle of BILO: it carries each BILO slot to a BILO slot.
- "fabi" carries each BILO slot to a SUZU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jada" and then "zati" lands on the same slot as running "jada" alone.
     ("zati" leaves every slot that "jada" produces unchanged.)
R1.2 Running "zati" and then "fabi" gives the same result as running "fabi" alone.
     ("fabi" cannot tell whether "zati" was applied first.)
R1.3 Running "zati" twice in a row leaves every BILO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TOVA has exactly 3 slots, called n1, n2, n3.
- SUZU has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (BILO):
D1.1 List the slots of BILO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "zati" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "jada" table entries in TOVA slot order n1, n2, n3.
D1.4 List the "fabi" table entries in BILO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

BILO = {q1_1, ..., q1_k}
jada: n1 -> <BILO slot>, n2 -> <BILO slot>, n3 -> <BILO slot>
zati: q1_1 -> <BILO slot>, ..., q1_k -> <BILO slot>
fabi: q1_1 -> <SUZU slot>, ... (one entry per BILO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
