You are completing the design of a small toy sorting line with 6 stations.

The stations are: SAZU, MUFI, MUNA, RUMI, DASU, TAMA. Toys move SAZU -> MUFI -> MUNA -> RUMI -> DASU -> TAMA.
There are 9 moving steps:

- "dufi" is an internal reshuffle of MUFI: it carries each MUFI slot to a MUFI slot.
- "goza" carries each MUFI slot to a MUNA slot.
- "tibi" is an internal reshuffle of MUNA: it carries each MUNA slot to a MUNA slot.
- "pozo" carries each MUNA slot to a RUMI slot.
- "tofi" is an internal reshuffle of RUMI: it carries each RUMI slot to a RUMI slot.
- "ravu" carries each RUMI slot to a DASU slot.
- "baku" is an internal reshuffle of DASU: it carries each DASU slot to a DASU slot.
- "pija" carries each DASU slot to a TAMA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "mudo" and then "dufi" lands on the same slot as running "mudo" alone.
     ("dufi" leaves every slot that "mudo" produces unchanged.)
R1.2 Running "dufi" and then "goza" gives the same result as running "goza" alone.
     ("goza" cannot tell whether "dufi" was applied first.)
R1.3 Running "dufi" three times in a row leaves every MUFI slot exactly where it started.
R2.1 Running "goza" and then "tibi" lands on the same slot as running "goza" alone.
     ("tibi" leaves every slot that "goza" produces unchanged.)
R2.2 Running "tibi" and then "pozo" gives the same result as running "pozo" alone.
