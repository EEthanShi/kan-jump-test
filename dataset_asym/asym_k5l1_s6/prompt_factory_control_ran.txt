You are completing the design of a small toy sorting line with 3 stations.

The stations are: DUGO, VAKO, MOKA. Toys move DUGO -> VAKO -> MOKA.
There are 3 moving steps:
- "giko" carries each DUGO slot to a VAKO slot.
- "supa" is an internal reshuffle of VAKO: it carries each VAKO slot to a VAKO slot.
- "tada" carries each VAKO slot to a MOKA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "giko" and then "supa" lands on the same slot as running "giko" alone.
     ("supa" leaves every slot that "giko" produces unchanged.)
R1.2 Running "supa" and then "tada" gives the same result as running "tada" alone.
     ("tada" cannot tell whether "supa" was applied first.)
R1.3 Running "supa" twice in a row leaves every VAKO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DUGO has exactly 5 slots, called n1, n2, n3, n4, n5.
- MOKA has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (VAKO):
D1.1 VAKO must be a finite set with at most 1 slot.
D1.2 List the "supa" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "giko" table entries in DUGO slot order n1, n2, n3, n4, n5.
D1.4 Every MOKA slot must be reached by "tada" from at least one VAKO slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

VAKO = {q1_1, ..., q1_k}
giko: n1 -> <VAKO slot>, n2 -> <VAKO slot>, n3 -> <VAKO slot>, n4 -> <VAKO slot>, n5 -> <VAKO slot>
supa: q1_1 -> <VAKO slot>, ..., q1_k -> <VAKO slot>
tada: q1_1 -> <MOKA slot>, ... (one entry per VAKO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
