You are completing the design of a small book sorting row of carts with 3 carts.

The carts are: DAFA, LOMA, BOLU. Books move DAFA -> LOMA -> BOLU.
There are 3 moving steps:
- "boju" carries each DAFA tray to a LOMA tray.
- "joto" is an internal rearrangement of LOMA: it carries each LOMA tray to a LOMA tray.
- "diri" carries each LOMA tray to a BOLU tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "boju" and then "joto" lands on the same tray as running "boju" alone.
     ("joto" leaves every tray that "boju" produces unchanged.)
R1.2 Running "joto" and then "diri" gives the same result as running "diri" alone.
     ("diri" cannot tell whether "joto" was applied first.)
R1.3 Running "joto" twice in a row leaves every LOMA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DAFA has exactly 3 trays, called n1, n2, n3.
- BOLU has exactly 1 tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle cart (LOMA):
D1.1 List the trays of LOMA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "joto" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D1.3 List the "boju" table entries in DAFA tray order n1, n2, n3.
D1.4 List the "diri" table entries in LOMA tray order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle cart.

Answer format bound: designs with up to 5 trays in the middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
use tray names q1_1, q1_2, ... for the middle cart):

LOMA = {q1_1, ..., q1_k}
boju: n1 -> <LOMA tray>, n2 -> <LOMA tray>, n3 -> <LOMA tray>
joto: q1_1 -> <LOMA tray>, ..., q1_k -> <LOMA tray>
diri: q1_1 -> <BOLU tray>, ... (one entry per LOMA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
