You are completing the design of a small book sorting row of carts with 5 carts.

The carts are: NIDA, TOJO, MATU, MUVA, SULO. Books move NIDA -> TOJO -> MATU -> MUVA -> SULO.
There are 7 moving steps:
- "zigo" carries each NIDA tray to a TOJO tray.
- "napi" is an internal rearrangement of TOJO: it carries each TOJO tray to a TOJO tray.
- "fini" carries each TOJO tray to a MATU tray.
- "pufi" is an internal rearrangement of MATU: it carries each MATU tray to a MATU tray.
- "sagu" carries each MATU tray to a MUVA tray.
- "liba" is an internal rearrangement of MUVA: it carries each MUVA tray to a MUVA tray.
- "mobo" carries each MUVA tray to a SULO tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "zigo" and then "napi" lands on the same tray as running "zigo" alone.
     ("napi" leaves every tray that "zigo" produces unchanged.)
R1.2 Running "napi" and then "fini" gives the same result as running "fini" alone.
     ("fini" cannot tell whether "napi" was applied first.)
R1.3 Running "napi" twice in a row leaves every TOJO tray exactly where it started.
R2.1 Running "fini" and then "pufi" lands on the same tray as running "fini" alone.
     ("pufi" leaves every tray that "fini" produces unchanged.)
R2.2 Running "pufi" and then "sagu" gives the same result as running "sagu" alone.
     ("sagu" cannot tell whether "pufi" was applied first.)
R2.3 Running "pufi" twice in a row leaves every MATU tray exactly where it started.
R3.1 Running "sagu" and then "liba" lands on the same tray as running "sagu" alone.
     ("liba" leaves every tray that "sagu" produces unchanged.)
R3.2 Running "liba" and then "mobo" gives the same result as running "mobo" alone.
     ("mobo" cannot tell whether "liba" was applied first.)
R3.3 Running "liba" three times in a row leaves every MUVA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NIDA has exactly one tray, called n1.
- SULO has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (TOJO, MATU, MUVA):
D1.1 TOJO must be a finite set with at most 1 tray.
D1.2 List the "napi" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 MATU must be a finite set with at most 1 tray.
D2.2 List the "pufi" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 MUVA must be a finite set with at most 1 tray.
D3.2 List the "liba" table entries in tray order q3_1, q3_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

TOJO = {q1_1, ..., q1_k}
zigo: n1 -> <TOJO tray>
napi: q1_1 -> <TOJO tray>, ..., q1_k -> <TOJO tray>
MATU = {q2_1, ..., q2_k}
fini: q1_1 -> <MATU tray>, ... (one entry per TOJO tray)
pufi: q2_1 -> <MATU tray>, ..., q2_k -> <MATU tray>
MUVA = {q3_1, ..., q3_k}
sagu: q2_1 -> <MUVA tray>, ... (one entry per MATU tray)
liba: q3_1 -> <MUVA tray>, ..., q3_k -> <MUVA tray>
mobo: q3_1 -> <SULO tray>, ... (one entry per MUVA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
