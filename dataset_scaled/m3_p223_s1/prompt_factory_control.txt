You are completing the design of a small toy sorting line with 5 stations.

The stations are: LISI, ROGO, LAKO, FOFI, MIZA. Toys move LISI -> ROGO -> LAKO -> FOFI -> MIZA.
There are 7 moving steps:
- "goli" carries each LISI slot to a ROGO slot.
- "motu" is an internal reshuffle of ROGO: it carries each ROGO slot to a ROGO slot.
- "fadu" carries each ROGO slot to a LAKO slot.
- "vira" is an internal reshuffle of LAKO: it carries each LAKO slot to a LAKO slot.
- "nuvo" carries each LAKO slot to a FOFI slot.
- "paga" is an internal reshuffle of FOFI: it carries each FOFI slot to a FOFI slot.
- "dufo" carries each FOFI slot to a MIZA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "goli" and then "motu" lands on the same slot as running "goli" alone.
     ("motu" leaves every slot that "goli" produces unchanged.)
R1.2 Running "motu" and then "fadu" gives the same result as running "fadu" alone.
     ("fadu" cannot tell whether "motu" was applied first.)
R1.3 Running "motu" twice in a row leaves every ROGO slot exactly where it started.
R2.1 Running "fadu" and then "vira" lands on the same slot as running "fadu" alone.
     ("vira" leaves every slot that "fadu" produces unchanged.)
R2.2 Running "vira" and then "nuvo" gives the same result as running "nuvo" alone.
     ("nuvo" cannot tell whether "vira" was applied first.)
R2.3 Running "vira" twice in a row leaves every LAKO slot exactly where it started.
R3.1 Running "nuvo" and then "paga" lands on the same slot as running "nuvo" alone.
     ("paga" leaves every slot that "nuvo" produces unchanged.)
R3.2 Running "paga" and then "dufo" gives the same result as running "dufo" alone.
     ("dufo" cannot tell whether "paga" was applied first.)
R3.3 Running "paga" three times in a row leaves every FOFI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LISI has exactly one slot, called n1.
- MIZA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (ROGO, LAKO, FOFI):
D1.1 ROGO must be a finite set with at most 1 slot.
D1.2 List the "motu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 LAKO must be a finite set with at most 1 slot.
D2.2 List the "vira" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 FOFI must be a finite set with at most 1 slot.
D3.2 List the "paga" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ROGO = {q1_1, ..., q1_k}
goli: n1 -> <ROGO slot>
motu: q1_1 -> <ROGO slot>, ..., q1_k -> <ROGO slot>
LAKO = {q2_1, ..., q2_k}
fadu: q1_1 -> <LAKO slot>, ... (one entry per ROGO slot)
vira: q2_1 -> <LAKO slot>, ..., q2_k -> <LAKO slot>
FOFI = {q3_1, ..., q3_k}
nuvo: q2_1 -> <FOFI slot>, ... (one entry per LAKO slot)
paga: q3_1 -> <FOFI slot>, ..., q3_k -> <FOFI slot>
dufo: q3_1 -> <MIZA slot>, ... (one entry per FOFI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
