You are completing the design of a small toy sorting line with 3 stations.

The stations are: POZU, MAMO, NOLU. Toys move POZU -> MAMO -> NOLU.
There are 3 moving steps:
- "luti" carries each POZU slot to a MAMO slot.
- "lufa" is an internal reshuffle of MAMO: it carries each MAMO slot to a MAMO slot.
- "doku" carries each MAMO slot to a NOLU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "luti" and then "lufa" lands on the same slot as running "luti" alone.
     ("lufa" leaves every slot that "luti" produces unchanged.)
R1.2 Running "lufa" and then "doku" gives the same result as running "doku" alone.
     ("doku" cannot tell whether "lufa" was applied first.)
R1.3 Running "lufa" twice in a row leaves every MAMO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- POZU has exactly 2 slots, called n1, n2.
- NOLU has exactly 2 slots, called s1, s2.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1.

Requirements for the middle station (MAMO):
D1.1 MAMO must be a finite set with at most 2 slots.
D1.2 List the "lufa" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "luti" must carry different POZU slots to different MAMO slots.
D1.4 List the "doku" table entries in MAMO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

MAMO = {q1_1, ..., q1_k}
luti: n1 -> <MAMO slot>, n2 -> <MAMO slot>
lufa: q1_1 -> <MAMO slot>, ..., q1_k -> <MAMO slot>
doku: q1_1 -> <NOLU slot>, ... (one entry per MAMO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
