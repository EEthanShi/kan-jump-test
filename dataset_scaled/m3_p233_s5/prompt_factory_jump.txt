You are completing the design of a small toy sorting line with 5 stations.

The stations are: RUDU, RULI, TURI, ZAKU, GOGA. Toys move RUDU -> RULI -> TURI -> ZAKU -> GOGA.
There are 7 moving steps:
- "dara" carries each RUDU slot to a RULI slot.
- "mivi" is an internal reshuffle of RULI: it carries each RULI slot to a RULI slot.
- "dati" carries each RULI slot to a TURI slot.
- "podu" is an internal reshuffle of TURI: it carries each TURI slot to a TURI slot.
- "jizo" carries each TURI slot to a ZAKU slot.
- "suvi" is an internal reshuffle of ZAKU: it carries each ZAKU slot to a ZAKU slot.
- "vovo" carries each ZAKU slot to a GOGA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dara" and then "mivi" lands on the same slot as running "dara" alone.
     ("mivi" leaves every slot that "dara" produces unchanged.)
R1.2 Running "mivi" and then "dati" gives the same result as running "dati" alone.
     ("dati" cannot tell whether "mivi" was applied first.)
R1.3 Running "mivi" twice in a row leaves every RULI slot exactly where it started.
R2.1 Running "dati" and then "podu" lands on the same slot as running "dati" alone.
     ("podu" leaves every slot that "dati" produces unchanged.)
R2.2 Running "podu" and then "jizo" gives the same result as running "jizo" alone.
     ("jizo" cannot tell whether "podu" was applied first.)
R2.3 Running "podu" three times in a row leaves every TURI slot exactly where it started.
R3.1 Running "jizo" and then "suvi" lands on the same slot as running "jizo" alone.
     ("suvi" leaves every slot that "jizo" produces unchanged.)
R3.2 Running "suvi" and then "vovo" gives the same result as running "vovo" alone.
     ("vovo" cannot tell whether "suvi" was applied first.)
R3.3 Running "suvi" three times in a row leaves every ZAKU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUDU has exactly one slot, called n1.
- GOGA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RULI, TURI, ZAKU):
D1.1 RULI must be a finite set with at most 3 slots.
D1.2 "mivi" must NOT be the do-nothing move (it must move at least one RULI slot).
D2.1 TURI must be a finite set with at most 4 slots.
D2.2 "podu" must NOT be the do-nothing move (it must move at least one TURI slot).
D3.1 ZAKU must be a finite set with at most 4 slots.
D3.2 "suvi" must NOT be the do-nothing move (it must move at least one ZAKU slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RULI = {q1_1, ..., q1_k}
dara: n1 -> <RULI slot>
mivi: q1_1 -> <RULI slot>, ..., q1_k -> <RULI slot>
TURI = {q2_1, ..., q2_k}
dati: q1_1 -> <TURI slot>, ... (one entry per RULI slot)
podu: q2_1 -> <TURI slot>, ..., q2_k -> <TURI slot>
ZAKU = {q3_1, ..., q3_k}
jizo: q2_1 -> <ZAKU slot>, ... (one entry per TURI slot)
suvi: q3_1 -> <ZAKU slot>, ..., q3_k -> <ZAKU slot>
vovo: q3_1 -> <GOGA slot>, ... (one entry per ZAKU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
