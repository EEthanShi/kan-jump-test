You are completing the design of a small toy sorting line with 3 stations.

The stations are: FODA, ZUNU, BUGO. Toys move FODA -> ZUNU -> BUGO.
There are 3 moving steps:
- "sisa" carries each FODA slot to a ZUNU slot.
- "koku" is an internal reshuffle of ZUNU: it carries each ZUNU slot to a ZUNU slot.
- "loru" carries each ZUNU slot to a BUGO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sisa" and then "koku" lands on the same slot as running "sisa" alone.
     ("koku" leaves every slot that "sisa" produces unchanged.)
R1.2 Running "koku" and then "loru" gives the same result as running "loru" alone.
     ("loru" cannot tell whether "koku" was applied first.)
R1.3 Running "koku" twice in a row leaves every ZUNU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FODA has exactly one slot, called n1.
- BUGO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (ZUNU):
D1.1 ZUNU must be a finite set with at most 1 slot.
D1.2 List the "koku" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ZUNU = {q1_1, ..., q1_k}
sisa: n1 -> <ZUNU slot>
koku: q1_1 -> <ZUNU slot>, ..., q1_k -> <ZUNU slot>
loru: q1_1 -> <BUGO slot>, ... (one entry per ZUNU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
