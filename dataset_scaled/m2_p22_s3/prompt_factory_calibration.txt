You are completing the design of a small toy sorting line with 4 stations.

The stations are: TOLU, SIZO, SUGA, PUPO. Toys move TOLU -> SIZO -> SUGA -> PUPO.
There are 5 moving steps:
- "solu" carries each TOLU slot to a SIZO slot.
- "gotu" is an internal reshuffle of SIZO: it carries each SIZO slot to a SIZO slot.
- "futi" carries each SIZO slot to a SUGA slot.
- "zini" is an internal reshuffle of SUGA: it carries each SUGA slot to a SUGA slot.
- "lati" carries each SUGA slot to a PUPO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "solu" and then "gotu" lands on the same slot as running "solu" alone.
     ("gotu" leaves every slot that "solu" produces unchanged.)
R1.2 Running "gotu" and then "futi" gives the same result as running "futi" alone.
     ("futi" cannot tell whether "gotu" was applied first.)
R1.3 Running "gotu" twice in a row leaves every SIZO slot exactly where it started.
R2.1 Running "futi" and then "zini" lands on the same slot as running "futi" alone.
     ("zini" leaves every slot that "futi" produces unchanged.)
R2.2 Running "zini" and then "lati" gives the same result as running "lati" alone.
     ("lati" cannot tell whether "zini" was applied first.)
R2.3 Running "zini" twice in a row leaves every SUGA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TOLU has exactly one slot, called n1.
- PUPO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (SIZO, SUGA):
D1.1 List the slots of SIZO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "gotu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of SUGA in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "zini" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

SIZO = {q1_1, ..., q1_k}
solu: n1 -> <SIZO slot>
gotu: q1_1 -> <SIZO slot>, ..., q1_k -> <SIZO slot>
SUGA = {q2_1, ..., q2_k}
futi: q1_1 -> <SUGA slot>, ... (one entry per SIZO slot)
zini: q2_1 -> <SUGA slot>, ..., q2_k -> <SUGA slot>
lati: q2_1 -> <PUPO slot>, ... (one entry per SUGA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
