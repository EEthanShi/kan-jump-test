You are completing the design of a small toy sorting line with 4 stations.

The stations are: JOVI, VASU, PAMU, KUGU. Toys move JOVI -> VASU -> PAMU -> KUGU.
There are 5 moving steps:
- "sinu" carries each JOVI slot to a VASU slot.
- "juna" is an internal reshuffle of VASU: it carries each VASU slot to a VASU slot.
- "sasu" carries each VASU slot to a PAMU slot.
- "rini" is an internal reshuffle of PAMU: it carries each PAMU slot to a PAMU slot.
- "zogu" carries each PAMU slot to a KUGU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sinu" and then "juna" lands on the same slot as running "sinu" alone.
     ("juna" leaves every slot that "sinu" produces unchanged.)
R1.2 Running "juna" and then "sasu" gives the same result as running "sasu" alone.
     ("sasu" cannot tell whether "juna" was applied first.)
R1.3 Running "juna" twice in a row leaves every VASU slot exactly where it started.
R2.1 Running "sasu" and then "rini" lands on the same slot as running "sasu" alone.
     ("rini" leaves every slot that "sasu" produces unchanged.)
R2.2 Running "rini" and then "zogu" gives the same result as running "zogu" alone.
     ("zogu" cannot tell whether "rini" was applied first.)
R2.3 Running "rini" twice in a row leaves every PAMU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JOVI has exactly one slot, called n1.
- KUGU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (VASU, PAMU):
D1.1 List the slots of VASU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "juna" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of PAMU in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "rini" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

VASU = {q1_1, ..., q1_k}
sinu: n1 -> <VASU slot>
juna: q1_1 -> <VASU slot>, ..., q1_k -> <VASU slot>
PAMU = {q2_1, ..., q2_k}
sasu: q1_1 -> <PAMU slot>, ... (one entry per VASU slot)
rini: q2_1 -> <PAMU slot>, ..., q2_k -> <PAMU slot>
zogu: q2_1 -> <KUGU slot>, ... (one entry per PAMU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
