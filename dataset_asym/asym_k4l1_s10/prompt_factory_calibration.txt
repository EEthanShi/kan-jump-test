You are completing the design of a small toy sorting line with 3 stations.

The stations are: DAGA, LUPI, KUMA. Toys move DAGA -> LUPI -> KUMA.
There are 3 moving steps:
- "zuma" carries each DAGA slot to a LUPI slot.
- "bigo" is an internal reshuffle of LUPI: it carries each LUPI slot to a LUPI slot.
- "pobi" carries each LUPI slot to a KUMA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "zuma" and then "bigo" lands on the same slot as running "zuma" alone.
     ("bigo" leaves every slot that "zuma" produces unchanged.)
R1.2 Running "bigo" and then "pobi" gives the same result as running "pobi" alone.
     ("pobi" cannot tell whether "bigo" was applied first.)
R1.3 Running "bigo" twice in a row leaves every LUPI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DAGA has exactly 4 slots, called n1, n2, n3, n4.
- KUMA has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1.

Requirements for the middle station (LUPI):
D1.1 List the slots of LUPI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "bigo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "zuma" table entries in DAGA slot order n1, n2, n3, n4.
D1.4 List the "pobi" table entries in LUPI slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 6 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

LUPI = {q1_1, ..., q1_k}
zuma: n1 -> <LUPI slot>, n2 -> <LUPI slot>, n3 -> <LUPI slot>, n4 -> <LUPI slot>
bigo: q1_1 -> <LUPI slot>, ..., q1_k -> <LUPI slot>
pobi: q1_1 -> <KUMA slot>, ... (one entry per LUPI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
