You are completing the design of a small toy sorting line with 5 stations.

The stations are: GUVU, JORU, RUJU, NIFA, PIFU. Toys move GUVU -> JORU -> RUJU -> NIFA -> PIFU.
There are 7 moving steps:
- "rulu" carries each GUVU slot to a JORU slot.
- "zavu" is an internal reshuffle of JORU: it carries each JORU slot to a JORU slot.
- "zifi" carries each JORU slot to a RUJU slot.
- "foda" is an internal reshuffle of RUJU: it carries each RUJU slot to a RUJU slot.
- "futo" carries each RUJU slot to a NIFA slot.
- "luru" is an internal reshuffle of NIFA: it carries each NIFA slot to a NIFA slot.
- "lumu" carries each NIFA slot to a PIFU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "rulu" and then "zavu" lands on the same slot as running "rulu" alone.
     ("zavu" leaves every slot that "rulu" produces unchanged.)
R1.2 Running "zavu" and then "zifi" gives the same result as running "zifi" alone.
     ("zifi" cannot tell whether "zavu" was applied first.)
R1.3 Running "zavu" three times in a row leaves every JORU slot exactly where it started.
R2.1 Running "zifi" and then "foda" lands on the same slot as running "zifi" alone.
     ("foda" leaves every slot that "zifi" produces unchanged.)
R2.2 Running "foda" and then "futo" gives the same result as running "futo" alone.
     ("futo" cannot tell whether "foda" was applied first.)
R2.3 Running "foda" three times in a row leaves every RUJU slot exactly where it started.
R3.1 Running "futo" and then "luru" lands on the same slot as running "futo" alone.
     ("luru" leaves every slot that "futo" produces unchanged.)
R3.2 Running "luru" and then "lumu" gives the same result as running "lumu" alone.
     ("lumu" cannot tell whether "luru" was applied first.)
R3.3 Running "luru" twice in a row leaves every NIFA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GUVU has exactly one slot, called n1.
- PIFU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (JORU, RUJU, NIFA):
D1.1 JORU must be a finite set with at most 4 slots.
D1.2 "zavu" must NOT be the do-nothing move (it must move at least one JORU slot).
D2.1 RUJU must be a finite set with at most 4 slots.
D2.2 "foda" must NOT be the do-nothing move (it must move at least one RUJU slot).
D3.1 NIFA must be a finite set with at most 3 slots.
D3.2 "luru" must NOT be the do-nothing move (it must move at least one NIFA slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

JORU = {q1_1, ..., q1_k}
rulu: n1 -> <JORU slot>
zavu: q1_1 -> <JORU slot>, ..., q1_k -> <JORU slot>
RUJU = {q2_1, ..., q2_k}
zifi: q1_1 -> <RUJU slot>, ... (one entry per JORU slot)
foda: q2_1 -> <RUJU slot>, ..., q2_k -> <RUJU slot>
NIFA = {q3_1, ..., q3_k}
futo: q2_1 -> <NIFA slot>, ... (one entry per RUJU slot)
luru: q3_1 -> <NIFA slot>, ..., q3_k -> <NIFA slot>
lumu: q3_1 -> <PIFU slot>, ... (one entry per NIFA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
