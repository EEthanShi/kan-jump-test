You are completing the design of a small book sorting row of carts with 5 carts.

The carts are: TAVA, TIFO, FUNO, TIGI, DOSI. Books move TAVA -> TIFO -> FUNO -> TIGI -> DOSI.
There are 7 moving steps:
- "dija" carries each TAVA tray to a TIFO tray.
- "fovo" is an internal rearrangement of TIFO: it carries each TIFO tray to a TIFO tray.
- "dupu" carries each TIFO tray to a FUNO tray.
- "nugo" is an internal rearrangement of FUNO: it carries each FUNO tray to a FUNO tray.
- "misu" carries each FUNO tray to a TIGI tray.
- "muma" is an internal rearrangement of TIGI: it carries each TIGI tray to a TIGI tray.
- "bizo" carries each TIGI tray to a DOSI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "dija" and then "fovo" lands on the same tray as running "dija" alone.
     ("fovo" leaves every tray that "dija" produces unchanged.)
R1.2 Running "fovo" and then "dupu" gives the same result as running "dupu" alone.
     ("dupu" cannot tell whether "fovo" was applied first.)
R1.3 Running "fovo" three times in a row leaves every TIFO tray exactly where it started.
R2.1 Running "dupu" and then "nugo" lands on the same tray as running "dupu" alone.
     ("nugo" leaves every tray that "dupu" produces unchanged.)
R2.2 Running "nugo" and then "misu" gives the same result as running "misu" alone.
     ("misu" cannot tell whether "nugo" was applied first.)
R2.3 Running "nugo" twice in a row leaves every FUNO tray exactly where it started.
R3.1 Running "misu" and then "muma" lands on the same tray as running "misu" alone.
     ("muma" leaves every tray that "misu" produces unchanged.)
R3.2 Running "muma" and then "bizo" gives the same result as running "bizo" alone.
     ("bizo" cannot tell whether "muma" was applied first.)
R3.3 Running "muma" three times in a row leaves every TIGI tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TAVA has exactly one tray, called n1.
- DOSI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (TIFO, FUNO, TIGI):
D1.1 TIFO must be a finite set with at most 1 tray.
D1.2 List the "fovo" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 FUNO must be a finite set with at most 1 tray.
D2.2 List the "nugo" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 TIGI must be a finite set with at most 1 tray.
D3.2 List the "muma" table entries in tray order q3_1, q3_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

TIFO = {q1_1, ..., q1_k}
dija: n1 -> <TIFO tray>
fovo: q1_1 -> <TIFO tray>, ..., q1_k -> <TIFO tray>
FUNO = {q2_1, ..., q2_k}
dupu: q1_1 -> <FUNO tray>, ... (one entry per TIFO tray)
nugo: q2_1 -> <FUNO tray>, ..., q2_k -> <FUNO tray>
TIGI = {q3_1, ..., q3_k}
misu: q2_1 -> <TIGI tray>, ... (one entry per FUNO tray)
muma: q3_1 -> <TIGI tray>, ..., q3_k -> <TIGI tray>
bizo: q3_1 -> <DOSI tray>, ... (one entry per TIGI tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
