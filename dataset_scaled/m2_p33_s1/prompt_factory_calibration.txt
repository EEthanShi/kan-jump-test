You are completing the design of a small toy sorting line with 4 stations.

The stations are: GARO, FONI, PINI, LOMI. Toys move GARO -> FONI -> PINI -> LOMI.
There are 5 moving steps:
- "vuli" carries each GARO slot to a FONI slot.
- "sova" is an internal reshuffle of FONI: it carries each FONI slot to a FONI slot.
- "vibi" carries each FONI slot to a PINI slot.
- "roja" is an internal reshuffle of PINI: it carries each PINI slot to a PINI slot.
- "sona" carries each PINI slot to a LOMI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vuli" and then "sova" lands on the same slot as running "vuli" alone.
     ("sova" leaves every slot that "vuli" produces unchanged.)
R1.2 Running "sova" and then "vibi" gives the same result as running "vibi" alone.
     ("vibi" cannot tell whether "sova" was applied first.)
R1.3 Running "sova" three times in a row leaves every FONI slot exactly where it started.
R2.1 Running "vibi" and then "roja" lands on the same slot as running "vibi" alone.
     ("roja" leaves every slot that "vibi" produces unchanged.)
R2.2 Running "roja" and then "sona" gives the same result as running "sona" alone.
     ("sona" cannot tell whether "roja" was applied first.)
R2.3 Running "roja" three times in a row leaves every PINI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GARO has exactly one slot, called n1.
- LOMI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FONI, PINI):
D1.1 List the slots of FONI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "sova" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of PINI in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "roja" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FONI = {q1_1, ..., q1_k}
vuli: n1 -> <FONI slot>
sova: q1_1 -> <FONI slot>, ..., q1_k -> <FONI slot>
PINI = {q2_1, ..., q2_k}
vibi: q1_1 -> <PINI slot>, ... (one entry per FONI slot)
roja: q2_1 -> <PINI slot>, ..., q2_k -> <PINI slot>
sona: q2_1 -> <LOMI slot>, ... (one entry per PINI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
