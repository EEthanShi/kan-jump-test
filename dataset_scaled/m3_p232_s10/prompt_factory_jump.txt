You are completing the design of a small toy sorting line with 5 stations.

The stations are: GUSA, RUTI, TIPI, MOBO, BARU. Toys move GUSA -> RUTI -> TIPI -> MOBO -> BARU.
There are 7 moving steps:
- "dalu" carries each GUSA slot to a RUTI slot.
- "dimu" is an internal reshuffle of RUTI: it carries each RUTI slot to a RUTI slot.
- "saku" carries each RUTI slot to a TIPI slot.
- "rogi" is an internal reshuffle of TIPI: it carries each TIPI slot to a TIPI slot.
- "figu" carries each TIPI slot to a MOBO slot.
- "mubu" is an internal reshuffle of MOBO: it carries each MOBO slot to a MOBO slot.
- "fiza" carries each MOBO slot to a BARU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dalu" and then "dimu" lands on the same slot as running "dalu" alone.
     ("dimu" leaves every slot that "dalu" produces unchanged.)
R1.2 Running "dimu" and then "saku" gives the same result as running "saku" alone.
     ("saku" cannot tell whether "dimu" was applied first.)
R1.3 Running "dimu" twice in a row leaves every RUTI slot exactly where it started.
R2.1 Running "saku" and then "rogi" lands on the same slot as running "saku" alone.
     ("rogi" leaves every slot that "saku" produces unchanged.)
R2.2 Running "rogi" and then "figu" gives the same result as running "figu" alone.
     ("figu" cannot tell whether "rogi" was applied first.)
R2.3 Running "rogi" three times in a row leaves every TIPI slot exactly where it started.
R3.1 Running "figu" and then "mubu" lands on the same slot as running "figu" alone.
     ("mubu" leaves every slot that "figu" produces unchanged.)
R3.2 Running "mubu" and then "fiza" gives the same result as running "fiza" alone.
     ("fiza" cannot tell whether "mubu" was applied first.)
R3.3 Running "mubu" twice in a row leaves every MOBO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GUSA has exactly one slot, called n1.
- BARU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RUTI, TIPI, MOBO):
D1.1 RUTI must be a finite set with at most 3 slots.
D1.2 "dimu" must NOT be the do-nothing move (it must move at least one RUTI slot).
D2.1 TIPI must be a finite set with at most 4 slots.
D2.2 "rogi" must NOT be the do-nothing move (it must move at least one TIPI slot).
D3.1 MOBO must be a finite set with at most 3 slots.
D3.2 "mubu" must NOT be the do-nothing move (it must move at least one MOBO slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RUTI = {q1_1, ..., q1_k}
dalu: n1 -> <RUTI slot>
dimu: q1_1 -> <RUTI slot>, ..., q1_k -> <RUTI slot>
TIPI = {q2_1, ..., q2_k}
saku: q1_1 -> <TIPI slot>, ... (one entry per RUTI slot)
rogi: q2_1 -> <TIPI slot>, ..., q2_k -> <TIPI slot>
MOBO = {q3_1, ..., q3_k}
figu: q2_1 -> <MOBO slot>, ... (one entry per TIPI slot)
mubu: q3_1 -> <MOBO slot>, ..., q3_k -> <MOBO slot>
fiza: q3_1 -> <BARU slot>, ... (one entry per MOBO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
