You are completing the design of a small toy sorting line with 6 stations.

The stations are: TIFO, GAJI, RARO, KIVI, PIBO, MIMO. Toys move TIFO -> GAJI -> RARO -> KIVI -> PIBO -> MIMO.
There are 9 moving steps:
- "duzi" carries each TIFO slot to a GAJI slot.
- "sari" is an internal reshuffle of GAJI: it carries each GAJI slot to a GAJI slot.
- "guba" carries each GAJI slot to a RARO slot.
- "vupu" is an internal reshuffle of RARO: it carries each RARO slot to a RARO slot.
- "dika" carries each RARO slot to a KIVI slot.
- "bigu" is an internal reshuffle of KIVI: it carries each KIVI slot to a KIVI slot.
- "ripo" carries each KIVI slot to a PIBO slot.
- "fuzu" is an internal reshuffle of PIBO: it carries each PIBO slot to a PIBO slot.
- "mibi" carries each PIBO slot to a MIMO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "duzi" and then "sari" lands on the same slot as running "duzi" alone.
     ("sari" leaves every slot that "duzi" produces unchanged.)
R1.2 Running "sari" and then "guba" gives the same result as running "guba" alone.
     ("guba" cannot tell whether "sari" was applied first.)
R1.3 Running "sari" twice in a row leaves every GAJI slot exactly where it started.
R2.1 Running "guba" and then "vupu" lands on the same slot as running "guba" alone.
     ("vupu" leaves every slot that "guba" produces unchanged.)
R2.2 Running "vupu" and then "dika" gives the same result as running "dika" alone.
     ("dika" cannot tell whether "vupu" was applied first.)
R2.3 Running "vupu" three times in a row leaves every RARO slot exactly where it started.
R3.1 Running "dika" and then "bigu" lands on the same slot as running "dika" alone.
     ("bigu" leaves every slot that "dika" produces unchanged.)
R3.2 Running "bigu" and then "ripo" gives the same result as running "ripo" alone.
     ("ripo" cannot tell whether "bigu" was applied first.)
R3.3 Running "bigu" twice in a row leaves every KIVI slot exactly where it started.
R4.1 Running "ripo" and then "fuzu" lands on the same slot as running "ripo" alone.
     ("fuzu" leaves every slot that "ripo" produces unchanged.)
R4.2 Running "fuzu" and then "mibi" gives the same result as running "mibi" alone.
     ("mibi" cannot tell whether "fuzu" was applied first.)
R4.3 Running "fuzu" three times in a row leaves every PIBO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TIFO has exactly one slot, called n1.
- MIMO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (GAJI, RARO, KIVI, PIBO):
D1.1 List the slots of GAJI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "sari" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of RARO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "vupu" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of KIVI in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "bigu" table entries in slot order q3_1, q3_2, ..., one entry per slot.
D4.1 List the slots of PIBO in increasing index order q4_1, q4_2, ... in its set line.
D4.2 List the "fuzu" table entries in slot order q4_1, q4_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
