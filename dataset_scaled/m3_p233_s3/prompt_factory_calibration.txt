You are completing the design of a small toy sorting line with 5 stations.

The stations are: GIJA, VUGO, RAVO, TILI, BOVA. Toys move GIJA -> VUGO -> RAVO -> TILI -> BOVA.
There are 7 moving steps:
- "bimu" carries each GIJA slot to a VUGO slot.
- "goju" is an internal reshuffle of VUGO: it carries each VUGO slot to a VUGO slot.
- "gopo" carries each VUGO slot to a RAVO slot.
- "gagi" is an internal reshuffle of RAVO: it carries each RAVO slot to a RAVO slot.
- "voli" carries each RAVO slot to a TILI slot.
- "dogo" is an internal reshuffle of TILI: it carries each TILI slot to a TILI slot.
- "kasi" carries each TILI slot to a BOVA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bimu" and then "goju" lands on the same slot as running "bimu" alone.
     ("goju" leaves every slot that "bimu" produces unchanged.)
R1.2 Running "goju" and then "gopo" gives the same result as running "gopo" alone.
     ("gopo" cannot tell whether "goju" was applied first.)
R1.3 Running "goju" twice in a row leaves every VUGO slot exactly where it started.
R2.1 Running "gopo" and then "gagi" lands on the same slot as running "gopo" alone.
     ("gagi" leaves every slot that "gopo" produces unchanged.)
R2.2 Running "gagi" and then "voli" gives the same result as running "voli" alone.
     ("voli" cannot tell whether "gagi" was applied first.)
R2.3 Running "gagi" three times in a row leaves every RAVO slot exactly where it started.
R3.1 Running "voli" and then "dogo" lands on the same slot as running "voli" alone.
     ("dogo" leaves every slot that "voli" produces unchanged.)
R3.2 Running "dogo" and then "kasi" gives the same result as running "kasi" alone.
     ("kasi" cannot tell whether "dogo" was applied first.)
R3.3 Running "dogo" three times in a row leaves every TILI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GIJA has exactly one slot, called n1.
- BOVA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (VUGO, RAVO, TILI):
D1.1 List the slots of VUGO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "goju" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of RAVO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "gagi" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of TILI in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "dogo" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

VUGO = {q1_1, ..., q1_k}
bimu: n1 -> <VUGO slot>
goju: q1_1 -> <VUGO slot>, ..., q1_k -> <VUGO slot>
RAVO = {q2_1, ..., q2_k}

gagi: q2_1 -> <RAVO slot>, ..., q2_k -> <RAVO slot>
TILI = {q3_1, ..., q3_k}
voli: q2_1 -> <TILI slot>, ... (one entry per RAVO slot)
dogo: q3_1 -> <TILI slot>, ..., q3_k -> <TILI slot>
kasi: q3_1 -> <BOVA slot>, ... (one entry per TILI slot)

Every rule and requirement above must hold exactly for your tables. Do not
