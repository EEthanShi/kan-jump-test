You are completing the design of a small toy sorting line with 5 stations.

The stations are: JONI, PURU, ZIZO, GUZU, PITO. Toys move JONI -> PURU -> ZIZO -> GUZU -> PITO.
There are 7 moving steps:
- "dizo" carries each JONI slot to a PURU slot.
- "puga" is an internal reshuffle of PURU: it carries each PURU slot to a PURU slot.
- "fosu" carries each PURU slot to a ZIZO slot.
- "vili" is an internal reshuffle of ZIZO: it carries each ZIZO slot to a ZIZO slot.
- "daba" carries each ZIZO slot to a GUZU slot.
- "musa" is an internal reshuffle of GUZU: it carries each GUZU slot to a GUZU slot.
- "nilo" carries each GUZU slot to a PITO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dizo" and then "puga" lands on the same slot as running "dizo" alone.
     ("puga" leaves every slot that "dizo" produces unchanged.)
R1.2 Running "puga" and then "fosu" gives the same result as running "fosu" alone.
     ("fosu" cannot tell whether "puga" was applied first.)
R1.3 Running "puga" twice in a row leaves every PURU slot exactly where it started.
R2.1 Running "fosu" and then "vili" lands on the same slot as running "fosu" alone.
     ("vili" leaves every slot that "fosu" produces unchanged.)
R2.2 Running "vili" and then "daba" gives the same result as running "daba" alone.
     ("daba" cannot tell whether "vili" was applied first.)
R2.3 Running "vili" twice in a row leaves every ZIZO slot exactly where it started.
R3.1 Running "daba" and then "musa" lands on the same slot as running "daba" alone.
     ("musa" leaves every slot that "daba" produces unchanged.)
R3.2 Running "musa" and then "nilo" gives the same result as running "nilo" alone.
     ("nilo" cannot tell whether "musa" was applied first.)
R3.3 Running "musa" twice in a row leaves every GUZU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JONI has exactly one slot, called n1.
- PITO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PURU, ZIZO, GUZU):
D1.1 PURU must be a finite set with at most 1 slot.
D1.2 List the "puga" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 ZIZO must be a finite set with at most 1 slot.
D2.2 List the "vili" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 GUZU must be a finite set with at most 1 slot.
D3.2 List the "musa" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PURU = {q1_1, ..., q1_k}
dizo: n1 -> <PURU slot>
puga: q1_1 -> <PURU slot>, ..., q1_k -> <PURU slot>
ZIZO = {q2_1, ..., q2_k}
fosu: q1_1 -> <ZIZO slot>, ... (one entry per PURU slot)
vili: q2_1 -> <ZIZO slot>, ..., q2_k -> <ZIZO slot>
GUZU = {q3_1, ..., q3_k}
daba: q2_1 -> <GUZU slot>, ... (one entry per ZIZO slot)
musa: q3_1 -> <GUZU slot>, ..., q3_k -> <GUZU slot>
nilo: q3_1 -> <PITO slot>, ... (one entry per GUZU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
