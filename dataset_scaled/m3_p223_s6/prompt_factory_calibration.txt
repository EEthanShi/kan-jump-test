You are completing the design of a small toy sorting line with 5 stations.

The stations are: LATI, KADI, VOVU, BOVU, LIPO. Toys move LATI -> KADI -> VOVU -> BOVU -> LIPO.
There are 7 moving steps:
- "kabu" carries each LATI slot to a KADI slot.
- "sopu" is an internal reshuffle of KADI: it carries each KADI slot to a KADI slot.
- "vavi" carries each KADI slot to a VOVU slot.
- "kuli" is an internal reshuffle of VOVU: it carries each VOVU slot to a VOVU slot.
- "taso" carries each VOVU slot to a BOVU slot.
- "baku" is an internal reshuffle of BOVU: it carries each BOVU slot to a BOVU slot.
- "pubi" carries each BOVU slot to a LIPO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "kabu" and then "sopu" lands on the same slot as running "kabu" alone.
     ("sopu" leaves every slot that "kabu" produces unchanged.)
R1.2 Running "sopu" and then "vavi" gives the same result as running "vavi" alone.
     ("vavi" cannot tell whether "sopu" was applied first.)
R1.3 Running "sopu" twice in a row leaves every KADI slot exactly where it started.
R2.1 Running "vavi" and then "kuli" lands on the same slot as running "vavi" alone.
     ("kuli" leaves every slot that "vavi" produces unchanged.)
R2.2 Running "kuli" and then "taso" gives the same result as running "taso" alone.
     ("taso" cannot tell whether "kuli" was applied first.)
R2.3 Running "kuli" twice in a row leaves every VOVU slot exactly where it started.
R3.1 Running "taso" and then "baku" lands on the same slot as running "taso" alone.
     ("baku" leaves every slot that "taso" produces unchanged.)
R3.2 Running "baku" and then "pubi" gives the same result as running "pubi" alone.
     ("pubi" cannot tell whether "baku" was applied first.)
R3.3 Running "baku" three times in a row leaves every BOVU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LATI has exactly one slot, called n1.
- LIPO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KADI, VOVU, BOVU):
D1.1 List the slots of KADI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "sopu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of VOVU in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "kuli" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of BOVU in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "baku" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KADI = {q1_1, ..., q1_k}
kabu: n1 -> <KADI slot>
sopu: q1_1 -> <KADI slot>, ..., q1_k -> <KADI slot>
VOVU = {q2_1, ..., q2_k}
vavi: q1_1 -> <VOVU slot>, ... (one entry per KADI slot)
kuli: q2_1 -> <VOVU slot>, ..., q2_k -> <VOVU slot>
BOVU = {q3_1, ..., q3_k}
taso: q2_1 -> <BOVU slot>, ... (one entry per VOVU slot)
baku: q3_1 -> <BOVU slot>, ..., q3_k -> <BOVU slot>
pubi: q3_1 -> <LIPO slot>, ... (one entry per BOVU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
