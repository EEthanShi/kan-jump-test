You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: NIFO, VIVU, GUTO, SIFO, NUVI, VOFI. Books move NIFO -> VIVU -> GUTO -> SIFO -> NUVI -> VOFI.
There are 9 moving steps:
- "tavu" carries each NIFO tray to a VIVU tray.
- "pava" is an internal rearrangement of VIVU: it carries each VIVU tray to a VIVU tray.
- "suju" carries each VIVU tray to a GUTO tray.
- "foji" is an internal rearrangement of GUTO: it carries each GUTO tray to a GUTO tray.
- "gamu" carries each GUTO tray to a SIFO tray.
- "kala" is an internal rearrangement of SIFO: it carries each SIFO tray to a SIFO tray.
- "sibo" carries each SIFO tray to a NUVI tray.
- "luji" is an internal rearrangement of NUVI: it carries each NUVI tray to a NUVI tray.
- "guko" carries each NUVI tray to a VOFI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "tavu" and then "pava" lands on the same tray as running "tavu" alone.
     ("pava" leaves every tray that "tavu" produces unchanged.)
R1.2 Running "pava" and then "suju" gives the same result as running "suju" alone.
     ("suju" cannot tell whether "pava" was applied first.)
R1.3 Running "pava" three times in a row leaves every VIVU tray exactly where it started.
R2.1 Running "suju" and then "foji" lands on the same tray as running "suju" alone.
     ("foji" leaves every tray that "suju" produces unchanged.)
R2.2 Running "foji" and then "gamu" gives the same result as running "gamu" alone.
     ("gamu" cannot tell whether "foji" was applied first.)
R2.3 Running "foji" three times in a row leaves every GUTO tray exactly where it started.
R3.1 Running "gamu" and then "kala" lands on the same tray as running "gamu" alone.
     ("kala" leaves every tray that "gamu" produces unchanged.)
R3.2 Running "kala" and then "sibo" gives the same result as running "sibo" alone.
     ("sibo" cannot tell whether "kala" was applied first.)
R3.3 Running "kala" three times in a row leaves every SIFO tray exactly where it started.
R4.1 Running "sibo" and then "luji" lands on the same tray as running "sibo" alone.
     ("luji" leaves every tray that "sibo" produces unchanged.)
R4.2 Running "luji" and then "guko" gives the same result as running "guko" alone.
     ("guko" cannot tell whether "luji" was applied first.)
R4.3 Running "luji" three times in a row leaves every NUVI tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NIFO has exactly one tray, called n1.
- VOFI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (VIVU, GUTO, SIFO, NUVI):
D1.1 List the trays of VIVU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "pava" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 List the trays of GUTO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "foji" table entries in tray order q2_1, q2_2, ..., one entry per tray.
