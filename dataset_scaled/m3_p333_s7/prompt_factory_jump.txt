You are completing the design of a small toy sorting line with 5 stations.

The stations are: GISO, LOKI, DUVI, JATI, JUGO. Toys move GISO -> LOKI -> DUVI -> JATI -> JUGO.
There are 7 moving steps:
- "vona" carries each GISO slot to a LOKI slot.
- "rotu" is an internal reshuffle of LOKI: it carries each LOKI slot to a LOKI slot.
- "raku" carries each LOKI slot to a DUVI slot.
- "maji" is an internal reshuffle of DUVI: it carries each DUVI slot to a DUVI slot.
- "fali" carries each DUVI slot to a JATI slot.
- "jori" is an internal reshuffle of JATI: it carries each JATI slot to a JATI slot.
- "vaja" carries each JATI slot to a JUGO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vona" and then "rotu" lands on the same slot as running "vona" alone.
     ("rotu" leaves every slot that "vona" produces unchanged.)
R1.2 Running "rotu" and then "raku" gives the same result as running "raku" alone.
     ("raku" cannot tell whether "rotu" was applied first.)
R1.3 Running "rotu" three times in a row leaves every LOKI slot exactly where it started.
R2.1 Running "raku" and then "maji" lands on the same slot as running "raku" alone.
     ("maji" leaves every slot that "raku" produces unchanged.)
R2.2 Running "maji" and then "fali" gives the same result as running "fali" alone.
     ("fali" cannot tell whether "maji" was applied first.)
R2.3 Running "maji" three times in a row leaves every DUVI slot exactly where it started.
R3.1 Running "fali" and then "jori" lands on the same slot as running "fali" alone.
     ("jori" leaves every slot that "fali" produces unchanged.)
R3.2 Running "jori" and then "vaja" gives the same result as running "vaja" alone.
     ("vaja" cannot tell whether "jori" was applied first.)
R3.3 Running "jori" three times in a row leaves every JATI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GISO has exactly one slot, called n1.
- JUGO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (LOKI, DUVI, JATI):
D1.1 LOKI must be a finite set with at most 4 slots.
D1.2 "rotu" must NOT be the do-nothing move (it must move at least one LOKI slot).
D2.1 DUVI must be a finite set with at most 4 slots.
D2.2 "maji" must NOT be the do-nothing move (it must move at least one DUVI slot).
D3.1 JATI must be a finite set with at most 4 slots.
D3.2 "jori" must NOT be the do-nothing move (it must move at least one JATI slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

LOKI = {q1_1, ..., q1_k}
vona: n1 -> <LOKI slot>
rotu: q1_1 -> <LOKI slot>, ..., q1_k -> <LOKI slot>
DUVI = {q2_1, ..., q2_k}
raku: q1_1 -> <DUVI slot>, ... (one entry per LOKI slot)
maji: q2_1 -> <DUVI slot>, ..., q2_k -> <DUVI slot>
JATI = {q3_1, ..., q3_k}
fali: q2_1 -> <JATI slot>, ... (one entry per DUVI slot)
jori: q3_1 -> <JATI slot>, ..., q3_k -> <JATI slot>
vaja: q3_1 -> <JUGO slot>, ... (one entry per JATI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
