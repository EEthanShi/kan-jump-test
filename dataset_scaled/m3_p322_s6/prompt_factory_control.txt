You are completing the design of a small toy sorting line with 5 stations.

The stations are: KANU, BUGO, LIJA, JOBU, DUKA. Toys move KANU -> BUGO -> LIJA -> JOBU -> DUKA.
There are 7 moving steps:
- "bura" carries each KANU slot to a BUGO slot.
- "bona" is an internal reshuffle of BUGO: it carries each BUGO slot to a BUGO slot.
- "gizo" carries each BUGO slot to a LIJA slot.
- "lofu" is an internal reshuffle of LIJA: it carries each LIJA slot to a LIJA slot.
- "pufu" carries each LIJA slot to a JOBU slot.
- "roji" is an internal reshuffle of JOBU: it carries each JOBU slot to a JOBU slot.
- "rivi" carries each JOBU slot to a DUKA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bura" and then "bona" lands on the same slot as running "bura" alone.
     ("bona" leaves every slot that "bura" produces unchanged.)
R1.2 Running "bona" and then "gizo" gives the same result as running "gizo" alone.
     ("gizo" cannot tell whether "bona" was applied first.)
R1.3 Running "bona" three times in a row leaves every BUGO slot exactly where it started.
R2.1 Running "gizo" and then "lofu" lands on the same slot as running "gizo" alone.
     ("lofu" leaves every slot that "gizo" produces unchanged.)
R2.2 Running "lofu" and then "pufu" gives the same result as running "pufu" alone.
     ("pufu" cannot tell whether "lofu" was applied first.)
R2.3 Running "lofu" twice in a row leaves every LIJA slot exactly where it started.
R3.1 Running "pufu" and then "roji" lands on the same slot as running "pufu" alone.
     ("roji" leaves every slot that "pufu" produces unchanged.)
R3.2 Running "roji" and then "rivi" gives the same result as running "rivi" alone.
     ("rivi" cannot tell whether "roji" was applied first.)
R3.3 Running "roji" twice in a row leaves every JOBU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KANU has exactly one slot, called n1.
- DUKA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (BUGO, LIJA, JOBU):
D1.1 BUGO must be a finite set with at most 1 slot.
D1.2 List the "bona" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 LIJA must be a finite set with at most 1 slot.
D2.2 List the "lofu" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 JOBU must be a finite set with at most 1 slot.
D3.2 List the "roji" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BUGO = {q1_1, ..., q1_k}
bura: n1 -> <BUGO slot>
bona: q1_1 -> <BUGO slot>, ..., q1_k -> <BUGO slot>
LIJA = {q2_1, ..., q2_k}
gizo: q1_1 -> <LIJA slot>, ... (one entry per BUGO slot)
lofu: q2_1 -> <LIJA slot>, ..., q2_k -> <LIJA slot>
JOBU = {q3_1, ..., q3_k}
pufu: q2_1 -> <JOBU slot>, ... (one entry per LIJA slot)
roji: q3_1 -> <JOBU slot>, ..., q3_k -> <JOBU slot>
rivi: q3_1 -> <DUKA slot>, ... (one entry per JOBU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
