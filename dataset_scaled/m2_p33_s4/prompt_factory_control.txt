You are completing the design of a small toy sorting line with 4 stations.

The stations are: NIBO, FONI, RURA, JOKU. Toys move NIBO -> FONI -> RURA -> JOKU.
There are 5 moving steps:
- "bupa" carries each NIBO slot to a FONI slot.
- "rado" is an internal reshuffle of FONI: it carries each FONI slot to a FONI slot.
- "zamu" carries each FONI slot to a RURA slot.
- "fali" is an internal reshuffle of RURA: it carries each RURA slot to a RURA slot.
- "guti" carries each RURA slot to a JOKU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bupa" and then "rado" lands on the same slot as running "bupa" alone.
     ("rado" leaves every slot that "bupa" produces unchanged.)
R1.2 Running "rado" and then "zamu" gives the same result as running "zamu" alone.
     ("zamu" cannot tell whether "rado" was applied first.)
R1.3 Running "rado" three times in a row leaves every FONI slot exactly where it started.
R2.1 Running "zamu" and then "fali" lands on the same slot as running "zamu" alone.
     ("fali" leaves every slot that "zamu" produces unchanged.)
R2.2 Running "fali" and then "guti" gives the same result as running "guti" alone.
     ("guti" cannot tell whether "fali" was applied first.)
R2.3 Running "fali" three times in a row leaves every RURA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NIBO has exactly one slot, called n1.
- JOKU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FONI, RURA):
D1.1 FONI must be a finite set with at most 1 slot.
D1.2 List the "rado" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 RURA must be a finite set with at most 1 slot.
D2.2 List the "fali" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FONI = {q1_1, ..., q1_k}
bupa: n1 -> <FONI slot>
rado: q1_1 -> <FONI slot>, ..., q1_k -> <FONI slot>
RURA = {q2_1, ..., q2_k}
zamu: q1_1 -> <RURA slot>, ... (one entry per FONI slot)
fali: q2_1 -> <RURA slot>, ..., q2_k -> <RURA slot>
guti: q2_1 -> <JOKU slot>, ... (one entry per RURA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
