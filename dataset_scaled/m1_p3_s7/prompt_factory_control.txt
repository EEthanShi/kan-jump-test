You are completing the design of a small toy sorting line with 3 stations.

The stations are: KAFI, SABU, KIFU. Toys move KAFI -> SABU -> KIFU.
There are 3 moving steps:
- "pigu" carries each KAFI slot to a SABU slot.
- "nogu" is an internal reshuffle of SABU: it carries each SABU slot to a SABU slot.
- "baza" carries each SABU slot to a KIFU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "pigu" and then "nogu" lands on the same slot as running "pigu" alone.
     ("nogu" leaves every slot that "pigu" produces unchanged.)
R1.2 Running "nogu" and then "baza" gives the same result as running "baza" alone.
     ("baza" cannot tell whether "nogu" was applied first.)
R1.3 Running "nogu" three times in a row leaves every SABU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- KAFI has exactly one slot, called n1.
- KIFU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (SABU):
D1.1 SABU must be a finite set with at most 1 slot.
D1.2 List the "nogu" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

SABU = {q1_1, ..., q1_k}
pigu: n1 -> <SABU slot>
nogu: q1_1 -> <SABU slot>, ..., q1_k -> <SABU slot>
baza: q1_1 -> <KIFU slot>, ... (one entry per SABU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
