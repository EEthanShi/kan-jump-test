You are completing the design of a small toy sorting line with 6 stations.

The stations are: LOTO, ROGI, SUJA, NUPO, SABA, NIBU. Toys move LOTO -> ROGI -> SUJA -> NUPO -> SABA -> NIBU.
There are 9 moving steps:
- "nuzo" carries each LOTO slot to a ROGI slot.
- "biki" is an internal reshuffle of ROGI: it carries each ROGI slot to a ROGI slot.
- "gosa" carries each ROGI slot to a SUJA slot.
- "jata" is an internal reshuffle of SUJA: it carries each SUJA slot to a SUJA slot.
- "rufi" carries each SUJA slot to a NUPO slot.
- "lato" is an internal reshuffle of NUPO: it carries each NUPO slot to a NUPO slot.
- "zika" carries each NUPO slot to a SABA slot.
- "batu" is an internal reshuffle of SABA: it carries each SABA slot to a SABA slot.
- "lolu" carries each SABA slot to a NIBU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "nuzo" and then "biki" lands on the same slot as running "nuzo" alone.
     ("biki" leaves every slot that "nuzo" produces unchanged.)
R1.2 Running "biki" and then "gosa" gives the same result as running "gosa" alone.
     ("gosa" cannot tell whether "biki" was applied first.)
R1.3 Running "biki" three times in a row leaves every ROGI slot exactly where it started.
R2.1 Running "gosa" and then "jata" lands on the same slot as running "gosa" alone.
     ("jata" leaves every slot that "gosa" produces unchanged.)
R2.2 Running "jata" and then "rufi" gives the same result as running "rufi" alone.
     ("rufi" cannot tell whether "jata" was applied first.)
R2.3 Running "jata" twice in a row leaves every SUJA slot exactly where it started.
R3.1 Running "rufi" and then "lato" lands on the same slot as running "rufi" alone.
     ("lato" leaves every slot that "rufi" produces unchanged.)
R3.2 Running "lato" and then "zika" gives the same result as running "zika" alone.
     ("zika" cannot tell whether "lato" was applied first.)
R3.3 Running "lato" three times in a row leaves every NUPO slot exactly where it started.
R4.1 Running "zika" and then "batu" lands on the same slot as running "zika" alone.
