You are completing the design of a small book sorting row of carts with 4 carts.

The carts are: GISO, KUGI, LOLI, BAJI. Books move GISO -> KUGI -> LOLI -> BAJI.
There are 5 moving steps:
- "sogo" carries each GISO tray to a KUGI tray.
- "lotu" is an internal rearrangement of KUGI: it carries each KUGI tray to a KUGI tray.
- "famo" carries each KUGI tray to a LOLI tray.
- "togo" is an internal rearrangement of LOLI: it carries each LOLI tray to a LOLI tray.
- "zino" carries each LOLI tray to a BAJI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "sogo" and then "lotu" lands on the same tray as running "sogo" alone.
     ("lotu" leaves every tray that "sogo" produces unchanged.)
R1.2 Running "lotu" and then "famo" gives the same result as running "famo" alone.
     ("famo" cannot tell whether "lotu" was applied first.)
R1.3 Running "lotu" twice in a row leaves every KUGI tray exactly where it started.
R2.1 Running "famo" and then "togo" lands on the same tray as running "famo" alone.
     ("togo" leaves every tray that "famo" produces unchanged.)
R2.2 Running "togo" and then "zino" gives the same result as running "zino" alone.
     ("zino" cannot tell whether "togo" was applied first.)
R2.3 Running "togo" twice in a row leaves every LOLI tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GISO has exactly one tray, called n1.
- BAJI has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (KUGI, LOLI):
D1.1 KUGI must be a finite set with at most 1 tray.
D1.2 List the "lotu" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 LOLI must be a finite set with at most 1 tray.
D2.2 List the "togo" table entries in tray order q2_1, q2_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

KUGI = {q1_1, ..., q1_k}
sogo: n1 -> <KUGI tray>
lotu: q1_1 -> <KUGI tray>, ..., q1_k -> <KUGI tray>
LOLI = {q2_1, ..., q2_k}
famo: q1_1 -> <LOLI tray>, ... (one entry per KUGI tray)
togo: q2_1 -> <LOLI tray>, ..., q2_k -> <LOLI tray>
zino: q2_1 -> <BAJI tray>, ... (one entry per LOLI tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
