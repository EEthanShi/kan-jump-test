You are completing the design of a small toy sorting line with 5 stations.

The stations are: SOZO, RATU, LALI, SUVU, ZOKI. Toys move SOZO -> RATU -> LALI -> SUVU -> ZOKI.
There are 7 moving steps:
- "sanu" carries each SOZO slot to a RATU slot.
- "sugi" is an internal reshuffle of RATU: it carries each RATU slot to a RATU slot.
- "siza" carries each RATU slot to a LALI slot.
- "puja" is an internal reshuffle of LALI: it carries each LALI slot to a LALI slot.
- "nita" carries each LALI slot to a SUVU slot.
- "fupo" is an internal reshuffle of SUVU: it carries each SUVU slot to a SUVU slot.
- "bira" carries each SUVU slot to a ZOKI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sanu" and then "sugi" lands on the same slot as running "sanu" alone.
     ("sugi" leaves every slot that "sanu" produces unchanged.)
R1.2 Running "sugi" and then "siza" gives the same result as running "siza" alone.
     ("siza" cannot tell whether "sugi" was applied first.)
R1.3 Running "sugi" twice in a row leaves every RATU slot exactly where it started.
R2.1 Running "siza" and then "puja" lands on the same slot as running "siza" alone.
     ("puja" leaves every slot that "siza" produces unchanged.)
R2.2 Running "puja" and then "nita" gives the same result as running "nita" alone.
     ("nita" cannot tell whether "puja" was applied first.)
R2.3 Running "puja" three times in a row leaves every LALI slot exactly where it started.
R3.1 Running "nita" and then "fupo" lands on the same slot as running "nita" alone.
     ("fupo" leaves every slot that "nita" produces unchanged.)
R3.2 Running "fupo" and then "bira" gives the same result as running "bira" alone.
     ("bira" cannot tell whether "fupo" was applied first.)
R3.3 Running "fupo" twice in a row leaves every SUVU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SOZO has exactly one slot, called n1.
- ZOKI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RATU, LALI, SUVU):
D1.1 RATU must be a finite set with at most 3 slots.
D1.2 "sugi" must NOT be the do-nothing move (it must move at least one RATU slot).
D2.1 LALI must be a finite set with at most 4 slots.
D2.2 "puja" must NOT be the do-nothing move (it must move at least one LALI slot).
D3.1 SUVU must be a finite set with at most 3 slots.
D3.2 "fupo" must NOT be the do-nothing move (it must move at least one SUVU slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RATU = {q1_1, ..., q1_k}
sanu: n1 -> <RATU slot>
sugi: q1_1 -> <RATU slot>, ..., q1_k -> <RATU slot>
LALI = {q2_1, ..., q2_k}
siza: q1_1 -> <LALI slot>, ... (one entry per RATU slot)
puja: q2_1 -> <LALI slot>, ..., q2_k -> <LALI slot>
SUVU = {q3_1, ..., q3_k}
nita: q2_1 -> <SUVU slot>, ... (one entry per LALI slot)
fupo: q3_1 -> <SUVU slot>, ..., q3_k -> <SUVU slot>
bira: q3_1 -> <ZOKI slot>, ... (one entry per SUVU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
