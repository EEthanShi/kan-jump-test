You are completing the design of a small toy sorting line with 6 stations.

The stations are: VAGO, MUKI, NALA, BUFU, JOBI, VAVU. Toys move VAGO -> MUKI -> NALA -> BUFU -> JOBI -> VAVU.
There are 9 moving steps:
- "sapa" carries each VAGO slot to a MUKI slot.
- "zimu" is an internal reshuffle of MUKI: it carries each MUKI slot to a MUKI slot.
- "liju" carries each MUKI slot to a NALA slot.
- "gaka" is an internal reshuffle of NALA: it carries each NALA slot to a NALA slot.
- "muti" carries each NALA slot to a BUFU slot.
- "rofu" is an internal reshuffle of BUFU: it carries each BUFU slot to a BUFU slot.
- "posi" carries each BUFU slot to a JOBI slot.
- "zaju" is an internal reshuffle of JOBI: it carries each JOBI slot to a JOBI slot.
- "tanu" carries each JOBI slot to a VAVU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sapa" and then "zimu" lands on the same slot as running "sapa" alone.
     ("zimu" leaves every slot that "sapa" produces unchanged.)
R1.2 Running "zimu" and then "liju" gives the same result as running "liju" alone.
     ("liju" cannot tell whether "zimu" was applied first.)
R1.3 Running "zimu" three times in a row leaves every MUKI slot exactly where it started.
R2.1 Running "liju" and then "gaka" lands on the same slot as running "liju" alone.
     ("gaka" leaves every slot that "liju" produces unchanged.)
R2.2 Running "gaka" and then "muti" gives the same result as running "muti" alone.

R3.2 Running "rofu" and then "posi" gives the same result as running "posi" alone.
