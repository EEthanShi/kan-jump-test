You are completing the design of a small toy sorting line with 6 stations.

The stations are: BUJU, TAZI, ROPO, KASA, MAVU, TOVU. Toys move BUJU -> TAZI -> ROPO -> KASA -> MAVU -> TOVU.
There are 9 moving steps:
- "gosa" carries each BUJU slot to a TAZI slot.
- "dibi" is an internal reshuffle of TAZI: it carries each TAZI slot to a TAZI slot.
- "goza" carries each TAZI slot to a ROPO slot.
- "jimi" is an internal reshuffle of ROPO: it carries each ROPO slot to a ROPO slot.
- "rafi" carries each ROPO slot to a KASA slot.
- "vapi" is an internal reshuffle of KASA: it carries each KASA slot to a KASA slot.
- "luga" carries each KASA slot to a MAVU slot.
- "nila" is an internal reshuffle of MAVU: it carries each MAVU slot to a MAVU slot.
- "mula" carries each MAVU slot to a TOVU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "gosa" and then "dibi" lands on the same slot as running "gosa" alone.
     ("dibi" leaves every slot that "gosa" produces unchanged.)
R1.2 Running "dibi" and then "goza" gives the same result as running "goza" alone.
     ("goza" cannot tell whether "dibi" was applied first.)
R1.3 Running "dibi" twice in a row leaves every TAZI slot exactly where it started.
R2.1 Running "goza" and then "jimi" lands on the same slot as running "goza" alone.
     ("jimi" leaves every slot that "goza" produces unchanged.)
R2.2 Running "jimi" and then "rafi" gives the same result as running "rafi" alone.
     ("rafi" cannot tell whether "jimi" was applied first.)
R2.3 Running "jimi" three times in a row leaves every ROPO slot exactly where it started.
R3.1 Running "rafi" and then "vapi" lands on the same slot as running "rafi" alone.
     ("vapi" leaves every slot that "rafi" produces unchanged.)
R3.2 Running "vapi" and then "luga" gives the same result as running "luga" alone.
     ("luga" cannot tell whether "vapi" was applied first.)
R3.3 Running "vapi" twice in a row leaves every KASA slot exactly where it started.
R4.1 Running "luga" and then "nila" lands on the same slot as running "luga" alone.
     ("nila" leaves every slot that "luga" produces unchanged.)
R4.2 Running "nila" and then "mula" gives the same result as running "mula" alone.
     ("mula" cannot tell whether "nila" was applied first.)
R4.3 Running "nila" three times in a row leaves every MAVU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- BUJU has exactly one slot, called n1.
- TOVU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (TAZI, ROPO, KASA, MAVU):
D1.1 TAZI must be a finite set with at most 1 slot.
D1.2 List the "dibi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 ROPO must be a finite set with at most 1 slot.
D2.2 List the "jimi" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 KASA must be a finite set with at most 1 slot.
D3.2 List the "vapi" table entries in slot order q3_1, q3_2, ..., one entry per slot.
D4.1 MAVU must be a finite set with at most 1 slot.
D4.2 List the "nila" table entries in slot order q4_1, q4_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):
