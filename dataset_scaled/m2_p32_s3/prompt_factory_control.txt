You are completing the design of a small toy sorting line with 4 stations.

The stations are: LIKU, FONU, PUVA, NAVO. Toys move LIKU -> FONU -> PUVA -> NAVO.
There are 5 moving steps:
- "dapu" carries each LIKU slot to a FONU slot.
- "pudo" is an internal reshuffle of FONU: it carries each FONU slot to a FONU slot.
- "noma" carries each FONU slot to a PUVA slot.
- "joli" is an internal reshuffle of PUVA: it carries each PUVA slot to a PUVA slot.
- "bovu" carries each PUVA slot to a NAVO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "dapu" and then "pudo" lands on the same slot as running "dapu" alone.
     ("pudo" leaves every slot that "dapu" produces unchanged.)
R1.2 Running "pudo" and then "noma" gives the same result as running "noma" alone.
     ("noma" cannot tell whether "pudo" was applied first.)
R1.3 Running "pudo" three times in a row leaves every FONU slot exactly where it started.
R2.1 Running "noma" and then "joli" lands on the same slot as running "noma" alone.
     ("joli" leaves every slot that "noma" produces unchanged.)
R2.2 Running "joli" and then "bovu" gives the same result as running "bovu" alone.
     ("bovu" cannot tell whether "joli" was applied first.)
R2.3 Running "joli" twice in a row leaves every PUVA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LIKU has exactly one slot, called n1.
- NAVO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FONU, PUVA):
D1.1 FONU must be a finite set with at most 1 slot.
D1.2 List the "pudo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 PUVA must be a finite set with at most 1 slot.
D2.2 List the "joli" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FONU = {q1_1, ..., q1_k}
dapu: n1 -> <FONU slot>
pudo: q1_1 -> <FONU slot>, ..., q1_k -> <FONU slot>
PUVA = {q2_1, ..., q2_k}
noma: q1_1 -> <PUVA slot>, ... (one entry per FONU slot)
joli: q2_1 -> <PUVA slot>, ..., q2_k -> <PUVA slot>
bovu: q2_1 -> <NAVO slot>, ... (one entry per PUVA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
