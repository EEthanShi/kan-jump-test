You are completing the design of a small toy sorting line with 3 stations.

The stations are: NABA, NOMO, GULI. Toys move NABA -> NOMO -> GULI.
There are 3 moving steps:
- "daru" carries each NABA slot to a NOMO slot.
- "bolo" is an internal reshuffle of NOMO: it carries each NOMO slot to a NOMO slot.
- "mari" carries each NOMO slot to a GULI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "daru" and then "bolo" lands on the same slot as running "daru" alone.
     ("bolo" leaves every slot that "daru" produces unchanged.)
R1.2 Running "bolo" and then "mari" gives the same result as running "mari" alone.
     ("mari" cannot tell whether "bolo" was applied first.)
R1.3 Running "bolo" twice in a row leaves every NOMO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NABA has exactly 4 slots, called n1, n2, n3, n4.
- GULI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1.

Requirements for the middle station (NOMO):
D1.1 NOMO must be a finite set with at most 4 slots.
D1.2 List the "bolo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "daru" must carry different NABA slots to different NOMO slots.
D1.4 List the "mari" table entries in NOMO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 6 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

NOMO = {q1_1, ..., q1_k}
daru: n1 -> <NOMO slot>, n2 -> <NOMO slot>, n3 -> <NOMO slot>, n4 -> <NOMO slot>
bolo: q1_1 -> <NOMO slot>, ..., q1_k -> <NOMO slot>
mari: q1_1 -> <GULI slot>, ... (one entry per NOMO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
