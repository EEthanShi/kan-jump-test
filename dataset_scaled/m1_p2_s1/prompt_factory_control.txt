You are completing the design of a small toy sorting line with 3 stations.

The stations are: GAMU, KAJU, MOTI. Toys move GAMU -> KAJU -> MOTI.
There are 3 moving steps:
- "vudu" carries each GAMU slot to a KAJU slot.
- "solu" is an internal reshuffle of KAJU: it carries each KAJU slot to a KAJU slot.
- "mala" carries each KAJU slot to a MOTI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vudu" and then "solu" lands on the same slot as running "vudu" alone.
     ("solu" leaves every slot that "vudu" produces unchanged.)
R1.2 Running "solu" and then "mala" gives the same result as running "mala" alone.
     ("mala" cannot tell whether "solu" was applied first.)
R1.3 Running "solu" twice in a row leaves every KAJU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GAMU has exactly one slot, called n1.
- MOTI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (KAJU):
D1.1 KAJU must be a finite set with at most 1 slot.
D1.2 List the "solu" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KAJU = {q1_1, ..., q1_k}
vudu: n1 -> <KAJU slot>
solu: q1_1 -> <KAJU slot>, ..., q1_k -> <KAJU slot>
mala: q1_1 -> <MOTI slot>, ... (one entry per KAJU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
