You are completing the design of a small toy sorting line with 3 stations.

The stations are: ROJI, DIRO, MIJU. Toys move ROJI -> DIRO -> MIJU.
There are 3 moving steps:
- "bini" carries each ROJI slot to a DIRO slot.
- "zovo" is an internal reshuffle of DIRO: it carries each DIRO slot to a DIRO slot.
- "jumu" carries each DIRO slot to a MIJU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "bini" and then "zovo" lands on the same slot as running "bini" alone.
     ("zovo" leaves every slot that "bini" produces unchanged.)
R1.2 Running "zovo" and then "jumu" gives the same result as running "jumu" alone.
     ("jumu" cannot tell whether "zovo" was applied first.)
R1.3 Running "zovo" twice in a row leaves every DIRO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ROJI has exactly one slot, called n1.
- MIJU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle station (DIRO):
D1.1 DIRO must be a finite set with at most 1 slot.
D1.2 List the "zovo" table entries in slot order q1_1, q1_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

DIRO = {q1_1, ..., q1_k}
bini: n1 -> <DIRO slot>
zovo: q1_1 -> <DIRO slot>, ..., q1_k -> <DIRO slot>
jumu: q1_1 -> <MIJU slot>, ... (one entry per DIRO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
