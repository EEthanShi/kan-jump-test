You are completing the design of a small toy sorting line with 3 stations.

The stations are: ZURU, TIMA, PIDA. Toys move ZURU -> TIMA -> PIDA.
There are 3 moving steps:
- "ladi" carries each ZURU slot to a TIMA slot.
- "motu" is an internal reshuffle of TIMA: it carries each TIMA slot to a TIMA slot.
- "soma" carries each TIMA slot to a PIDA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "ladi" and then "motu" lands on the same slot as running "ladi" alone.
     ("motu" leaves every slot that "ladi" produces unchanged.)
R1.2 Running "motu" and then "soma" gives the same result as running "soma" alone.
     ("soma" cannot tell whether "motu" was applied first.)
R1.3 Running "motu" twice in a row leaves every TIMA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ZURU has exactly 2 slots, called n1, n2.
- PIDA has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1.

Requirements for the middle station (TIMA):
D1.1 List the slots of TIMA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "motu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "ladi" table entries in ZURU slot order n1, n2.
D1.4 List the "soma" table entries in TIMA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 4 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

TIMA = {q1_1, ..., q1_k}
ladi: n1 -> <TIMA slot>, n2 -> <TIMA slot>
motu: q1_1 -> <TIMA slot>, ..., q1_k -> <TIMA slot>
soma: q1_1 -> <PIDA slot>, ... (one entry per TIMA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
