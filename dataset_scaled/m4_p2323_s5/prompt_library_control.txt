You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: VIZU, FOZO, PADI, KOFU, TIDU, LUVA. Books move VIZU -> FOZO -> PADI -> KOFU -> TIDU -> LUVA.
There are 9 moving steps:
- "fiko" carries each VIZU tray to a FOZO tray.
- "bilo" is an internal rearrangement of FOZO: it carries each FOZO tray to a FOZO tray.
- "naso" carries each FOZO tray to a PADI tray.
- "puli" is an internal rearrangement of PADI: it carries each PADI tray to a PADI tray.
- "guji" carries each PADI tray to a KOFU tray.
- "soro" is an internal rearrangement of KOFU: it carries each KOFU tray to a KOFU tray.
- "fazo" carries each KOFU tray to a TIDU tray.
- "joso" is an internal rearrangement of TIDU: it carries each TIDU tray to a TIDU tray.
- "zibo" carries each TIDU tray to a LUVA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "fiko" and then "bilo" lands on the same tray as running "fiko" alone.
     ("bilo" leaves every tray that "fiko" produces unchanged.)
R1.2 Running "bilo" and then "naso" gives the same result as running "naso" alone.
     ("naso" cannot tell whether "bilo" was applied first.)
R1.3 Running "bilo" twice in a row leaves every FOZO tray exactly where it started.
R2.1 Running "naso" and then "puli" lands on the same tray as running "naso" alone.
     ("puli" leaves every tray that "naso" produces unchanged.)
R2.2 Running "puli" and then "guji" gives the same result as running "guji" alone.
     ("guji" cannot tell whether "puli" was applied first.)
R2.3 Running "puli" three times in a row leaves every PADI tray exactly where it started.
R3.1 Running "guji" and then "soro" lands on the same tray as running "guji" alone.
     ("soro" leaves every tray that "guji" produces unchanged.)
R3.2 Running "soro" and then "fazo" gives the same result as running "fazo" alone.
     ("fazo" cannot tell whether "soro" was applied first.)
R3.3 Running "soro" twice in a row leaves every KOFU tray exactly where it started.
R4.1 Running "fazo" and then "joso" lands on the same tray as running "fazo" alone.
     ("joso" leaves every tray that "fazo" produces unchanged.)
R4.2 Running "joso" and then "zibo" gives the same result as running "zibo" alone.
     ("zibo" cannot tell whether "joso" was applied first.)
R4.3 Running "joso" three times in a row leaves every TIDU tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VIZU has exactly one tray, called n1.
- LUVA has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (FOZO, PADI, KOFU, TIDU):
D1.1 FOZO must be a finite set with at most 1 tray.
D1.2 List the "bilo" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 PADI must be a finite set with at most 1 tray.
D2.2 List the "puli" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 KOFU must be a finite set with at most 1 tray.
D3.2 List the "soro" table entries in tray order q3_1, q3_2, ..., one entry per tray.
D4.1 TIDU must be a finite set with at most 1 tray.
D4.2 List the "joso" table entries in tray order q4_1, q4_2, ..., one entry per tray.

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):
