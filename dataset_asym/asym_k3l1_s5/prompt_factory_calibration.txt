You are completing the design of a small toy sorting line with 3 stations.

The stations are: BOZI, LAGA, DIFO. Toys move BOZI -> LAGA -> DIFO.
There are 3 moving steps:
- "jozi" carries each BOZI slot to a LAGA slot.
- "sipu" is an internal reshuffle of LAGA: it carries each LAGA slot to a LAGA slot.
- "tora" carries each LAGA slot to a DIFO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jozi" and then "sipu" lands on the same slot as running "jozi" alone.
     ("sipu" leaves every slot that "jozi" produces unchanged.)
R1.2 Running "sipu" and then "tora" gives the same result as running "tora" alone.
     ("tora" cannot tell whether "sipu" was applied first.)
R1.3 Running "sipu" twice in a row leaves every LAGA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- BOZI has exactly 3 slots, called n1, n2, n3.
- DIFO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (LAGA):
D1.1 List the slots of LAGA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "sipu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "jozi" table entries in BOZI slot order n1, n2, n3.
D1.4 List the "tora" table entries in LAGA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

LAGA = {q1_1, ..., q1_k}
jozi: n1 -> <LAGA slot>, n2 -> <LAGA slot>, n3 -> <LAGA slot>
sipu: q1_1 -> <LAGA slot>, ..., q1_k -> <LAGA slot>
tora: q1_1 -> <DIFO slot>, ... (one entry per LAGA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
