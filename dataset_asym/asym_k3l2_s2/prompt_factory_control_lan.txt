You are completing the design of a small toy sorting line with 3 stations.

The stations are: MOJU, NASU, LOFU. Toys move MOJU -> NASU -> LOFU.
There are 3 moving steps:
- "lina" carries each MOJU slot to a NASU slot.
- "noto" is an internal reshuffle of NASU: it carries each NASU slot to a NASU slot.
- "joja" carries each NASU slot to a LOFU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "lina" and then "noto" lands on the same slot as running "lina" alone.
     ("noto" leaves every slot that "lina" produces unchanged.)
R1.2 Running "noto" and then "joja" gives the same result as running "joja" alone.
     ("joja" cannot tell whether "noto" was applied first.)
R1.3 Running "noto" twice in a row leaves every NASU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- MOJU has exactly 3 slots, called n1, n2, n3.
- LOFU has exactly 2 slots, called s1, s2.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (NASU):
D1.1 NASU must be a finite set with at most 3 slots.
D1.2 List the "noto" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "lina" must carry different MOJU slots to different NASU slots.
D1.4 List the "joja" table entries in NASU slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

NASU = {q1_1, ..., q1_k}
lina: n1 -> <NASU slot>, n2 -> <NASU slot>, n3 -> <NASU slot>
noto: q1_1 -> <NASU slot>, ..., q1_k -> <NASU slot>
joja: q1_1 -> <LOFU slot>, ... (one entry per NASU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
