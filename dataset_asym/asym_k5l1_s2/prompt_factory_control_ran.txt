You are completing the design of a small toy sorting line with 3 stations.

The stations are: NINO, SAZO, TUVI. Toys move NINO -> SAZO -> TUVI.
There are 3 moving steps:
- "basa" carries each NINO slot to a SAZO slot.
- "vuvo" is an internal reshuffle of SAZO: it carries each SAZO slot to a SAZO slot.
- "vaki" carries each SAZO slot to a TUVI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "basa" and then "vuvo" lands on the same slot as running "basa" alone.
     ("vuvo" leaves every slot that "basa" produces unchanged.)
R1.2 Running "vuvo" and then "vaki" gives the same result as running "vaki" alone.
     ("vaki" cannot tell whether "vuvo" was applied first.)
R1.3 Running "vuvo" twice in a row leaves every SAZO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NINO has exactly 5 slots, called n1, n2, n3, n4, n5.
- TUVI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (SAZO):
D1.1 SAZO must be a finite set with at most 1 slot.
D1.2 List the "vuvo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "basa" table entries in NINO slot order n1, n2, n3, n4, n5.
D1.4 Every TUVI slot must be reached by "vaki" from at least one SAZO slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

SAZO = {q1_1, ..., q1_k}
basa: n1 -> <SAZO slot>, n2 -> <SAZO slot>, n3 -> <SAZO slot>, n4 -> <SAZO slot>, n5 -> <SAZO slot>
vuvo: q1_1 -> <SAZO slot>, ..., q1_k -> <SAZO slot>
vaki: q1_1 -> <TUVI slot>, ... (one entry per SAZO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
