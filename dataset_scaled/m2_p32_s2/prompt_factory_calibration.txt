You are completing the design of a small toy sorting line with 4 stations.

The stations are: SILI, VASU, JIVO, SUJA. Toys move SILI -> VASU -> JIVO -> SUJA.
There are 5 moving steps:
- "vilu" carries each SILI slot to a VASU slot.
- "raza" is an internal reshuffle of VASU: it carries each VASU slot to a VASU slot.
- "fumu" carries each VASU slot to a JIVO slot.
- "tido" is an internal reshuffle of JIVO: it carries each JIVO slot to a JIVO slot.
- "nuvi" carries each JIVO slot to a SUJA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vilu" and then "raza" lands on the same slot as running "vilu" alone.
     ("raza" leaves every slot that "vilu" produces unchanged.)
R1.2 Running "raza" and then "fumu" gives the same result as running "fumu" alone.
     ("fumu" cannot tell whether "raza" was applied first.)
R1.3 Running "raza" three times in a row leaves every VASU slot exactly where it started.
R2.1 Running "fumu" and then "tido" lands on the same slot as running "fumu" alone.
     ("tido" leaves every slot that "fumu" produces unchanged.)
R2.2 Running "tido" and then "nuvi" gives the same result as running "nuvi" alone.
     ("nuvi" cannot tell whether "tido" was applied first.)
R2.3 Running "tido" twice in a row leaves every JIVO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SILI has exactly one slot, called n1.
- SUJA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (VASU, JIVO):
D1.1 List the slots of VASU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "raza" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of JIVO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "tido" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

VASU = {q1_1, ..., q1_k}
vilu: n1 -> <VASU slot>
raza: q1_1 -> <VASU slot>, ..., q1_k -> <VASU slot>
JIVO = {q2_1, ..., q2_k}
fumu: q1_1 -> <JIVO slot>, ... (one entry per VASU slot)
tido: q2_1 -> <JIVO slot>, ..., q2_k -> <JIVO slot>
nuvi: q2_1 -> <SUJA slot>, ... (one entry per JIVO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
