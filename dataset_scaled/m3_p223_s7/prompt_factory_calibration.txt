You are completing the design of a small toy sorting line with 5 stations.

The stations are: RUDA, NISA, GOMO, TUMI, KOTI. Toys move RUDA -> NISA -> GOMO -> TUMI -> KOTI.
There are 7 moving steps:
- "rura" carries each RUDA slot to a NISA slot.
- "pino" is an internal reshuffle of NISA: it carries each NISA slot to a NISA slot.
- "jiza" carries each NISA slot to a GOMO slot.
- "fopo" is an internal reshuffle of GOMO: it carries each GOMO slot to a GOMO slot.
- "pabu" carries each GOMO slot to a TUMI slot.
- "jani" is an internal reshuffle of TUMI: it carries each TUMI slot to a TUMI slot.
- "kuti" carries each TUMI slot to a KOTI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "rura" and then "pino" lands on the same slot as running "rura" alone.
     ("pino" leaves every slot that "rura" produces unchanged.)
R1.2 Running "pino" and then "jiza" gives the same result as running "jiza" alone.
     ("jiza" cannot tell whether "pino" was applied first.)
R1.3 Running "pino" twice in a row leaves every NISA slot exactly where it started.
R2.1 Running "jiza" and then "fopo" lands on the same slot as running "jiza" alone.
     ("fopo" leaves every slot that "jiza" produces unchanged.)
R2.2 Running "fopo" and then "pabu" gives the same result as running "pabu" alone.
     ("pabu" cannot tell whether "fopo" was applied first.)
R2.3 Running "fopo" twice in a row leaves every GOMO slot exactly where it started.
R3.1 Running "pabu" and then "jani" lands on the same slot as running "pabu" alone.
     ("jani" leaves every slot that "pabu" produces unchanged.)
R3.2 Running "jani" and then "kuti" gives the same result as running "kuti" alone.
     ("kuti" cannot tell whether "jani" was applied first.)
R3.3 Running "jani" three times in a row leaves every TUMI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUDA has exactly one slot, called n1.
- KOTI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (NISA, GOMO, TUMI):
D1.1 List the slots of NISA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "pino" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of GOMO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "fopo" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of TUMI in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "jani" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

NISA = {q1_1, ..., q1_k}
rura: n1 -> <NISA slot>
pino: q1_1 -> <NISA slot>, ..., q1_k -> <NISA slot>
GOMO = {q2_1, ..., q2_k}
jiza: q1_1 -> <GOMO slot>, ... (one entry per NISA slot)
fopo: q2_1 -> <GOMO slot>, ..., q2_k -> <GOMO slot>
TUMI = {q3_1, ..., q3_k}
pabu: q2_1 -> <TUMI slot>, ... (one entry per GOMO slot)
jani: q3_1 -> <TUMI slot>, ..., q3_k -> <TUMI slot>
kuti: q3_1 -> <KOTI slot>, ... (one entry per TUMI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
