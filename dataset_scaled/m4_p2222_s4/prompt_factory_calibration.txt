You are completing the design of a small toy sorting line with 6 stations.

The stations are: LIJO, KAKI, PISI, MOSI, JUFU, PAGO. Toys move LIJO -> KAKI -> PISI -> MOSI -> JUFU -> PAGO.
There are 9 moving steps:
- "losa" carries each LIJO slot to a KAKI slot.
- "koza" is an internal reshuffle of KAKI: it carries each KAKI slot to a KAKI slot.
- "koso" carries each KAKI slot to a PISI slot.
- "banu" is an internal reshuffle of PISI: it carries each PISI slot to a PISI slot.
- "sudu" carries each PISI slot to a MOSI slot.
- "zona" is an internal reshuffle of MOSI: it carries each MOSI slot to a MOSI slot.
- "sutu" carries each MOSI slot to a JUFU slot.
- "jibu" is an internal reshuffle of JUFU: it carries each JUFU slot to a JUFU slot.
- "kato" carries each JUFU slot to a PAGO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "losa" and then "koza" lands on the same slot as running "losa" alone.
     ("koza" leaves every slot that "losa" produces unchanged.)
R1.2 Running "koza" and then "koso" gives the same result as running "koso" alone.
     ("koso" cannot tell whether "koza" was applied first.)
R1.3 Running "koza" twice in a row leaves every KAKI slot exactly where it started.
R2.1 Running "koso" and then "banu" lands on the same slot as running "koso" alone.
     ("banu" leaves every slot that "koso" produces unchanged.)
R2.2 Running "banu" and then "sudu" gives the same result as running "sudu" alone.
     ("sudu" cannot tell whether "banu" was applied first.)
R2.3 Running "banu" twice in a row leaves every PISI slot exactly where it started.
R3.1 Running "sudu" and then "zona" lands on the same slot as running "sudu" alone.
     ("zona" leaves every slot that "sudu" produces unchanged.)
R3.2 Running "zona" and then "sutu" gives the same result as running "sutu" alone.
     ("sutu" cannot tell whether "zona" was applied first.)
R3.3 Running "zona" twice in a row leaves every MOSI slot exactly where it started.
R4.1 Running "sutu" and then "jibu" lands on the same slot as running "sutu" alone.

R4.2 Running "jibu" and then "kato" gives the same result as running "kato" alone.
     ("kato" cannot tell whether "jibu" was applied first.)
