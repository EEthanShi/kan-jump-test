You are completing the design of a small toy sorting line with 6 stations.

The stations are: RUBU, KUKI, BASO, FUJU, PIZA, NIJU. Toys move RUBU -> KUKI -> BASO -> FUJU -> PIZA -> NIJU.
There are 9 moving steps:
- "livu" carries each RUBU slot to a KUKI slot.
- "tija" is an internal reshuffle of KUKI: it carries each KUKI slot to a KUKI slot.
- "timi" carries each KUKI slot to a BASO slot.
- "riju" is an internal reshuffle of BASO: it carries each BASO slot to a BASO slot.
- "buzu" carries each BASO slot to a FUJU slot.
- "loju" is an internal reshuffle of FUJU: it carries each FUJU slot to a FUJU slot.
- "noma" carries each FUJU slot to a PIZA slot.
- "tojo" is an internal reshuffle of PIZA: it carries each PIZA slot to a PIZA slot.
- "ponu" carries each PIZA slot to a NIJU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "livu" and then "tija" lands on the same slot as running "livu" alone.
     ("tija" leaves every slot that "livu" produces unchanged.)
R1.2 Running "tija" and then "timi" gives the same result as running "timi" alone.
     ("timi" cannot tell whether "tija" was applied first.)
R1.3 Running "tija" twice in a row leaves every KUKI slot exactly where it started.
R2.1 Running "timi" and then "riju" lands on the same slot as running "timi" alone.
     ("riju" leaves every slot that "timi" produces unchanged.)
R2.2 Running "riju" and then "buzu" gives the same result as running "buzu" alone.
     ("buzu" cannot tell whether "riju" was applied first.)
R2.3 Running "riju" twice in a row leaves every BASO slot exactly where it started.
R3.1 Running "buzu" and then "loju" lands on the same slot as running "buzu" alone.
     ("loju" leaves every slot that "buzu" produces unchanged.)
R3.2 Running "loju" and then "noma" gives the same result as running "noma" alone.
     ("noma" cannot tell whether "loju" was applied first.)
R3.3 Running "loju" twice in a row leaves every FUJU slot exactly where it started.
R4.1 Running "noma" and then "tojo" lands on the same slot as running "noma" alone.
     ("tojo" leaves every slot that "noma" produces unchanged.)
R4.2 Running "tojo" and then "ponu" gives the same result as running "ponu" alone.
     ("ponu" cannot tell whether "tojo" was applied first.)
R4.3 Running "tojo" twice in a row leaves every PIZA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUBU has exactly one slot, called n1.
- NIJU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (KUKI, BASO, FUJU, PIZA):
D1.1 KUKI must be a finite set with at most 1 slot.
D1.2 List the "tija" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 BASO must be a finite set with at most 1 slot.
D2.2 List the "riju" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 FUJU must be a finite set with at most 1 slot.
D3.2 List the "loju" table entries in slot order q3_1, q3_2, ..., one entry per slot.
D4.1 PIZA must be a finite set with at most 1 slot.
D4.2 List the "tojo" table entries in slot order q4_1, q4_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

KUKI = {q1_1, ..., q1_k}
livu: n1 -> <KUKI slot>

FUJU = {q3_1, ..., q3_k}

PIZA = {q4_1, ..., q4_k}
