You are completing the design of a small book sorting row of carts with 5 carts.

The carts are: LIVO, SUGO, KOFU, FAJA, GOVA. Books move LIVO -> SUGO -> KOFU -> FAJA -> GOVA.
There are 7 moving steps:
- "vuzi" carries each LIVO tray to a SUGO tray.
- "loma" is an internal rearrangement of SUGO: it carries each SUGO tray to a SUGO tray.
- "sima" carries each SUGO tray to a KOFU tray.
- "luga" is an internal rearrangement of KOFU: it carries each KOFU tray to a KOFU tray.
- "diti" carries each KOFU tray to a FAJA tray.
- "gubi" is an internal rearrangement of FAJA: it carries each FAJA tray to a FAJA tray.
- "misi" carries each FAJA tray to a GOVA tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "vuzi" and then "loma" lands on the same tray as running "vuzi" alone.
     ("loma" leaves every tray that "vuzi" produces unchanged.)
R1.2 Running "loma" and then "sima" gives the same result as running "sima" alone.
     ("sima" cannot tell whether "loma" was applied first.)
R1.3 Running "loma" three times in a row leaves every SUGO tray exactly where it started.
R2.1 Running "sima" and then "luga" lands on the same tray as running "sima" alone.
     ("luga" leaves every tray that "sima" produces unchanged.)
R2.2 Running "luga" and then "diti" gives the same result as running "diti" alone.
     ("diti" cannot tell whether "luga" was applied first.)
R2.3 Running "luga" twice in a row leaves every KOFU tray exactly where it started.
R3.1 Running "diti" and then "gubi" lands on the same tray as running "diti" alone.
     ("gubi" leaves every tray that "diti" produces unchanged.)
R3.2 Running "gubi" and then "misi" gives the same result as running "misi" alone.
     ("misi" cannot tell whether "gubi" was applied first.)
R3.3 Running "gubi" three times in a row leaves every FAJA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LIVO has exactly one tray, called n1.
- GOVA has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (SUGO, KOFU, FAJA):
D1.1 SUGO must be a finite set with at most 4 trays.
D1.2 "loma" must NOT be the do-nothing move (it must move at least one SUGO tray).
D2.1 KOFU must be a finite set with at most 3 trays.
D2.2 "luga" must NOT be the do-nothing move (it must move at least one KOFU tray).
D3.1 FAJA must be a finite set with at most 4 trays.
D3.2 "gubi" must NOT be the do-nothing move (it must move at least one FAJA tray).

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 5 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

SUGO = {q1_1, ..., q1_k}
vuzi: n1 -> <SUGO tray>
loma: q1_1 -> <SUGO tray>, ..., q1_k -> <SUGO tray>
KOFU = {q2_1, ..., q2_k}
sima: q1_1 -> <KOFU tray>, ... (one entry per SUGO tray)
luga: q2_1 -> <KOFU tray>, ..., q2_k -> <KOFU tray>
FAJA = {q3_1, ..., q3_k}
diti: q2_1 -> <FAJA tray>, ... (one entry per KOFU tray)
gubi: q3_1 -> <FAJA tray>, ..., q3_k -> <FAJA tray>
misi: q3_1 -> <GOVA tray>, ... (one entry per FAJA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
