You are completing the design of a small toy sorting line with 5 stations.

The stations are: VAKI, BIKO, GUZO, GAVI, BOVI. Toys move VAKI -> BIKO -> GUZO -> GAVI -> BOVI.
There are 7 moving steps:
- "toso" carries each VAKI slot to a BIKO slot.
- "sijo" is an internal reshuffle of BIKO: it carries each BIKO slot to a BIKO slot.
- "mina" carries each BIKO slot to a GUZO slot.
- "pufu" is an internal reshuffle of GUZO: it carries each GUZO slot to a GUZO slot.
- "dalo" carries each GUZO slot to a GAVI slot.
- "rilo" is an internal reshuffle of GAVI: it carries each GAVI slot to a GAVI slot.
- "tovo" carries each GAVI slot to a BOVI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "toso" and then "sijo" lands on the same slot as running "toso" alone.
     ("sijo" leaves every slot that "toso" produces unchanged.)
R1.2 Running "sijo" and then "mina" gives the same result as running "mina" alone.
     ("mina" cannot tell whether "sijo" was applied first.)
R1.3 Running "sijo" three times in a row leaves every BIKO slot exactly where it started.
R2.1 Running "mina" and then "pufu" lands on the same slot as running "mina" alone.
     ("pufu" leaves every slot that "mina" produces unchanged.)
R2.2 Running "pufu" and then "dalo" gives the same result as running "dalo" alone.
     ("dalo" cannot tell whether "pufu" was applied first.)
R2.3 Running "pufu" three times in a row leaves every GUZO slot exactly where it started.
R3.1 Running "dalo" and then "rilo" lands on the same slot as running "dalo" alone.
     ("rilo" leaves every slot that "dalo" produces unchanged.)
R3.2 Running "rilo" and then "tovo" gives the same result as running "tovo" alone.
     ("tovo" cannot tell whether "rilo" was applied first.)
R3.3 Running "rilo" three times in a row leaves every GAVI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VAKI has exactly one slot, called n1.
- BOVI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (BIKO, GUZO, GAVI):
D1.1 BIKO must be a finite set with at most 1 slot.
D1.2 List the "sijo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 GUZO must be a finite set with at most 1 slot.
D2.2 List the "pufu" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 GAVI must be a finite set with at most 1 slot.
D3.2 List the "rilo" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

BIKO = {q1_1, ..., q1_k}
toso: n1 -> <BIKO slot>
sijo: q1_1 -> <BIKO slot>, ..., q1_k -> <BIKO slot>
GUZO = {q2_1, ..., q2_k}
mina: q1_1 -> <GUZO slot>, ... (one entry per BIKO slot)
pufu: q2_1 -> <GUZO slot>, ..., q2_k -> <GUZO slot>
GAVI = {q3_1, ..., q3_k}
dalo: q2_1 -> <GAVI slot>, ... (one entry per GUZO slot)
rilo: q3_1 -> <GAVI slot>, ..., q3_k -> <GAVI slot>
tovo: q3_1 -> <BOVI slot>, ... (one entry per GAVI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
