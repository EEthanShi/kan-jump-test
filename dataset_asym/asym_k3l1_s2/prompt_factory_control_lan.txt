You are completing the design of a small toy sorting line with 3 stations.

The stations are: DAKI, MURA, DAMI. Toys move DAKI -> MURA -> DAMI.
There are 3 moving steps:
- "roru" carries each DAKI slot to a MURA slot.
- "musu" is an internal reshuffle of MURA: it carries each MURA slot to a MURA slot.
- "figu" carries each MURA slot to a DAMI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "roru" and then "musu" lands on the same slot as running "roru" alone.
     ("musu" leaves every slot that "roru" produces unchanged.)
R1.2 Running "musu" and then "figu" gives the same result as running "figu" alone.
     ("figu" cannot tell whether "musu" was applied first.)
R1.3 Running "musu" twice in a row leaves every MURA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DAKI has exactly 3 slots, called n1, n2, n3.
- DAMI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (MURA):
D1.1 MURA must be a finite set with at most 3 slots.
D1.2 List the "musu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "roru" must carry different DAKI slots to different MURA slots.
D1.4 List the "figu" table entries in MURA slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

MURA = {q1_1, ..., q1_k}
roru: n1 -> <MURA slot>, n2 -> <MURA slot>, n3 -> <MURA slot>
musu: q1_1 -> <MURA slot>, ..., q1_k -> <MURA slot>
figu: q1_1 -> <DAMI slot>, ... (one entry per MURA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
