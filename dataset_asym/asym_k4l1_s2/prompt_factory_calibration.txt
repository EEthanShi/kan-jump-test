You are completing the design of a small toy sorting line with 3 stations.

The stations are: NALA, ZARU, GAJO. Toys move NALA -> ZARU -> GAJO.
There are 3 moving steps:
- "fadu" carries each NALA slot to a ZARU slot.
- "dola" is an internal reshuffle of ZARU: it carries each ZARU slot to a ZARU slot.
- "diru" carries each ZARU slot to a GAJO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "fadu" and then "dola" lands on the same slot as running "fadu" alone.
     ("dola" leaves every slot that "fadu" produces unchanged.)
R1.2 Running "dola" and then "diru" gives the same result as running "diru" alone.
     ("diru" cannot tell whether "dola" was applied first.)
R1.3 Running "dola" twice in a row leaves every ZARU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- NALA has exactly 4 slots, called n1, n2, n3, n4.
- GAJO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1.

Requirements for the middle station (ZARU):
D1.1 List the slots of ZARU in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "dola" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "fadu" table entries in NALA slot order n1, n2, n3, n4.
D1.4 List the "diru" table entries in ZARU slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 6 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

ZARU = {q1_1, ..., q1_k}
fadu: n1 -> <ZARU slot>, n2 -> <ZARU slot>, n3 -> <ZARU slot>, n4 -> <ZARU slot>
dola: q1_1 -> <ZARU slot>, ..., q1_k -> <ZARU slot>
diru: q1_1 -> <GAJO slot>, ... (one entry per ZARU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
