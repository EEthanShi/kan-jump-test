You are completing the design of a small book sorting row of carts with 6 carts.

The carts are: LALA, ZANI, PUKI, JOVU, SOMA, LINO. Books move LALA -> ZANI -> PUKI -> JOVU -> SOMA -> LINO.
There are 9 moving steps:
- "gifo" carries each LALA tray to a ZANI tray.
- "mibu" is an internal rearrangement of ZANI: it carries each ZANI tray to a ZANI tray.
- "lajo" carries each ZANI tray to a PUKI tray.
- "tulu" is an internal rearrangement of PUKI: it carries each PUKI tray to a PUKI tray.
- "jubu" carries each PUKI tray to a JOVU tray.
- "sini" is an internal rearrangement of JOVU: it carries each JOVU tray to a JOVU tray.
- "fiza" carries each JOVU tray to a SOMA tray.
- "bigu" is an internal rearrangement of SOMA: it carries each SOMA tray to a SOMA tray.
- "dufa" carries each SOMA tray to a LINO tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "gifo" and then "mibu" lands on the same tray as running "gifo" alone.
     ("mibu" leaves every tray that "gifo" produces unchanged.)
R1.2 Running "mibu" and then "lajo" gives the same result as running "lajo" alone.
     ("lajo" cannot tell whether "mibu" was applied first.)
R1.3 Running "mibu" three times in a row leaves every ZANI tray exactly where it started.
R2.1 Running "lajo" and then "tulu" lands on the same tray as running "lajo" alone.
     ("tulu" leaves every tray that "lajo" produces unchanged.)
R2.2 Running "tulu" and then "jubu" gives the same result as running "jubu" alone.
     ("jubu" cannot tell whether "tulu" was applied first.)
R2.3 Running "tulu" twice in a row leaves every PUKI tray exactly where it started.
R3.1 Running "jubu" and then "sini" lands on the same tray as running "jubu" alone.
     ("sini" leaves every tray that "jubu" produces unchanged.)
R3.2 Running "sini" and then "fiza" gives the same result as running "fiza" alone.
     ("fiza" cannot tell whether "sini" was applied first.)
R3.3 Running "sini" three times in a row leaves every JOVU tray exactly where it started.
R4.1 Running "fiza" and then "bigu" lands on the same tray as running "fiza" alone.
     ("bigu" leaves every tray that "fiza" produces unchanged.)
R4.2 Running "bigu" and then "dufa" gives the same result as running "dufa" alone.
     ("dufa" cannot tell whether "bigu" was applied first.)
R4.3 Running "bigu" twice in a row leaves every SOMA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- LALA has exactly one tray, called n1.
- LINO has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (ZANI, PUKI, JOVU, SOMA):
D1.1 List the trays of ZANI in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "mibu" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D2.1 List the trays of PUKI in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "tulu" table entries in tray order q2_1, q2_2, ..., one entry per tray.
D3.1 List the trays of JOVU in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "sini" table entries in tray order q3_1, q3_2, ..., one entry per tray.
D4.1 List the trays of SOMA in increasing index order q4_1, q4_2, ... in its set line.
D4.2 List the "bigu" table entries in tray order q4_1, q4_2, ..., one entry per tray.
