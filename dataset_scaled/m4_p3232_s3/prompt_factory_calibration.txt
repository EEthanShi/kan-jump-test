You are completing the design of a small toy sorting line with 6 stations.

The stations are: PABI, SUZA, ZILO, FAJA, KABO, LAGU. Toys move PABI -> SUZA -> ZILO -> FAJA -> KABO -> LAGU.
There are 9 moving steps:
- "zoma" carries each PABI slot to a SUZA slot.
- "koki" is an internal reshuffle of SUZA: it carries each SUZA slot to a SUZA slot.
- "tusu" carries each SUZA slot to a ZILO slot.
- "nalo" is an internal reshuffle of ZILO: it carries each ZILO slot to a ZILO slot.
- "doku" carries each ZILO slot to a FAJA slot.
- "pufo" is an internal reshuffle of FAJA: it carries each FAJA slot to a FAJA slot.
- "bazi" carries each FAJA slot to a KABO slot.
- "favi" is an internal reshuffle of KABO: it carries each KABO slot to a KABO slot.
- "roso" carries each KABO slot to a LAGU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "zoma" and then "koki" lands on the same slot as running "zoma" alone.
     ("koki" leaves every slot that "zoma" produces unchanged.)
R1.2 Running "koki" and then "tusu" gives the same result as running "tusu" alone.
     ("tusu" cannot tell whether "koki" was applied first.)
R1.3 Running "koki" three times in a row leaves every SUZA slot exactly where it started.
R2.1 Running "tusu" and then "nalo" lands on the same slot as running "tusu" alone.
     ("nalo" leaves every slot that "tusu" produces unchanged.)
R2.2 Running "nalo" and then "doku" gives the same result as running "doku" alone.
     ("doku" cannot tell whether "nalo" was applied first.)
R2.3 Running "nalo" twice in a row leaves every ZILO slot exactly where it started.
R3.1 Running "doku" and then "pufo" lands on the same slot as running "doku" alone.
     ("pufo" leaves every slot that "doku" produces unchanged.)
R3.2 Running "pufo" and then "bazi" gives the same result as running "bazi" alone.
     ("bazi" cannot tell whether "pufo" was applied first.)
R3.3 Running "pufo" three times in a row leaves every FAJA slot exactly where it started.
R4.1 Running "bazi" and then "favi" lands on the same slot as running "bazi" alone.
     ("favi" leaves every slot that "bazi" produces unchanged.)
R4.2 Running "favi" and then "roso" gives the same result as running "roso" alone.
     ("roso" cannot tell whether "favi" was applied first.)
R4.3 Running "favi" twice in a row leaves every KABO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PABI has exactly one slot, called n1.
- LAGU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (SUZA, ZILO, FAJA, KABO):
D1.1 List the slots of SUZA in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "koki" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of ZILO in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "nalo" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 List the slots of FAJA in increasing index order q3_1, q3_2, ... in its set line.
D3.2 List the "pufo" table entries in slot order q3_1, q3_2, ..., one entry per slot.
D4.1 List the slots of KABO in increasing index order q4_1, q4_2, ... in its set line.
D4.2 List the "favi" table entries in slot order q4_1, q4_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.
