You are completing the design of a small book sorting row of carts with 5 carts.

The carts are: RALU, BASO, FAVI, KUJA, GUSO. Books move RALU -> BASO -> FAVI -> KUJA -> GUSO.
There are 7 moving steps:
- "moso" carries each RALU tray to a BASO tray.
- "kati" is an internal rearrangement of BASO: it carries each BASO tray to a BASO tray.
- "tiko" carries each BASO tray to a FAVI tray.
- "gata" is an internal rearrangement of FAVI: it carries each FAVI tray to a FAVI tray.
- "vuri" carries each FAVI tray to a KUJA tray.
- "jitu" is an internal rearrangement of KUJA: it carries each KUJA tray to a KUJA tray.
- "sanu" carries each KUJA tray to a GUSO tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "moso" and then "kati" lands on the same tray as running "moso" alone.
     ("kati" leaves every tray that "moso" produces unchanged.)
R1.2 Running "kati" and then "tiko" gives the same result as running "tiko" alone.
     ("tiko" cannot tell whether "kati" was applied first.)
R1.3 Running "kati" three times in a row leaves every BASO tray exactly where it started.
R2.1 Running "tiko" and then "gata" lands on the same tray as running "tiko" alone.
     ("gata" leaves every tray that "tiko" produces unchanged.)
R2.2 Running "gata" and then "vuri" gives the same result as running "vuri" alone.
     ("vuri" cannot tell whether "gata" was applied first.)
R2.3 Running "gata" twice in a row leaves every FAVI tray exactly where it started.
R3.1 Running "vuri" and then "jitu" lands on the same tray as running "vuri" alone.
     ("jitu" leaves every tray that "vuri" produces unchanged.)
R3.2 Running "jitu" and then "sanu" gives the same result as running "sanu" alone.
     ("sanu" cannot tell whether "jitu" was applied first.)
R3.3 Running "jitu" twice in a row leaves every KUJA tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RALU has exactly one tray, called n1.
- GUSO has exactly one tray, called s1.
- The observed end-to-end behavior of the row sends n1 to s1.

Requirements for the middle carts (BASO, FAVI, KUJA):
D1.1 BASO must be a finite set with at most 4 trays.
D1.2 "kati" must NOT be the do-nothing move (it must move at least one BASO tray).
D2.1 FAVI must be a finite set with at most 3 trays.
D2.2 "gata" must NOT be the do-nothing move (it must move at least one FAVI tray).
D3.1 KUJA must be a finite set with at most 3 trays.
D3.2 "jitu" must NOT be the do-nothing move (it must move at least one KUJA tray).

Your task: give one complete concrete design of the middle carts.

Answer format bound: designs with up to 4 trays per middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
for cart number i in the row, use tray names qi_1, qi_2, ...):

BASO = {q1_1, ..., q1_k}
moso: n1 -> <BASO tray>
kati: q1_1 -> <BASO tray>, ..., q1_k -> <BASO tray>
FAVI = {q2_1, ..., q2_k}
tiko: q1_1 -> <FAVI tray>, ... (one entry per BASO tray)
gata: q2_1 -> <FAVI tray>, ..., q2_k -> <FAVI tray>
KUJA = {q3_1, ..., q3_k}
vuri: q2_1 -> <KUJA tray>, ... (one entry per FAVI tray)
jitu: q3_1 -> <KUJA tray>, ..., q3_k -> <KUJA tray>
sanu: q3_1 -> <GUSO tray>, ... (one entry per KUJA tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
