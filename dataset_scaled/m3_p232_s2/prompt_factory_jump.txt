You are completing the design of a small toy sorting line with 5 stations.

The stations are: PUPU, SOBU, FIRU, PIMU, LOTU. Toys move PUPU -> SOBU -> FIRU -> PIMU -> LOTU.
There are 7 moving steps:
- "sutu" carries each PUPU slot to a SOBU slot.
- "bonu" is an internal reshuffle of SOBU: it carries each SOBU slot to a SOBU slot.
- "solu" carries each SOBU slot to a FIRU slot.
- "raka" is an internal reshuffle of FIRU: it carries each FIRU slot to a FIRU slot.
- "muzo" carries each FIRU slot to a PIMU slot.
- "tupa" is an internal reshuffle of PIMU: it carries each PIMU slot to a PIMU slot.
- "vona" carries each PIMU slot to a LOTU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sutu" and then "bonu" lands on the same slot as running "sutu" alone.
     ("bonu" leaves every slot that "sutu" produces unchanged.)
R1.2 Running "bonu" and then "solu" gives the same result as running "solu" alone.
     ("solu" cannot tell whether "bonu" was applied first.)
R1.3 Running "bonu" twice in a row leaves every SOBU slot exactly where it started.
R2.1 Running "solu" and then "raka" lands on the same slot as running "solu" alone.
     ("raka" leaves every slot that "solu" produces unchanged.)
R2.2 Running "raka" and then "muzo" gives the same result as running "muzo" alone.
     ("muzo" cannot tell whether "raka" was applied first.)
R2.3 Running "raka" three times in a row leaves every FIRU slot exactly where it started.
R3.1 Running "muzo" and then "tupa" lands on the same slot as running "muzo" alone.
     ("tupa" leaves every slot that "muzo" produces unchanged.)
R3.2 Running "tupa" and then "vona" gives the same result as running "vona" alone.
     ("vona" cannot tell whether "tupa" was applied first.)
R3.3 Running "tupa" twice in a row leaves every PIMU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PUPU has exactly one slot, called n1.
- LOTU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (SOBU, FIRU, PIMU):
D1.1 SOBU must be a finite set with at most 3 slots.
D1.2 "bonu" must NOT be the do-nothing move (it must move at least one SOBU slot).
D2.1 FIRU must be a finite set with at most 4 slots.
D2.2 "raka" must NOT be the do-nothing move (it must move at least one FIRU slot).
D3.1 PIMU must be a finite set with at most 3 slots.
D3.2 "tupa" must NOT be the do-nothing move (it must move at least one PIMU slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

SOBU = {q1_1, ..., q1_k}
sutu: n1 -> <SOBU slot>
bonu: q1_1 -> <SOBU slot>, ..., q1_k -> <SOBU slot>
FIRU = {q2_1, ..., q2_k}
solu: q1_1 -> <FIRU slot>, ... (one entry per SOBU slot)
raka: q2_1 -> <FIRU slot>, ..., q2_k -> <FIRU slot>
PIMU = {q3_1, ..., q3_k}
muzo: q2_1 -> <PIMU slot>, ... (one entry per FIRU slot)
tupa: q3_1 -> <PIMU slot>, ..., q3_k -> <PIMU slot>
vona: q3_1 -> <LOTU slot>, ... (one entry per PIMU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
