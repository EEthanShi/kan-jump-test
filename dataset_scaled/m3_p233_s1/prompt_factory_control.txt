You are completing the design of a small toy sorting line with 5 stations.

The stations are: FULI, FAMU, VIFU, MIKI, PIPU. Toys move FULI -> FAMU -> VIFU -> MIKI -> PIPU.
There are 7 moving steps:
- "sivo" carries each FULI slot to a FAMU slot.
- "fovo" is an internal reshuffle of FAMU: it carries each FAMU slot to a FAMU slot.
- "zama" carries each FAMU slot to a VIFU slot.
- "lika" is an internal reshuffle of VIFU: it carries each VIFU slot to a VIFU slot.
- "vabo" carries each VIFU slot to a MIKI slot.
- "fugi" is an internal reshuffle of MIKI: it carries each MIKI slot to a MIKI slot.
- "guji" carries each MIKI slot to a PIPU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "sivo" and then "fovo" lands on the same slot as running "sivo" alone.
     ("fovo" leaves every slot that "sivo" produces unchanged.)
R1.2 Running "fovo" and then "zama" gives the same result as running "zama" alone.
     ("zama" cannot tell whether "fovo" was applied first.)
R1.3 Running "fovo" twice in a row leaves every FAMU slot exactly where it started.
R2.1 Running "zama" and then "lika" lands on the same slot as running "zama" alone.
     ("lika" leaves every slot that "zama" produces unchanged.)
R2.2 Running "lika" and then "vabo" gives the same result as running "vabo" alone.
     ("vabo" cannot tell whether "lika" was applied first.)
R2.3 Running "lika" three times in a row leaves every VIFU slot exactly where it started.
R3.1 Running "vabo" and then "fugi" lands on the same slot as running "vabo" alone.
     ("fugi" leaves every slot that "vabo" produces unchanged.)
R3.2 Running "fugi" and then "guji" gives the same result as running "guji" alone.
     ("guji" cannot tell whether "fugi" was applied first.)
R3.3 Running "fugi" three times in a row leaves every MIKI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FULI has exactly one slot, called n1.
- PIPU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FAMU, VIFU, MIKI):
D1.1 FAMU must be a finite set with at most 1 slot.
D1.2 List the "fovo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 VIFU must be a finite set with at most 1 slot.
D2.2 List the "lika" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 MIKI must be a finite set with at most 1 slot.
D3.2 List the "fugi" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FAMU = {q1_1, ..., q1_k}
sivo: n1 -> <FAMU slot>
fovo: q1_1 -> <FAMU slot>, ..., q1_k -> <FAMU slot>
VIFU = {q2_1, ..., q2_k}
zama: q1_1 -> <VIFU slot>, ... (one entry per FAMU slot)
lika: q2_1 -> <VIFU slot>, ..., q2_k -> <VIFU slot>
MIKI = {q3_1, ..., q3_k}
vabo: q2_1 -> <MIKI slot>, ... (one entry per VIFU slot)
fugi: q3_1 -> <MIKI slot>, ..., q3_k -> <MIKI slot>
guji: q3_1 -> <PIPU slot>, ... (one entry per MIKI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
