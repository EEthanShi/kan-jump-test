You are completing the design of a small toy sorting line with 5 stations.

The stations are: FUBO, NAKA, DASI, GORI, NIGA. Toys move FUBO -> NAKA -> DASI -> GORI -> NIGA.
There are 7 moving steps:
- "vuni" carries each FUBO slot to a NAKA slot.
- "nuzu" is an internal reshuffle of NAKA: it carries each NAKA slot to a NAKA slot.
- "tasi" carries each NAKA slot to a DASI slot.
- "jali" is an internal reshuffle of DASI: it carries each DASI slot to a DASI slot.
- "nuku" carries each DASI slot to a GORI slot.
- "fulo" is an internal reshuffle of GORI: it carries each GORI slot to a GORI slot.
- "dola" carries each GORI slot to a NIGA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "vuni" and then "nuzu" lands on the same slot as running "vuni" alone.
     ("nuzu" leaves every slot that "vuni" produces unchanged.)
R1.2 Running "nuzu" and then "tasi" gives the same result as running "tasi" alone.
     ("tasi" cannot tell whether "nuzu" was applied first.)
R1.3 Running "nuzu" twice in a row leaves every NAKA slot exactly where it started.
R2.1 Running "tasi" and then "jali" lands on the same slot as running "tasi" alone.
     ("jali" leaves every slot that "tasi" produces unchanged.)
R2.2 Running "jali" and then "nuku" gives the same result as running "nuku" alone.
     ("nuku" cannot tell whether "jali" was applied first.)
R2.3 Running "jali" three times in a row leaves every DASI slot exactly where it started.
R3.1 Running "nuku" and then "fulo" lands on the same slot as running "nuku" alone.
     ("fulo" leaves every slot that "nuku" produces unchanged.)
R3.2 Running "fulo" and then "dola" gives the same result as running "dola" alone.
     ("dola" cannot tell whether "fulo" was applied first.)
R3.3 Running "fulo" twice in a row leaves every GORI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FUBO has exactly one slot, called n1.
- NIGA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (NAKA, DASI, GORI):
D1.1 NAKA must be a finite set with at most 1 slot.
D1.2 List the "nuzu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 DASI must be a finite set with at most 1 slot.
D2.2 List the "jali" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 GORI must be a finite set with at most 1 slot.
D3.2 List the "fulo" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

NAKA = {q1_1, ..., q1_k}
vuni: n1 -> <NAKA slot>
nuzu: q1_1 -> <NAKA slot>, ..., q1_k -> <NAKA slot>
DASI = {q2_1, ..., q2_k}
tasi: q1_1 -> <DASI slot>, ... (one entry per NAKA slot)
jali: q2_1 -> <DASI slot>, ..., q2_k -> <DASI slot>
GORI = {q3_1, ..., q3_k}
nuku: q2_1 -> <GORI slot>, ... (one entry per DASI slot)
fulo: q3_1 -> <GORI slot>, ..., q3_k -> <GORI slot>
dola: q3_1 -> <NIGA slot>, ... (one entry per GORI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
