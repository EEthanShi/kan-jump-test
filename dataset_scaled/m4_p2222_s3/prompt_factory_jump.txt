You are completing the design of a small toy sorting line with 6 stations.

The stations are: SUTA, FOBA, LOJA, KOKU, LIPI, MUDU. Toys move SUTA -> FOBA -> LOJA -> KOKU -> LIPI -> MUDU.
There are 9 moving steps:
- "nisi" carries each SUTA slot to a FOBA slot.
- "dazo" is an internal reshuffle of FOBA: it carries each FOBA slot to a FOBA slot.
- "duju" carries each FOBA slot to a LOJA slot.
- "fivi" is an internal reshuffle of LOJA: it carries each LOJA slot to a LOJA slot.
- "zasa" carries each LOJA slot to a KOKU slot.
- "zupa" is an internal reshuffle of KOKU: it carries each KOKU slot to a KOKU slot.
- "pumu" carries each KOKU slot to a LIPI slot.
- "nifu" is an internal reshuffle of LIPI: it carries each LIPI slot to a LIPI slot.
- "rumo" carries each LIPI slot to a MUDU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "nisi" and then "dazo" lands on the same slot as running "nisi" alone.
     ("dazo" leaves every slot that "nisi" produces unchanged.)
R1.2 Running "dazo" and then "duju" gives the same result as running "duju" alone.
     ("duju" cannot tell whether "dazo" was applied first.)
R1.3 Running "dazo" twice in a row leaves every FOBA slot exactly where it started.
R2.1 Running "duju" and then "fivi" lands on the same slot as running "duju" alone.
     ("fivi" leaves every slot that "duju" produces unchanged.)
R2.2 Running "fivi" and then "zasa" gives the same result as running "zasa" alone.
     ("zasa" cannot tell whether "fivi" was applied first.)
R2.3 Running "fivi" twice in a row leaves every LOJA slot exactly where it started.
R3.1 Running "zasa" and then "zupa" lands on the same slot as running "zasa" alone.
     ("zupa" leaves every slot that "zasa" produces unchanged.)
R3.2 Running "zupa" and then "pumu" gives the same result as running "pumu" alone.
     ("pumu" cannot tell whether "zupa" was applied first.)
R3.3 Running "zupa" twice in a row leaves every KOKU slot exactly where it started.
R4.1 Running "pumu" and then "nifu" lands on the same slot as running "pumu" alone.
     ("nifu" leaves every slot that "pumu" produces unchanged.)
R4.2 Running "nifu" and then "rumo" gives the same result as running "rumo" alone.
     ("rumo" cannot tell whether "nifu" was applied first.)
R4.3 Running "nifu" twice in a row leaves every LIPI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SUTA has exactly one slot, called n1.
- MUDU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FOBA, LOJA, KOKU, LIPI):
D1.1 FOBA must be a finite set with at most 3 slots.
D1.2 "dazo" must NOT be the do-nothing move (it must move at least one FOBA slot).
D2.1 LOJA must be a finite set with at most 3 slots.
D2.2 "fivi" must NOT be the do-nothing move (it must move at least one LOJA slot).
D3.1 KOKU must be a finite set with at most 3 slots.
D3.2 "zupa" must NOT be the do-nothing move (it must move at least one KOKU slot).
D4.1 LIPI must be a finite set with at most 3 slots.
D4.2 "nifu" must NOT be the do-nothing move (it must move at least one LIPI slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FOBA = {q1_1, ..., q1_k}
nisi: n1 -> <FOBA slot>
dazo: q1_1 -> <FOBA slot>, ..., q1_k -> <FOBA slot>
LOJA = {q2_1, ..., q2_k}
duju: q1_1 -> <LOJA slot>, ... (one entry per FOBA slot)
fivi: q2_1 -> <LOJA slot>, ..., q2_k -> <LOJA slot>
KOKU = {q3_1, ..., q3_k}
zasa: q2_1 -> <KOKU slot>, ... (one entry per LOJA slot)
zupa: q3_1 -> <KOKU slot>, ..., q3_k -> <KOKU slot>
LIPI = {q4_1, ..., q4_k}
pumu: q3_1 -> <LIPI slot>, ... (one entry per KOKU slot)
