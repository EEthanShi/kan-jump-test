You are completing the design of a small toy sorting line with 4 stations.

The stations are: RUNO, VIRI, SUPU, JIGO. Toys move RUNO -> VIRI -> SUPU -> JIGO.
There are 5 moving steps:
- "funo" carries each RUNO slot to a VIRI slot.
- "gula" is an internal reshuffle of VIRI: it carries each VIRI slot to a VIRI slot.
- "vutu" carries each VIRI slot to a SUPU slot.
- "foso" is an internal reshuffle of SUPU: it carries each SUPU slot to a SUPU slot.
- "gura" carries each SUPU slot to a JIGO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "funo" and then "gula" lands on the same slot as running "funo" alone.
     ("gula" leaves every slot that "funo" produces unchanged.)
R1.2 Running "gula" and then "vutu" gives the same result as running "vutu" alone.
     ("vutu" cannot tell whether "gula" was applied first.)
R1.3 Running "gula" three times in a row leaves every VIRI slot exactly where it started.
R2.1 Running "vutu" and then "foso" lands on the same slot as running "vutu" alone.
     ("foso" leaves every slot that "vutu" produces unchanged.)
R2.2 Running "foso" and then "gura" gives the same result as running "gura" alone.
     ("gura" cannot tell whether "foso" was applied first.)
R2.3 Running "foso" twice in a row leaves every SUPU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- RUNO has exactly one slot, called n1.
- JIGO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (VIRI, SUPU):
D1.1 VIRI must be a finite set with at most 1 slot.
D1.2 List the "gula" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 SUPU must be a finite set with at most 1 slot.
D2.2 List the "foso" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

VIRI = {q1_1, ..., q1_k}
funo: n1 -> <VIRI slot>
gula: q1_1 -> <VIRI slot>, ..., q1_k -> <VIRI slot>
SUPU = {q2_1, ..., q2_k}
vutu: q1_1 -> <SUPU slot>, ... (one entry per VIRI slot)
foso: q2_1 -> <SUPU slot>, ..., q2_k -> <SUPU slot>
gura: q2_1 -> <JIGO slot>, ... (one entry per SUPU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
