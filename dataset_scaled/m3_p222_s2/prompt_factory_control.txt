You are completing the design of a small toy sorting line with 5 stations.

The stations are: JUTO, PIVO, DIZA, MUZU, NOPA. Toys move JUTO -> PIVO -> DIZA -> MUZU -> NOPA.
There are 7 moving steps:
- "ragi" carries each JUTO slot to a PIVO slot.
- "sari" is an internal reshuffle of PIVO: it carries each PIVO slot to a PIVO slot.
- "vani" carries each PIVO slot to a DIZA slot.
- "lunu" is an internal reshuffle of DIZA: it carries each DIZA slot to a DIZA slot.
- "guki" carries each DIZA slot to a MUZU slot.
- "pupu" is an internal reshuffle of MUZU: it carries each MUZU slot to a MUZU slot.
- "noti" carries each MUZU slot to a NOPA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "ragi" and then "sari" lands on the same slot as running "ragi" alone.
     ("sari" leaves every slot that "ragi" produces unchanged.)
R1.2 Running "sari" and then "vani" gives the same result as running "vani" alone.
     ("vani" cannot tell whether "sari" was applied first.)
R1.3 Running "sari" twice in a row leaves every PIVO slot exactly where it started.
R2.1 Running "vani" and then "lunu" lands on the same slot as running "vani" alone.
     ("lunu" leaves every slot that "vani" produces unchanged.)
R2.2 Running "lunu" and then "guki" gives the same result as running "guki" alone.
     ("guki" cannot tell whether "lunu" was applied first.)
R2.3 Running "lunu" twice in a row leaves every DIZA slot exactly where it started.
R3.1 Running "guki" and then "pupu" lands on the same slot as running "guki" alone.
     ("pupu" leaves every slot that "guki" produces unchanged.)
R3.2 Running "pupu" and then "noti" gives the same result as running "noti" alone.
     ("noti" cannot tell whether "pupu" was applied first.)
R3.3 Running "pupu" twice in a row leaves every MUZU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JUTO has exactly one slot, called n1.
- NOPA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PIVO, DIZA, MUZU):
D1.1 PIVO must be a finite set with at most 1 slot.
D1.2 List the "sari" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 DIZA must be a finite set with at most 1 slot.
D2.2 List the "lunu" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 MUZU must be a finite set with at most 1 slot.
D3.2 List the "pupu" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PIVO = {q1_1, ..., q1_k}
ragi: n1 -> <PIVO slot>
sari: q1_1 -> <PIVO slot>, ..., q1_k -> <PIVO slot>
DIZA = {q2_1, ..., q2_k}
vani: q1_1 -> <DIZA slot>, ... (one entry per PIVO slot)
lunu: q2_1 -> <DIZA slot>, ..., q2_k -> <DIZA slot>
MUZU = {q3_1, ..., q3_k}
guki: q2_1 -> <MUZU slot>, ... (one entry per DIZA slot)
pupu: q3_1 -> <MUZU slot>, ..., q3_k -> <MUZU slot>
noti: q3_1 -> <NOPA slot>, ... (one entry per MUZU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
