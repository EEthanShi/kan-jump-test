You are completing the design of a small toy sorting line with 4 stations.

The stations are: FOGA, MAPO, TIGO, MUPO. Toys move FOGA -> MAPO -> TIGO -> MUPO.
There are 5 moving steps:
- "fonu" carries each FOGA slot to a MAPO slot.
- "timo" is an internal reshuffle of MAPO: it carries each MAPO slot to a MAPO slot.
- "maba" carries each MAPO slot to a TIGO slot.
- "nibo" is an internal reshuffle of TIGO: it carries each TIGO slot to a TIGO slot.
- "kaba" carries each TIGO slot to a MUPO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "fonu" and then "timo" lands on the same slot as running "fonu" alone.
     ("timo" leaves every slot that "fonu" produces unchanged.)
R1.2 Running "timo" and then "maba" gives the same result as running "maba" alone.
     ("maba" cannot tell whether "timo" was applied first.)
R1.3 Running "timo" twice in a row leaves every MAPO slot exactly where it started.
R2.1 Running "maba" and then "nibo" lands on the same slot as running "maba" alone.
     ("nibo" leaves every slot that "maba" produces unchanged.)
R2.2 Running "nibo" and then "kaba" gives the same result as running "kaba" alone.
     ("kaba" cannot tell whether "nibo" was applied first.)
R2.3 Running "nibo" twice in a row leaves every TIGO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- FOGA has exactly one slot, called n1.
- MUPO has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (MAPO, TIGO):
D1.1 MAPO must be a finite set with at most 3 slots.
D1.2 "timo" must NOT be the do-nothing move (it must move at least one MAPO slot).
D2.1 TIGO must be a finite set with at most 3 slots.
D2.2 "nibo" must NOT be the do-nothing move (it must move at least one TIGO slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

MAPO = {q1_1, ..., q1_k}
fonu: n1 -> <MAPO slot>
timo: q1_1 -> <MAPO slot>, ..., q1_k -> <MAPO slot>
TIGO = {q2_1, ..., q2_k}
maba: q1_1 -> <TIGO slot>, ... (one entry per MAPO slot)
nibo: q2_1 -> <TIGO slot>, ..., q2_k -> <TIGO slot>
kaba: q2_1 -> <MUPO slot>, ... (one entry per TIGO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
