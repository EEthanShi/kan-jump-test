You are completing the design of a small toy sorting line with 4 stations.

The stations are: GAPI, PAVU, NODU, NAKI. Toys move GAPI -> PAVU -> NODU -> NAKI.
There are 5 moving steps:
- "kano" carries each GAPI slot to a PAVU slot.
- "duba" is an internal reshuffle of PAVU: it carries each PAVU slot to a PAVU slot.
- "buri" carries each PAVU slot to a NODU slot.
- "vudi" is an internal reshuffle of NODU: it carries each NODU slot to a NODU slot.
- "pupi" carries each NODU slot to a NAKI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "kano" and then "duba" lands on the same slot as running "kano" alone.
     ("duba" leaves every slot that "kano" produces unchanged.)
R1.2 Running "duba" and then "buri" gives the same result as running "buri" alone.
     ("buri" cannot tell whether "duba" was applied first.)
R1.3 Running "duba" twice in a row leaves every PAVU slot exactly where it started.
R2.1 Running "buri" and then "vudi" lands on the same slot as running "buri" alone.
     ("vudi" leaves every slot that "buri" produces unchanged.)
R2.2 Running "vudi" and then "pupi" gives the same result as running "pupi" alone.
     ("pupi" cannot tell whether "vudi" was applied first.)
R2.3 Running "vudi" three times in a row leaves every NODU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- GAPI has exactly one slot, called n1.
- NAKI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (PAVU, NODU):
D1.1 PAVU must be a finite set with at most 1 slot.
D1.2 List the "duba" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 NODU must be a finite set with at most 1 slot.
D2.2 List the "vudi" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

PAVU = {q1_1, ..., q1_k}
kano: n1 -> <PAVU slot>
duba: q1_1 -> <PAVU slot>, ..., q1_k -> <PAVU slot>
NODU = {q2_1, ..., q2_k}
buri: q1_1 -> <NODU slot>, ... (one entry per PAVU slot)
vudi: q2_1 -> <NODU slot>, ..., q2_k -> <NODU slot>
pupi: q2_1 -> <NAKI slot>, ... (one entry per NODU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
