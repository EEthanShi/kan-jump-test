You are completing the design of a small toy sorting line with 3 stations.

The stations are: SARO, BOSO, RUFI. Toys move SARO -> BOSO -> RUFI.
There are 3 moving steps:
- "futa" carries each SARO slot to a BOSO slot.
- "dura" is an internal reshuffle of BOSO: it carries each BOSO slot to a BOSO slot.
- "bimi" carries each BOSO slot to a RUFI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "futa" and then "dura" lands on the same slot as running "futa" alone.
     ("dura" leaves every slot that "futa" produces unchanged.)
R1.2 Running "dura" and then "bimi" gives the same result as running "bimi" alone.
     ("bimi" cannot tell whether "dura" was applied first.)
R1.3 Running "dura" twice in a row leaves every BOSO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- SARO has exactly 3 slots, called n1, n2, n3.
- RUFI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle station (BOSO):
D1.1 BOSO must be a finite set with at most 1 slot.
D1.2 List the "dura" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 List the "futa" table entries in SARO slot order n1, n2, n3.
D1.4 Every RUFI slot must be reached by "bimi" from at least one BOSO slot.

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 5 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

BOSO = {q1_1, ..., q1_k}
futa: n1 -> <BOSO slot>, n2 -> <BOSO slot>, n3 -> <BOSO slot>
dura: q1_1 -> <BOSO slot>, ..., q1_k -> <BOSO slot>
bimi: q1_1 -> <RUFI slot>, ... (one entry per BOSO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
