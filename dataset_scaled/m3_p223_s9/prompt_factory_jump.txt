You are completing the design of a small toy sorting line with 5 stations.

The stations are: VUDI, RATA, RUJU, VIJA, DINU. Toys move VUDI -> RATA -> RUJU -> VIJA -> DINU.
There are 7 moving steps:
- "jagu" carries each VUDI slot to a RATA slot.
- "puja" is an internal reshuffle of RATA: it carries each RATA slot to a RATA slot.
- "luji" carries each RATA slot to a RUJU slot.
- "vapo" is an internal reshuffle of RUJU: it carries each RUJU slot to a RUJU slot.
- "vobo" carries each RUJU slot to a VIJA slot.
- "ziti" is an internal reshuffle of VIJA: it carries each VIJA slot to a VIJA slot.
- "ragi" carries each VIJA slot to a DINU slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "jagu" and then "puja" lands on the same slot as running "jagu" alone.
     ("puja" leaves every slot that "jagu" produces unchanged.)
R1.2 Running "puja" and then "luji" gives the same result as running "luji" alone.
     ("luji" cannot tell whether "puja" was applied first.)
R1.3 Running "puja" twice in a row leaves every RATA slot exactly where it started.
R2.1 Running "luji" and then "vapo" lands on the same slot as running "luji" alone.
     ("vapo" leaves every slot that "luji" produces unchanged.)
R2.2 Running "vapo" and then "vobo" gives the same result as running "vobo" alone.
     ("vobo" cannot tell whether "vapo" was applied first.)
R2.3 Running "vapo" twice in a row leaves every RUJU slot exactly where it started.
R3.1 Running "vobo" and then "ziti" lands on the same slot as running "vobo" alone.
     ("ziti" leaves every slot that "vobo" produces unchanged.)
R3.2 Running "ziti" and then "ragi" gives the same result as running "ragi" alone.
     ("ragi" cannot tell whether "ziti" was applied first.)
R3.3 Running "ziti" three times in a row leaves every VIJA slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- VUDI has exactly one slot, called n1.
- DINU has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (RATA, RUJU, VIJA):
D1.1 RATA must be a finite set with at most 3 slots.
D1.2 "puja" must NOT be the do-nothing move (it must move at least one RATA slot).
D2.1 RUJU must be a finite set with at most 3 slots.
D2.2 "vapo" must NOT be the do-nothing move (it must move at least one RUJU slot).
D3.1 VIJA must be a finite set with at most 4 slots.
D3.2 "ziti" must NOT be the do-nothing move (it must move at least one VIJA slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

RATA = {q1_1, ..., q1_k}
jagu: n1 -> <RATA slot>
puja: q1_1 -> <RATA slot>, ..., q1_k -> <RATA slot>
RUJU = {q2_1, ..., q2_k}
luji: q1_1 -> <RUJU slot>, ... (one entry per RATA slot)
vapo: q2_1 -> <RUJU slot>, ..., q2_k -> <RUJU slot>
VIJA = {q3_1, ..., q3_k}
vobo: q2_1 -> <VIJA slot>, ... (one entry per RUJU slot)
ziti: q3_1 -> <VIJA slot>, ..., q3_k -> <VIJA slot>
ragi: q3_1 -> <DINU slot>, ... (one entry per VIJA slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
