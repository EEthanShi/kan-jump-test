You are completing the design of a small toy sorting line with 5 stations.

The stations are: JUKI, NUSO, POVO, FAZO, DUNA. Toys move JUKI -> NUSO -> POVO -> FAZO -> DUNA.
There are 7 moving steps:
- "gafu" carries each JUKI slot to a NUSO slot.
- "poja" is an internal reshuffle of NUSO: it carries each NUSO slot to a NUSO slot.
- "lika" carries each NUSO slot to a POVO slot.
- "luvu" is an internal reshuffle of POVO: it carries each POVO slot to a POVO slot.
- "sazi" carries each POVO slot to a FAZO slot.
- "tajo" is an internal reshuffle of FAZO: it carries each FAZO slot to a FAZO slot.
- "gara" carries each FAZO slot to a DUNA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "gafu" and then "poja" lands on the same slot as running "gafu" alone.
     ("poja" leaves every slot that "gafu" produces unchanged.)
R1.2 Running "poja" and then "lika" gives the same result as running "lika" alone.
     ("lika" cannot tell whether "poja" was applied first.)
R1.3 Running "poja" three times in a row leaves every NUSO slot exactly where it started.
R2.1 Running "lika" and then "luvu" lands on the same slot as running "lika" alone.
     ("luvu" leaves every slot that "lika" produces unchanged.)
R2.2 Running "luvu" and then "sazi" gives the same result as running "sazi" alone.
     ("sazi" cannot tell whether "luvu" was applied first.)
R2.3 Running "luvu" twice in a row leaves every POVO slot exactly where it started.
R3.1 Running "sazi" and then "tajo" lands on the same slot as running "sazi" alone.
     ("tajo" leaves every slot that "sazi" produces unchanged.)
R3.2 Running "tajo" and then "gara" gives the same result as running "gara" alone.
     ("gara" cannot tell whether "tajo" was applied first.)
R3.3 Running "tajo" twice in a row leaves every FAZO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JUKI has exactly one slot, called n1.
- DUNA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (NUSO, POVO, FAZO):
D1.1 NUSO must be a finite set with at most 1 slot.
D1.2 List the "poja" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 POVO must be a finite set with at most 1 slot.
D2.2 List the "luvu" table entries in slot order q2_1, q2_2, ..., one entry per slot.
D3.1 FAZO must be a finite set with at most 1 slot.
D3.2 List the "tajo" table entries in slot order q3_1, q3_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

NUSO = {q1_1, ..., q1_k}
gafu: n1 -> <NUSO slot>
poja: q1_1 -> <NUSO slot>, ..., q1_k -> <NUSO slot>
POVO = {q2_1, ..., q2_k}
lika: q1_1 -> <POVO slot>, ... (one entry per NUSO slot)
luvu: q2_1 -> <POVO slot>, ..., q2_k -> <POVO slot>
FAZO = {q3_1, ..., q3_k}
sazi: q2_1 -> <FAZO slot>, ... (one entry per POVO slot)
tajo: q3_1 -> <FAZO slot>, ..., q3_k -> <FAZO slot>
gara: q3_1 -> <DUNA slot>, ... (one entry per FAZO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
