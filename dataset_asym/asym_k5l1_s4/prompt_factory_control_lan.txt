You are completing the design of a small toy sorting line with 3 stations.

The stations are: TANU, KUTO, MUDI. Toys move TANU -> KUTO -> MUDI.
There are 3 moving steps:
- "zafa" carries each TANU slot to a KUTO slot.
- "nabo" is an internal reshuffle of KUTO: it carries each KUTO slot to a KUTO slot.
- "zigi" carries each KUTO slot to a MUDI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "zafa" and then "nabo" lands on the same slot as running "zafa" alone.
     ("nabo" leaves every slot that "zafa" produces unchanged.)
R1.2 Running "nabo" and then "zigi" gives the same result as running "zigi" alone.
     ("zigi" cannot tell whether "nabo" was applied first.)
R1.3 Running "nabo" twice in a row leaves every KUTO slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- TANU has exactly 5 slots, called n1, n2, n3, n4, n5.
- MUDI has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (KUTO):
D1.1 KUTO must be a finite set with at most 5 slots.
D1.2 List the "nabo" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "zafa" must carry different TANU slots to different KUTO slots.
D1.4 List the "zigi" table entries in KUTO slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

KUTO = {q1_1, ..., q1_k}
zafa: n1 -> <KUTO slot>, n2 -> <KUTO slot>, n3 -> <KUTO slot>, n4 -> <KUTO slot>, n5 -> <KUTO slot>
nabo: q1_1 -> <KUTO slot>, ..., q1_k -> <KUTO slot>
zigi: q1_1 -> <MUDI slot>, ... (one entry per KUTO slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
