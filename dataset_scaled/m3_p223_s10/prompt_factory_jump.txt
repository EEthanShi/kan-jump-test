You are completing the design of a small toy sorting line with 5 stations.

The stations are: PIGI, ZIZA, TONO, FIFU, PORI. Toys move PIGI -> ZIZA -> TONO -> FIFU -> PORI.
There are 7 moving steps:
- "gofi" carries each PIGI slot to a ZIZA slot.
- "vuru" is an internal reshuffle of ZIZA: it carries each ZIZA slot to a ZIZA slot.
- "foma" carries each ZIZA slot to a TONO slot.
- "zabu" is an internal reshuffle of TONO: it carries each TONO slot to a TONO slot.
- "nugo" carries each TONO slot to a FIFU slot.
- "fuvi" is an internal reshuffle of FIFU: it carries each FIFU slot to a FIFU slot.
- "tusi" carries each FIFU slot to a PORI slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "gofi" and then "vuru" lands on the same slot as running "gofi" alone.
     ("vuru" leaves every slot that "gofi" produces unchanged.)
R1.2 Running "vuru" and then "foma" gives the same result as running "foma" alone.
     ("foma" cannot tell whether "vuru" was applied first.)
R1.3 Running "vuru" twice in a row leaves every ZIZA slot exactly where it started.
R2.1 Running "foma" and then "zabu" lands on the same slot as running "foma" alone.
     ("zabu" leaves every slot that "foma" produces unchanged.)
R2.2 Running "zabu" and then "nugo" gives the same result as running "nugo" alone.
     ("nugo" cannot tell whether "zabu" was applied first.)
R2.3 Running "zabu" twice in a row leaves every TONO slot exactly where it started.
R3.1 Running "nugo" and then "fuvi" lands on the same slot as running "nugo" alone.
     ("fuvi" leaves every slot that "nugo" produces unchanged.)
R3.2 Running "fuvi" and then "tusi" gives the same result as running "tusi" alone.
     ("tusi" cannot tell whether "fuvi" was applied first.)
R3.3 Running "fuvi" three times in a row leaves every FIFU slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- PIGI has exactly one slot, called n1.
- PORI has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (ZIZA, TONO, FIFU):
D1.1 ZIZA must be a finite set with at most 3 slots.
D1.2 "vuru" must NOT be the do-nothing move (it must move at least one ZIZA slot).
D2.1 TONO must be a finite set with at most 3 slots.
D2.2 "zabu" must NOT be the do-nothing move (it must move at least one TONO slot).
D3.1 FIFU must be a finite set with at most 4 slots.
D3.2 "fuvi" must NOT be the do-nothing move (it must move at least one FIFU slot).

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 5 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

ZIZA = {q1_1, ..., q1_k}
gofi: n1 -> <ZIZA slot>
vuru: q1_1 -> <ZIZA slot>, ..., q1_k -> <ZIZA slot>
TONO = {q2_1, ..., q2_k}
foma: q1_1 -> <TONO slot>, ... (one entry per ZIZA slot)
zabu: q2_1 -> <TONO slot>, ..., q2_k -> <TONO slot>
FIFU = {q3_1, ..., q3_k}
nugo: q2_1 -> <FIFU slot>, ... (one entry per TONO slot)
fuvi: q3_1 -> <FIFU slot>, ..., q3_k -> <FIFU slot>
tusi: q3_1 -> <PORI slot>, ... (one entry per FIFU slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
