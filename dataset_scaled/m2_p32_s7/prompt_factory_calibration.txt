You are completing the design of a small toy sorting line with 4 stations.

The stations are: JADI, FOFO, GOJI, DISA. Toys move JADI -> FOFO -> GOJI -> DISA.
There are 5 moving steps:
- "fijo" carries each JADI slot to a FOFO slot.
- "pisi" is an internal reshuffle of FOFO: it carries each FOFO slot to a FOFO slot.
- "nubu" carries each FOFO slot to a GOJI slot.
- "vapa" is an internal reshuffle of GOJI: it carries each GOJI slot to a GOJI slot.
- "subi" carries each GOJI slot to a DISA slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "fijo" and then "pisi" lands on the same slot as running "fijo" alone.
     ("pisi" leaves every slot that "fijo" produces unchanged.)
R1.2 Running "pisi" and then "nubu" gives the same result as running "nubu" alone.
     ("nubu" cannot tell whether "pisi" was applied first.)
R1.3 Running "pisi" three times in a row leaves every FOFO slot exactly where it started.
R2.1 Running "nubu" and then "vapa" lands on the same slot as running "nubu" alone.
     ("vapa" leaves every slot that "nubu" produces unchanged.)
R2.2 Running "vapa" and then "subi" gives the same result as running "subi" alone.
     ("subi" cannot tell whether "vapa" was applied first.)
R2.3 Running "vapa" twice in a row leaves every GOJI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- JADI has exactly one slot, called n1.
- DISA has exactly one slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1.

Requirements for the middle stations (FOFO, GOJI):
D1.1 List the slots of FOFO in increasing index order q1_1, q1_2, ... in its set line.
D1.2 List the "pisi" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D2.1 List the slots of GOJI in increasing index order q2_1, q2_2, ... in its set line.
D2.2 List the "vapa" table entries in slot order q2_1, q2_2, ..., one entry per slot.

Your task: give one complete concrete design of the middle stations.

Answer format bound: designs with up to 4 slots per middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
for station number i in the row, use slot names qi_1, qi_2, ...):

FOFO = {q1_1, ..., q1_k}
fijo: n1 -> <FOFO slot>
pisi: q1_1 -> <FOFO slot>, ..., q1_k -> <FOFO slot>
GOJI = {q2_1, ..., q2_k}
nubu: q1_1 -> <GOJI slot>, ... (one entry per FOFO slot)
vapa: q2_1 -> <GOJI slot>, ..., q2_k -> <GOJI slot>
subi: q2_1 -> <DISA slot>, ... (one entry per GOJI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
