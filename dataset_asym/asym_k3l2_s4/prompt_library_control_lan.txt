You are completing the design of a small book sorting row of carts with 3 carts.

The carts are: DOFI, TALO, NUFI. Books move DOFI -> TALO -> NUFI.
There are 3 moving steps:
- "josu" carries each DOFI tray to a TALO tray.
- "bizo" is an internal rearrangement of TALO: it carries each TALO tray to a TALO tray.
- "lomo" carries each TALO tray to a NUFI tray.

The row's operating rules. These must hold exactly, tray by tray:
R1.1 Running "josu" and then "bizo" lands on the same tray as running "josu" alone.
     ("bizo" leaves every tray that "josu" produces unchanged.)
R1.2 Running "bizo" and then "lomo" gives the same result as running "lomo" alone.
     ("lomo" cannot tell whether "bizo" was applied first.)
R1.3 Running "bizo" twice in a row leaves every TALO tray exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- DOFI has exactly 3 trays, called n1, n2, n3.
- NUFI has exactly 2 trays, called s1, s2.
- The observed end-to-end behavior of the row sends n1 to s1, n2 to s1, n3 to s1.

Requirements for the middle cart (TALO):
D1.1 TALO must be a finite set with at most 3 trays.
D1.2 List the "bizo" table entries in tray order q1_1, q1_2, ..., one entry per tray.
D1.3 "josu" must carry different DOFI trays to different TALO trays.
D1.4 List the "lomo" table entries in TALO tray order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle cart.

Answer format bound: designs with up to 5 trays in the middle cart
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every tray and every table entry;
use tray names q1_1, q1_2, ... for the middle cart):

TALO = {q1_1, ..., q1_k}
josu: n1 -> <TALO tray>, n2 -> <TALO tray>, n3 -> <TALO tray>
bizo: q1_1 -> <TALO tray>, ..., q1_k -> <TALO tray>
lomo: q1_1 -> <NUFI tray>, ... (one entry per TALO tray)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
