You are completing the design of a small toy sorting line with 3 stations.

The stations are: ZOBU, DAGI, ZIGO. Toys move ZOBU -> DAGI -> ZIGO.
There are 3 moving steps:
- "supo" carries each ZOBU slot to a DAGI slot.
- "vazu" is an internal reshuffle of DAGI: it carries each DAGI slot to a DAGI slot.
- "kali" carries each DAGI slot to a ZIGO slot.

The line's operating rules. These must hold exactly, slot by slot:
R1.1 Running "supo" and then "vazu" lands on the same slot as running "supo" alone.
     ("vazu" leaves every slot that "supo" produces unchanged.)
R1.2 Running "vazu" and then "kali" gives the same result as running "kali" alone.
     ("kali" cannot tell whether "vazu" was applied first.)
R1.3 Running "vazu" twice in a row leaves every DAGI slot exactly where it started.

Recorded observations (fixed; your design must reproduce them exactly):
- ZOBU has exactly 5 slots, called n1, n2, n3, n4, n5.
- ZIGO has exactly 1 slot, called s1.
- The observed end-to-end behavior of the line sends n1 to s1, n2 to s1, n3 to s1, n4 to s1, n5 to s1.

Requirements for the middle station (DAGI):
D1.1 DAGI must be a finite set with at most 5 slots.
D1.2 List the "vazu" table entries in slot order q1_1, q1_2, ..., one entry per slot.
D1.3 "supo" must carry different ZOBU slots to different DAGI slots.
D1.4 List the "kali" table entries in DAGI slot order q1_1, q1_2, ...

Your task: give one complete concrete design of the middle station.

Answer format bound: designs with up to 7 slots in the middle station
are well-formed answers (the requirements above may restrict this further).

Answer in exactly this format (listing every slot and every table entry;
use slot names q1_1, q1_2, ... for the middle station):

DAGI = {q1_1, ..., q1_k}
supo: n1 -> <DAGI slot>, n2 -> <DAGI slot>, n3 -> <DAGI slot>, n4 -> <DAGI slot>, n5 -> <DAGI slot>
vazu: q1_1 -> <DAGI slot>, ..., q1_k -> <DAGI slot>
kali: q1_1 -> <ZIGO slot>, ... (one entry per DAGI slot)

Every rule and requirement above must hold exactly for your tables. Do not
explain; output only the lines in the format above.
